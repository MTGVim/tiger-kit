# ADR 0009: Terra 6.1의 Effort 고정 시범 재채용

- 상태: Accepted (기본값 복원, 실효 작업 결과 미검증)
- 날짜: 2026-11-21

## 맥락

사용자가 Orca에서 GPT-6.1 Terra High로 구현을 요청했지만 실제 코드를 수정하지 않고 설명만 한 뒤 턴을 종료하는 현상을 경험했습니다. 이후 문제 발생 직전에 Effort를 변경했다는 사실이 확인됐습니다. 세션과 턴의 Effort 불일치가 조기 종료와 함께 보고된 Codex 사례도 있으나, 사용자 환경의 원인이 동일하다고 입증되지 않았습니다. Effort를 변경하지 않은 상황의 실패 가능성도 남아 있습니다.

2026-11-21에는 이 경험과 커뮤니티 제보를 근거로 Terra를 기본 모델에서 제외했습니다. 하지만 그 과정에서 Pareto 기반 벤치마크 도출을 건너뛰는 조건과 Terra 제외 예외를 `derive()`에 추가하고, OpenAI Top의 Effort도 Medium에서 High로 변경했습니다. 일시적인 위험 대응이 모델 선정 알고리즘의 변경으로 확대됐습니다.

## 결정

1. Terra 제외 직전의 비용·지능 점수 기반 Pareto 선정 규칙과 기본 모델 대응표를 복원합니다. OpenAI Standard 모드는 Luna 6 Low / Terra 6.1 Medium / Sol 6.2 Medium, Economy 모드는 Luna 6 Low / Terra 6.1 Low / Sol 6.2 Medium입니다. Anthropic 대응표는 유지합니다.
2. Terra는 **Effort를 바꾸지 않는 조건으로 시범 재채용**합니다. 모델과 Effort는 새 세션 시작 전에 지정하며, 작업 도중 둘 중 하나를 변경하지 않습니다. 변경해야 한다면 새 세션에서 별도 작업으로 다시 시작하고 실제 적용값을 호스트 기록으로 확인합니다.
3. 비용·지능 점수는 후보 선정을 위해 사용하고, 실제 작업 완료율·미착수·조기 종료·거짓 완료·재지시·검증 통과·비용은 독립된 신뢰성 지표로 보고합니다. 통제된 비교 없이 Terra를 일괄 배제하거나 성공률이 높아졌다고 단정하지 않습니다.
4. 번들 벤치마크는 2026-11-17에 재구성한 과거 자료로, Sol 6.1 측정값을 Sol 6.2의 수치로 전용하지 않습니다. 최신 모델을 평가할 때에는 원본 데이터와 코딩 성능 자료를 다시 조사합니다.
5. 이번 결정은 저장소의 **신규 기본 대응표**에만 적용합니다. 사용자별 저장 설정, 실제 Orca/Codex/Claude Code/Hermes의 프로필과 진행 중인 세션은 자동 변경하지 않습니다.

## 검증 상태와 재평가

이번 재채용은 기본 설정 및 검증 조건의 복원을 의미합니다. Effort를 고정했을 때 Terra의 조기 종료가 사라지는지는 아직 확인되지 않았고, 실제 코딩 완료율도 측정하지 않았습니다. 동일 과제·호스트·권한·검증 명령으로 Sol 대안과 반복 비교한 결과를 얻으면 `tk-route-mode update`를 통해 재평가합니다.

## 변경 이력

- 2026-11-21: 실행 미착수 경험으로 Terra를 제외했다가 Effort 변경 사실과 원인 불확실성을 확인한 후, 원래 모델 선정 규칙을 복원하고 Effort 고정 조건으로 시범 재채용했습니다.
