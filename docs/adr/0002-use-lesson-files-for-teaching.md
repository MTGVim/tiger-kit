# 0002. 새 학습은 수업별 HTML과 실제 답변의 피드백으로 이어간다

상태: 확정 · 2026-10-25

[코스 폐기 결정](0001-retire-tk-course.md) 이후에도 설명과 예제·연습을 다시 볼 HTML 자료는 필요하다. 모든 수업을 큰 진입 문서로 계속 재생성하면, 실제 답변에 따라 다음 수업만 조정하려는 목적과 파일 유지 방식이 어긋난다.

새 학습에서는 한 수업을 독립된 HTML 파일로 만들고, 학습자의 실제 풀이와 이유에 따라 피드백·재시도·다음 수업을 정한다. 목록은 필요할 때만 가볍게 갱신한다. 기존 단일 문서와 학습 기록은 자동 분할·이전하지 않으며, 사용자가 완결된 다중 챕터 자료를 명시적으로 요청하면 그 범위를 따른다.

대안은 단일 누적 문서를 계속 기본값으로 삼거나 별도 수업 런타임을 도입하는 것이었다. 수업 파일을 선택하면 앞선 자료를 유지하면서 다음 단위만 바꿀 수 있지만 작은 표시 자산이 파일마다 중복되고 연결 관리가 필요하다. 오프라인 자기 확인과 에이전트가 실제로 본 답변을 구분하므로 자동 제출·숙달 판정을 제공하지 않는다. 영상·음성과 대용량 자산의 별도 배포는 기존 도구와 공통 계약의 후속 검토 범위로 남긴다.

근거: 공개 구현을 대조한 재구성안에 대한 이번 진행 요청, [현재 증류 근거](../../skills/tk-teach/references/distillation.md), [기존 학습 기록 계약](../../skills/tk-teach/references/learning-state.md). 이 기록은 코스 폐기 결정을 대체하지 않고 수업 제작 방식만 구체화한다.
