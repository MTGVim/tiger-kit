# 0001. `tk-course`를 폐기하고 수업·매체의 책임을 분리한다

현재 설명·후속 수업 담당자는 `tk-explain`입니다. 아래는 결정 당시의 기록이며 폐기된 스킬의 현재 설치 안내가 아닙니다.

상태: 확정 · 2026-10-25

대용량 `index.html`을 열지 못한 문제를 계기로 검토한 결과, 완결 코스의 저작·재생·배포 계층을 계속 유지하는 비용이 수업 내용의 개선과 평가를 어렵게 한다고 판단했다. 미디어를 외부 파일로 분리하는 수정은 반영했지만, 사용자는 추가 보수 대신 `tk-course`의 폐기를 결정했다.

`tk-course`와 전용 생성기·플레이어·평가 계약을 현행 배포에서 제거한다. 학습자의 실제 답변에 따른 수업과 복습은 `tk-teach`, 현상·개념 설명은 `tk-explain`이 담당한다. HTML 수업 자료는 유지하며 `tk-video`와 `tk-tts`도 독립 도구로 유지한다. 기존에 만든 코스와 학습 기록을 삭제하거나 자동 이전하지 않는다.

대안은 분리 배포를 적용한 코스 계층을 계속 보수하는 것이었다. 폐기를 선택하면 완결 코스 전용 재생·진도·카탈로그 기능의 신규 제작 경로를 잃지만, 그 계층을 유지하고 검증할 부담을 줄인다. 복구에는 전용 구현과 평가 계약의 재도입이 필요하므로 단순한 이름 변경이나 `tk-teach`로의 통합으로 취급하지 않는다. `tk-teach`의 세부 재구성은 공개 구현을 조사한 뒤 별도로 검토하며 이 기록에서 확정하지 않는다.
