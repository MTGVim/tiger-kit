# 이슈 371 산출물 경로 조사

2026-09-19에 활성 스킬 본문·참조, 실행 스크립트, 릴리즈 예시와 평가 소비자를 조사했습니다.
공통 정책은 `scripts/artifact_policy.py`가 소유하며 설치 패키지에는 동일한 실행 계약을 포함합니다.
이 문서는 경로 이전 판단을 기록합니다.

| 대상 | 판정 | 근거와 목적지 |
| --- | --- | --- |
| `tk-explain`의 현재 디렉터리 HTML | `move` | 기본 경로는 `.tigerkit/explanations/`이며 명시한 최종 경로는 존중합니다. |
| `tk-explain-diff`, `tk-study` | `move` | `.tigerkit/explanations/`와 `.tigerkit/study/<topic>/`를 사용합니다. |
| 저장하는 `tk-research` 보고서 | `move` | 기본 경로는 `.tigerkit/research/`이며 저장이 필요하지 않으면 대화로만 답합니다. |
| 브라우저 이미지 근거 | `move` | `.tigerkit/evidence/tk-browser-verify/<run-id>/`로 통일하고 캡처와 소비자 대응을 보존합니다. |
| 브라우저의 변경 전 소스 복원 | `move` | `.tigerkit/tmp/tk-browser-verify/<run-id>/baseline-source/`를 사용하고 실행 소유 서버를 종료한 뒤 정리합니다. |
| 릴리즈·평가 결과 | `move` | `.tigerkit/evidence/<owner>/`에 고유 실행 경로를 만들며 명시한 외부 최종 경로는 지원합니다. |
| 평가용 격리 작업 트리·복제본·어댑터 실행·설치 검사 | `move` | 검사한 `.tigerkit/tmp/<owner>/`에 생성하고 실행 소유 디렉터리만 정리합니다. |
| 기존 준비·학습·인계·SDD·시제품·비밀 입력 산출물 | `keep` | 이미 저장소 내부에 있으며 추적·무시 검사와 소유자 경계를 유지합니다. |
| 원자적 교체용 임시 파일 | `keep` | 대상과 같은 파일시스템에 있어야 하며 성공 후 실행 소유 임시 파일을 정리합니다. |
| 단위 테스트의 `tempfile` | `keep` | 손상되거나 Git이 없는 저장소를 의도적으로 만들어야 하므로 실제 저장소를 수정하지 않는 격리가 필요합니다. |
| 외부 브라우저 프로필·패키지 캐시 | `keep` | 해당 도구가 수명을 소유하며 TigerKit 보고서나 사용자 입력은 보관하지 않습니다. |
| 필수 렌더러·학습 작업 공간 상용구 | `remove` | 신규 스킬은 학습 내용과 표현을 분리하며 불필요한 디렉터리를 만들지 않습니다. |

활성 실행 도구에서 별도의 `mktemp` 셸 명령이나 저장소 루트에 임시 JSON·Markdown을 쓰는 경로는 발견되지 않았습니다.
과거 이력과 부정 테스트 사례를 기본 출력 지침으로 취급하지 않습니다.
중첩 작업 트리 검증기는 상위 `.tigerkit` 이름이 아닌 검사 대상 내부의 상대 경로로 제외 여부를 판단합니다.
기계적 검사는 안전하지 않은 경로·추적·무시·심볼릭 링크·기존 결과 보존·중첩 링크 검사·표 구조·호출 방식·공통 정책을 다룹니다.
계약 설명의 의미와 교육 품질은 독립 검수 및 실제 스킬 실행으로 확인합니다.
