# 검증 강조·장면별 판정·형식 번호 보강

기준은 `b483cdf`다. 리치 텍스트 편집기 검증에서 제공된 관찰과 현재 정본을 대조했다.
직접 `outline`만 허용하던 지침에는 외부 스타일 변경을 되돌리는 편집 영역의 대안이 없었고,
`results.md`의 간결한 요약도 실제 열을 지정하지 않았다. 실행 환경별 일반화를 피하기 위해
프레임워크가 외부 변경을 되돌리는 조건에만 실행 소유 `head style`을 적용한다.
일반 요소의 직접 강조, `body absolute` 라벨, 분리 좌표 오버레이 금지는 유지한다.

강조와 라벨은 최종 이미지에서 확인해야 한다. 빠지거나 잘린 촬영은 실패로 보존하고 다시
촬영한다. 화면 밖인 대상은 해당 시각 기준의 근거가 될 수 없다. 대상과 라벨이 한 화면보다
큰 경우 검증된 높이 확장과 일반 촬영을 우선하지만, 높이 단위·가상화·스크롤 동작 등의 기존
전제조건은 유지한다. 수정 전후 공통 크기와 원상 복구도 그대로 요구한다.

웹과 네이티브 결과는 장면별 수정 전 관찰값·수정 후 관찰값·판정을 표로 보여 주고 같은
단계의 관찰값 문구를 라벨로 쓴다. 네이티브는 실제 앱·접근성·런타임 관찰을 사용하며 존재하지
않는 `DOM` 측정값을 만들지 않는다. 실제 회귀나 근거 부족을 세 가지 정상 분류에 억지로
넣지 않도록 `regression/unverifiable`도 보존하고, 기준별 `Pass/Fail/Blocked/Unverifiable`는
변경하지 않았다. `annotation`은 대상 강조선의 상태이며 유지·등장·제거에서 강조 대상이
없는 경우를 구분한다. 단계 라벨은 별도로 실제 이미지에서 확인하고 촬영용 변경에 기록한다.

필수 `README.md`가 유일한 Markdown 인덱스다. 파생 갤러리·연락판은 대체물이 아니며 원본
검토를 유지한다. 경로를 반환하고 사용자 브라우저나 데스크톱 열기는 명시적 요청에만 한다.
실행 소유 헤드리스 검증과 명시적 열기 요청은 기존 권한·포커스 경계에서 계속 가능하다.

설명 형식에 `F1`-`F9` 고정 번호를 추가했다. 제안의 `F1`-`F7`을 유지하고 기존 형식인
`#27` 재생과 `#30` 스레드에 `F8/F9`를 부여했다. 호환성 필터 뒤에도 번호를 재배정하지
않으며 번호 단독 응답을 받는다. 기법 `01`-`30`, `A`, `P1`-`P4` 및 요청 전용 지위와
기존 이름·번호 별칭은 유지한다. 형식 하나를 정했다고 미정 스타일까지 위임받지 않는다.

추가 문장은 각각 편집기 전용 대안, 누락 촬영 실패, 안전한 범위 선택, 장면별 관찰값 대응,
파생 보기의 한계, 자동 열기 방지, 형식 번호 입력이라는 누락된 행동을 소유한다. 삭제하면
기존 실패가 다시 허용되거나 선택 번호가 모호해진다. 기존 상시 본문에는 중복 지시를
추가하지 않고 이미 읽기가 필수인 조건부 참조에만 둔다.

회귀 평가 9개를 추가했다. 실제 브라우저 실험은 외부 스타일 변경을 되돌리는 합성 편집
영역의 문단·목록·표와 고정 사이드바를 사용한다. 실제 `ProseMirror` 제품이나 네이티브 앱을
실행한 시험은 아니며, 네이티브 제공자별 주석 구현과 제품별 높이 의존성은 각 검증 시 확인한다.
제공된 사건의 프레임워크 재렌더링 원인은 가설로 남기고 조건 자체에 대한 교정을 검증한다.
새 실행 도구·설치·전역 설정·상태 형식은 추가하지 않았다.

공개 카탈로그 설명과 호출 방식이 바뀌지 않아 `README` 수정은 없다.
