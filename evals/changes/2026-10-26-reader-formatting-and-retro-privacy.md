# 설명 문서 서식과 회고 첨부물 검증

첨부 개선안에서 확인한 문서 서식 공백과 익명화 검사 범위를 보강합니다.
기존 문장 의미 보존·오프라인 HTML·회고 제안 전용 권한은 유지합니다.

- tk-explain의 문서 서식 참조를 추가하고 기존 HTML 소유자에게 일반 파일로 동기화합니다.
  조건부 포인터를 통해 설명 산문의 밀도·강조·보조 제목·그림 경계를 선택할 때 읽습니다.
  필수 경고, 테스트 UI, 검증 결과의 별도 구조는 각 소유자가 우선합니다.
- 참고문헌은 제목과 메타정보의 논리적 두 행을 기본으로 합니다. 긴 제목은 자연스럽게
  줄바꿈하며 출처 연결을 생략하지 않습니다. 기존 한 줄 배치 결정을 재검토한 변경입니다.
  연구 보고서의 인용·복귀 링크 검사 계약은 유지합니다.
- 그림 묶음의 자식에 `min-width: 0`을 적용하고, 선택형 그림 프레임을 제공합니다.
  기존 그림의 최소 폭 가설은 `360px` 브라우저 전후 비교로 검증합니다.
- tk-retro는 요청받은 첨부물만 검증 수준·근거를 포함한 매니페스트와 ZIP으로 전달합니다.
  기본 파일은 이슈 초안 하나이며, 별도 회고 보고서는 만들지 않습니다.
  모든 재사용 파일과 예시에는 식별자·원문·독립 익명화 검사를 적용합니다.
  검사 원문을 출력하지 않는 표준 라이브러리 도구를 추가합니다.

`README: no public change`: `skills/tk-explain/SKILL.md`와 `skills/tk-retro/SKILL.md`의
내부 실행 계약만 변경하며 이름·호출·카탈로그 설명·설치 방법은 유지합니다.

기준 대비: 이전에는 서식의 강약과 보조 절 분류를 판단할 참조가 없고, 식별자가 없는
원문 복제를 기계적으로 검사할 도구가 없었습니다. 새 조건부 참조가 두 판단을 소유합니다.
상시 추가 문장은 조건 분기와 필수 파일 검사를 연결하는 포인터이며, 이 포인터를 제거하면
기존 호출자가 새 참조와 실행 도구에 도달하지 못합니다. 기존 `clear-writing` 규칙은 복제하지 않습니다.
