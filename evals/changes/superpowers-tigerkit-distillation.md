# `Superpowers` 증류 시드 반영

출처는 `obra/superpowers`의 `v7.0.0`, `v6.4.2`, `v6.4.1` 릴리스입니다. 전체 이식이 아니라 필요한 차이만 반영했습니다.

## 채택 / 변형 / 제외

- **변형 — `brainstorming`, v7.0.0:** 보고된 증상과 의도한 결과·사용 장면을 구분하고, 중요한 의도 추론을 표시합니다. 이를 `tk-prep`의 간결한 규칙 하나로 추가했습니다. 결과가 분명할 때 인터뷰·요약·추가 확인 단계를 강제하지 않는 기존 `frontier` 정책을 유지합니다.
- **채택 — `writing plans`, v6.4.2:** 결정 중심 계획, 구체적인 테스트·`assertion`과 통과 조건, 확인 가능한 작업 결과는 이미 `tk-prep`의 `Seed` 및 `SDD` 참조에 있습니다. 중복 규칙은 추가하지 않았습니다.
- **채택 — `evidence-based diagnosis`, v6.4.1:** `tk-retro`가 근거·가설·누락 근거를 이미 구분하므로 변경하지 않았습니다.
- **제외 — `Builder Check`:** 기존 준비도 판단, `SDD` 사전 점검, 독립 구현 검수가 관련 경계를 다룹니다. 상시 추가 검수자나 에이전트가 필요한 공백은 시드에서 확인되지 않았습니다.
- **제외 — `visual companion`:** 시각적 탐색은 기존 `tk-prototype`의 책임이며, 시드도 `companion`을 구현 계약이 아닌 참고 자료로 취급합니다.

## 검증 목표

새 `prep-distinguishes-symptom-from-intended-result` `eval`은 `tk-prep`이 제공된 근거에 해석을 연결하고, 중요한 의도 추론을 표시하며, 미해결 범위 결정만 질문하는지 확인합니다. 추가 확인 단계와 구현 금지 경계도 보존합니다.

README 공개 카탈로그 변경은 없습니다.
