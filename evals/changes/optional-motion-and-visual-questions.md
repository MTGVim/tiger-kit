# 시각적 질문과 선택형 미디어

화면 배치 질문은 `tk-grill`, `tk-prep`, `tk-roadmap`에서만 와이어프레임 HTML을 추가합니다.
번호별 텍스트·추천과 질문 안의 절대 링크를 유지하며, 시각적 선택이 없으면 파일을 만들지 않습니다.
`tk-grill` 산출물 예외와 생성기·참조를 함께 바꿨고 공통 `questions.md`는 바꾸지 않았습니다.

`tk-browser-verify`는 승인된 선택 또는 저장소 `evidenceMedia` 설정에서만 미디어 분기를 읽습니다.
필수 스크린샷·비교 쌍과 실제 시간 `assertion`은 기존 계약을 유지합니다. 연속 캡처는 현재 제공자가
지원할 때 같은 실행에서만 공유하며, 지원하지 않으면 미디어만 생략합니다. 캡처 타임스탬프를 보존하고
`assertion` 시점 스크린샷을 가까운 영상 프레임으로 대체하지 않습니다.

짧은 흐름의 GIF는 기존 `enthus-appdev/gh-attach@v0.7.0`을 사용하며 전체 소스 `commit` 고정은
앞선 변경을 보존합니다. 5`MiB`는 목표이고, 프레임 축소·초과·변경된 재생 시간 경고를 보존합니다.
고정 버전에서는 JSON 경고 누락 때문에 `stdout`과 `stderr`를 분리해 사용합니다. 출처는
[고정 구현](https://github.com/enthus-appdev/gh-attach/blob/663d13d6e42b98eadf6f1d9a517813b8a0f4eaf1/internal/cli/gif.go)과
[#34](https://github.com/enthus-appdev/gh-attach/pull/34)입니다. 미출시 수정과 새 포크는 도입하지 않았습니다.
게시 없이 GIF 생성만 선택한 경우에는 설치된 `ffmpeg`로 로컬 파일을 만듭니다. 준비된 GIF는 다시
조립하지 않고 이미지로 올리며, 확장의 `--gif` 조립·업로드 경로는 게시가 선택된 경우에만 씁니다.

MP4 조립기는 실제 타임스탬프, 자막과 선택 오디오만 소비하고 설치나 음성 엔진을 불러오지 않습니다.
`H`.264 10`fps`와 선택 AAC 모노 48`kbps`를 사용합니다. 기본 스크린샷 증거를 유지하고 미디어 실패를 별도로 보고합니다.
`tk-pr-image`는 영상 첨부와 함께 `tk-pr-media`로 바꾸며 별칭을 남기지 않습니다. 기본 이미지 경로와
영상 native `gh pr edit --attach` 경로를 구분하고, native 첨부에 확장 전용 업로드 `ref`를 요구하지 않습니다.
전체 영상 통과에는 실제 플레이어 재생 확인이 필요하며, 게시 선택 없이 자동 업로드하지 않습니다.

README의 공개 카탈로그와 `MIGRATION.md`를 갱신합니다. 기존 이미지 평가와 카탈로그는 명시적 이름 변경
및 경로 문자열 평가 이전으로 보존합니다. 형식 선택·파일 없음·도구 없음·타이밍 근거·경고·재생 미확인·게시 권한
경계를 새 평가로 보호합니다. 실제 원격 PR 첨부는 별도 대상이 승인되지 않았으므로 이 변경의 실험에 포함하지 않습니다.

같은 10초 프레임으로 로컬 GIF와 자막·음성 MP4를 생성하고 전체 디코딩·길이·형식을 확인했습니다.
이는 조립기 실험이며 확장 업로드나 PR 플레이어의 실제 재생을 증명하지 않습니다.
