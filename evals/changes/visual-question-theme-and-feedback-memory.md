## 근거와 선택

새 외부 테마를 도입하지 않습니다. 최신 내부 원천인 `tk-explain`의 `assets/html-theme.css`, `assets/html-theme.js`, `references/html-output.md`와 기존 블라인드 갤러리의 인라인 구현을 변경 전에 읽었습니다. 테마 전환과 저장 거부를 다루는 기존 `evals/skills/tk-explain/theme.test.cjs`를 재사용하며, 이번 세 질문 패키지의 실제 배포 스크립트도 실행하도록 확장했습니다.

- keep: 기존 공용 테마의 토큰·마크업·전환 방식, 외부 리소스 없는 단일 파일, 질문 카드 선택·진행률·답변 복사·수동 복사 대안·저장 거부 대응을 유지합니다. 블라인드 갤러리는 수정하지 않습니다.
- adapt: 세 질문 패키지에 공용 CSS·JavaScript만 복제 배포하고 기존 동기화 도구가 누락·변형을 검사하게 합니다. 정본 `visual-questions.md`에 인라인과 상단 테마 컨트롤의 실제 마크업 계약을 추가하고 세 패키지에 동기화합니다.
- omit: 설명 자료 전체의 문서·차트·코드 강조 도구를 질문 패키지에 복제하지 않습니다. 새 질문 생성기·별도 테마·지속 회고 메모리도 만들지 않습니다.

공용 `tigerkit:skill-feedback` 블록의 최소 근거 보관 위치를 현재 대화로 명시하고, 요청 없는 지속 메모리 저장을 금지합니다. 명시적인 기억 요청과 기존 담당자의 권한·비밀정보 경계는 유지합니다. 원래 세션의 메모리는 이미 삭제됐다는 사용자 근거만 있으며, 이번 작업에서 개인 메모리를 조회·작성·삭제하지 않았습니다.
