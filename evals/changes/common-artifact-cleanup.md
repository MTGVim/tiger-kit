# 공통 파일 정리 규칙을 스킬 본문에 유지

코스 저작 중 압축 해제를 위해 빈 실행 소유 폴더에 진입한 뒤 불필요한 `rm -rf *`를
사용했다는 구체적인 제보를 최신 `18dd564c`의 공통 생성 원본과 대조했습니다.
세부 참조에는 이미 작업 경로·리터럴 절대 경로 규칙이 있지만, 위임받은 작업자가
스킬 본문만 읽는 상황에서는 이 규칙을 확인할 수 없었습니다.

- 적용: `scripts/artifact_policy.py`가 소유한 공통 문장을 모든 `Artifact Paths`
  블록에 생성합니다. 새 폴더를 우선하고 승인된 정리에는 지원되는 휴지통 기능을
  우선하며, 삭제·이동 모두 기록된 실행 소유 리터럴 절대 경로만 대상으로 합니다.
- 유지: 비밀 정보는 휴지통 우선 대상에서 제외하여 기존 일회성 비밀 폐기 계약을
  유지합니다. 읽기 전용 스킬에 새 정리 권한을 주지 않으며, 상세 참조와 조건부
  열람 구조, 기존 자원 수명 및 도구 소유 임시 공간은 그대로 유지합니다.
- 공통 블록 추가로 기존 스킬 3개가 본문 길이 제한을 넘겨, 기존 안내의 중복 표현을
  함께 줄였습니다. 작성 권한, 선행 참조, 해시·재열람, 매번 수행할 경로 검사,
  기본·명시 경로, 대화 전용 분기와 게시 권한 경계는 유지합니다.
- 제외: 전역 `rm` 별칭, 휴지통 도구 설치·의존성, 새 정리 실행기, 개별 스킬별
  예외 목록, 기존 사용자 파일의 임의 삭제·이동입니다.

상세 참조를 제공하지 않는 압축 해제 사례와 휴지통 가용·비가용 조건을 평가에 추가합니다.
공통 문장을 삭제하면 본문만 읽는 경로에서 삭제 규칙이 다시 누락됩니다. 기존 동기화
검사가 모든 패키지의 공통 블록 일치를 검사하며, 실제 모델 행동 실험은 실행하지 않습니다.

파트 1의 과정 계획 원문·상태·재개·내부 링크·배포 제외는 `18dd564c`에 이미 반영되어
있음을 확인했습니다. 중복 계획 형식이나 별도 갱신 규칙은 추가하지 않습니다.
