# 코스의 도표·도입·강의 흐름 개선

2026-10-23 사용자 추가 요청을 기존 슬롯·강조·탐색기 미리보기와 대조했습니다.
장기 계획 보존과 공통 삭제 규칙은 이전 반영을 유지합니다.

- `bar`·`line`·`stacked`는 `visual.data`의 유한한 숫자와 명시적인 단위·축·출처를 검증합니다.
  수치에 맞는 좌표, 0 기준 막대, 실제 간격의 `x`축, 실측과 구분한 기준선, 원본 데이터 표를
  오프라인 SVG로 제공합니다. 데이터마다 큐가 연결되지 않으면 출력 전에 거부합니다.
- `output`은 출력·로그·스택의 원문과 줄 번호를 유지합니다. `code`·`timeline`은 줄·사건별
  강조로 일반화하고 기존 강조 이름을 별칭으로 보존합니다. 넘친 텍스트는 의미 단위로
  나누도록 거부하며, 좁은 화면의 시각적 줄바꿈은 원문을 바꾸지 않습니다.
- 도입 카드 전체를 의미 단위로 강조하고 공개 전에는 흐리게 남깁니다. 빈 첫 큐는 전체를
  보여 줍니다. `hook`은 1-4장과 긴 값을 지원합니다. `preview_slide`의 실제 참조 검증과
  문서화로 코스별 미리보기를 선택하며 형제 코스의 도입과 설명 첫 문장을 대조합니다.
- `cover`·`course-map`·`summary`와 강의 플롯 지침을 추가합니다. 인사·강의 번호·이전 내용
  연결·목표·판단/실습·정리·예고를 점검하고 기존 자료의 끝 역할 누락과 반복 도입은 경고로
  남깁니다. 지도상의 이전 강의 표시는 학습자의 숙련·완료 기록을 추정하지 않습니다.
- 긴 수치 라벨과 원문을 위한 세로 배치를 따로 그리고, 자막은 도표 아래에 둡니다.
  실제 브라우저에서 두 테마·세 폭과 모든 큐를 검사합니다. 원본과 화면의 수치를 대조하며
  화면 확인을 음성의 발음·자연스러움 검사로 확대하지 않습니다.
- 마지막 추가 요청에 따라 비용 절감과 품질 보존을 함께 기대할 수 있는 독립된 자료 대조,
  강의 초안·검증에는 위임을 허용합니다. 공통 결정과 참고 문서를 전달하고 파일 소유를
  분리하며 주 작업자가 연결·통합·최종 검증을 검토합니다. 고정 모델명이나 제공자 체계는
  코스에 저장하지 않고, 조정 비용이 큰 일은 직접 처리합니다.

근거와 선택:

- 기존 `references/chart-design.md`와 `assets/chart-examples.html`의 질문별 표현 선택,
  공통 척도·출처·원본 표·테마 토큰을 적용합니다. 단일 파일 계약을 유지하며 외부 실행
  의존성이나 차트 라이브러리는 추가하지 않습니다.
- `reveal.js`의 공개 차트 플러그인과 `Slidev`의 도식 문법은 표현 선택의 선행 사례로만
  검토했습니다. 외부 코드·스타일·자료나 실행기를 복제하지 않습니다.
  https://github.com/rajgoel/reveal.js-plugins/blob/master/chart/README.md , https://sli.dev/guide/syntax .
- 교수 설계 지침은 계획 점검표로 적용합니다. `NIU`의 `Gagné` 안내는 순서 설계 근거이며,
  `Guo` 등의 논문은 관찰된 시청 참여와 제작 특성의 관계를 다룹니다. 학습 효과나 인과
  보장으로 확대하지 않습니다. 개인화 원리 링크는 사용자가 제공한 2차 요약임을 구분합니다.
  https://www.niu.edu/citl/resources/guides/instructional-guide/gagnes-nine-events-of-instruction.shtml
  https://up.csail.mit.edu/other-pubs/las2014-pguo-engagement.pdf
  https://pressbooks.pub/elearning2020/chapter/the-personalization-principle

정적 검사·실제 빌드·수치 및 별칭 회귀 검사·실제 `headless` `Chromium`의 화면/강조 검사를
구분합니다. 강의 플롯의 교육적 적절성과 새 문장의 발음·음질은 기계 검사만으로 보장하지
않으며 저작 검토와 실제 실청을 남깁니다. 모델 행동 평가 항목은 계약 회귀용 시나리오이며
실제 모델을 실행한 평가라고 보고하지 않습니다.
