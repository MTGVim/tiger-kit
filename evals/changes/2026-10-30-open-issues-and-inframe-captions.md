# 열린 이슈와 화면 안 자막 수정

## 변경 범위

- `#487`: 기존 실행 형태 선택 참조에서 다중 `PR`일 때만 안전성 참조를 읽습니다.
  공유 산출물의 단일 생성 책임, 전체 `Unit`별 유일 `PR` 그룹, 후속·범위 밖 제한 검사의
  선행 노출 방지, 독립 병합 순서와 실제 발행 인계의 정합성을 확인합니다.
  기존 `SDD` 헤더 문법과 단일 `PR` 경로는 유지합니다. 패키지 사본은 기존 동기화 도구가 소유합니다.
- `#488`: `tk-skill-vet`는 외부 패키지의 숨은 지시·동봉 코드·설정·설치 명령과
  업데이트를 정적으로 검토합니다. 실행·설치·실제 비밀 접근·외부 분석 전송은 하지 않습니다.
  정상 주석·로컬 읽기 전용 `helper`·보안 교육 인용을 악성으로 오인하지 않는 대조를 포함합니다.
  `README`에는 새 스킬 한 줄만 추가합니다.
- `#489`: 기존 `tk-rewrite`와 독자 평가, 말투 보존 평가를 대조했습니다. 기존 계약으로
  다룰 수 있어 실행 지침은 변경하지 않습니다. 비의도적 종결형 획일화, 명시적 공식체 통일,
  친근한 내부 공지, 이미 균일한 정상 원문을 자체 한국어 사례로 추가합니다.
  어미 다양성·길이·비율을 품질 목표로 삼지 않습니다.
- `#491`: 애니메이션의 하드 자막 선택만으로 하단 띠를 추가하지 않습니다.
  배치 미지정 시 기존 `overlay-rounded`를 사용하며 원래 화면 크기를 유지합니다.
  명시적 `band`, 선택형·무자막, `UI` 증거 캡처는 보존합니다.

## 검증 설계와 관찰

- 새 행동 사례 23개, 신규 스킬의 호출 사례 18개와 카탈로그 경계 3개를 추가했습니다.
- 독립 실행자가 기대값을 보지 않고 새 보안 사례 11개와 한국어 재작성 사례 4개의
  실제 출력을 반환했습니다. 정상 사례의 오탐을 확인했으며, 두 초기 악성 `fixture`에는
  호출 경로가 빠져 있어 입력에 진입점·함수 정의를 명시한 뒤 관련 3개를 다시 실행했습니다.
  판정 규칙을 완화하지 않았습니다. 다중 `PR` 계획·인계 사례 7개도 기대값을 가린 실제 출력과 대조했습니다. 정적 자료만으로 실제 실행 결과를 보장하지 않습니다.
- 자막 회귀는 수정 전 `128×144`와 추가 띠 `48px`로 실패했고, 수정 후
  `128×96`과 추가 띠 `0px`로 통과했습니다. 기존 `libass` 지원 `Docker`에서 영상 검사 11개가 통과했습니다.
- 동기화·`SDD` 경계의 집중 검사 26개가 통과했습니다. 전체 릴리즈 검사와 독립 검수 결과는
  해당 후보 커밋에 묶인 무시된 실행 근거 및 이슈 댓글에서 확인합니다.
- 이 검증은 저장소의 전체 호스트별 행동 벤치마크나 모든 모델의 보안 성능을 뜻하지 않습니다.
  새 상시 규칙 대신 기존 조건부 참조를 확장했으며, 각 신규 조건은 대응하는 실패·정상 사례와 대조합니다.

상류 고정 `revision`, `keep | adapt | omit`과 `MIT` 고지는 `NOTICE.md` 및 해당 패키지에서 관리합니다.
