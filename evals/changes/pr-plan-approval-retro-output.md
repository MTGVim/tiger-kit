## 계약과 검증

- 기존 회고 평가 8건은 삭제하지 않고 사유가 명시된 개별 이전으로 새 출력에 맞췄습니다. 비밀정보 제외·권한·근거·선행 결정·초안 재사용 검증을 보존하며 상시 보고서 요구만 폐지했습니다.
- PR 계획 표, 한 건의 계획, 선택 항목을 포함한 단일 승인, 선택 항목만 답한 경우의 게시 금지, 명시적 선택 승인 재사용과 새 외부 이슈 초안의 단독 생성을 평가에 추가했습니다.
- 추가한 지시는 각각 기존 계약에서 빠진 관찰 가능 결과를 담당합니다. 표 지시를 빼면 첫 계획의 종류 열이 보장되지 않고, 선택지 지시를 빼면 종속 질문이 분리되며, 선택 답변 경계를 빼면 부분 답변에서 게시 승인을 추론할 여지가 생깁니다. 세션 요약 지시는 보고서 폐지 후 관찰 순서를 대화에 보존합니다. 기존 중복 보고서 본문과 형식 참조는 제거했습니다.
