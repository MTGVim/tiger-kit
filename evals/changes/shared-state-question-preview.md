# 공유 상태 보호, 질문 시작 경계와 PR 승인 미리보기

## 근거와 소유 범위

사용자가 제공한 데스크톱 앱 세션 회고의 세 개선안을 구현했습니다. 원 세션 로그와 사용자
클립보드는 조사하지 않았습니다. 사건 관찰은 사용자 제공 근거이며, 최신 기준 커밋
`1ed77999c60bee8b7e4ad60d191be11089de4a37`에서 질문 시작 제목과 미리보기 형식 및
클립보드 보호 절차가 명시되지 않은 점은 저장소 원문으로 대조했습니다.
이 구체적인 실패 사례와 해당 계약의 빈칸을 증류 근거로 사용하며 외부 구현을 복사하지 않습니다.

- 공용 질문 원본은 `scripts/question_policy.py`와 `skills/tk-grill/references/questions.md`입니다.
  28개 패키지의 예시·실행 블록은 동기화 도구로 재생성합니다.
- 공유 상태 절차는 브라우저 검증 패키지의 `references/verification.md`가 소유합니다.
  앱 패키지는 기존 동기화 계약으로 같은 바이트를 받고, 앱 상호작용 절과 브라우저 동작·안전
  참조가 해당 절차를 연결합니다. 새 OS별 클립보드 실행 도구는 만들지 않습니다.
- PR 미리보기 형식은 `tk-pr-open`의 승인 패킷 절이 소유합니다. 게시 원문과 파일 보존 정책은
  유지합니다. 공개 동작을 설명하는 README도 함께 갱신했습니다.

## 검증

질문 예시 회귀 6개는 단일·복수 질문과 한국어 제목, 시작 제목 누락, 구분선으로 제목 대체,
구분선 양쪽 빈 줄 누락을 검사합니다. 잘못된 원본을 모든 사본에 똑같이 동기화해도 실패하는지,
동기화 재실행이 멱등이고 인접 내용이 보존되는지도 확인합니다.

독립 에이전트에 수정된 스킬과 가상 입력만 제공하여 6개 대화 전용 응답을 확인했습니다.

| 입력 | 관찰한 응답 |
| --- | --- |
| 부분 클립보드 읽기와 복사·내보내기·알림·접기 대조군 | 부작용을 확인한 접기를 추천하고 부분 읽기를 백업으로 인정하지 않았습니다. |
| 텍스트·서식이 있는 클립보드와 텍스트 전용 도구 | 서식 보존 한계를 먼저 밝히고 일반 검증 승인을 손실 승인으로 확대하지 않았습니다. |
| 한국어 단일 질문 | `## 질문`으로 시작하고 질문 뒤에 새 계획을 붙이지 않았습니다. |
| 절·체크리스트·주석과 전후 이미지 표가 있는 PR 미리보기 | 굵은 절 라벨·항목·이미지 배치 한 줄 요약을 사용하고 코드 펜스와 원시 표를 내보내지 않았습니다. |
| 전체 백업 후 복원 실패 | 전체 성공을 선언하지 않고 보호된 백업을 복구용으로 유지했습니다. |
| 복원 후 바이트·타입 일치 확인 | 해당 기준의 성공과 검증 완료 후 백업 제거를 구분해 설명했습니다. |

이는 정책 판단과 응답 형식 확인입니다. 사용자 공유 상태를 변경하지 않았고 운영체제별 전체
타입 백업·복원 도구나 중단 복구를 실행 검증했다고 주장하지 않습니다. 이전 스킬과의 통계적
성능 비교 또는 모든 모델·호스트에서의 재발 방지 보장은 하지 않습니다.

새 행동 평가 9개는 두 검증 표면의 기본 대조군·제한된 백업·복원 실패, 단일·복수 질문 제목,
PR 미리보기와 원문 보존을 보호합니다. 기준 커밋의 기존 앱 배경 스크롤 평가 한 건에는
필수 기계 검사가 빠져 있어 `git_head_unchanged`만 추가했습니다. 기존 입력·판정과 안전 조건은
그대로 유지하며 기존 평가를 삭제하거나 포괄적으로 교체하지 않습니다.

필수 구조·문서·카탈로그·링크 검사와 두 버전 설치 목록 검사가 통과했습니다. 전체 Python
검사 256개 중 255개가 통과하고 운영체제 조건의 1개가 건너뛰어졌으며, PR 분류 검사 31개가
통과했습니다. 최종 릴리즈 판정은 커밋된 후보에 실행하는 로컬 릴리즈 게이트 결과로 결정합니다.
