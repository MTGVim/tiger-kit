# MP4의 명시적인 화질 설정

작은 UI 글자를 위한 MP4 화질 개선 요청을 기존 `libx264` 조립 경로에 반영합니다.
기존에는 화질 인자를 전달하지 않아 라이브러리의 기본값을 사용했습니다.

- MP4는 `CRF 18`을 기본으로 전달하고 MP4 전용 `--crf 0-51` 정수 옵션을 제공합니다.
  잘못된 값과 GIF에 대한 명시적 지정은 출력을 만들기 전에 거부합니다.
- 결과에는 `encoder`, 요청한 `crf`, 실제 인코딩된 `width`, `height`, `pixel_format`을
  반환합니다. 화질 설정값과 실측 화질을 구분하며 무손실을 보장하지 않습니다.
  기존 `yuv420p`의 색차 축소는 유지하므로 작은 유색 글자에는 여전히 손실이 있을 수 있습니다.
- 캡처 담당자는 승인된 뷰포트 해상도의 PNG를 텍스트 UI에 우선합니다. 해상도를 낮추려면
  선택된 조건이 있어야 하며, 이미 제공된 JPEG를 다시 변환하거나 원본 크기를 임의로 늘리지 않습니다.
  조립기는 기존 짝수 크기 패딩·자막 영역만 추가하고 자동 크기 변경을 도입하지 않습니다.
- 유지: `H.264` 호환성, 기존 GIF 기본값, 관찰 시간, 음성·자막·출처 검사와 설치·게시 경계.
  적용: 명시적 품질값과 결과의 실제 크기 표시. 제외: 새 코덱, 하드웨어 인코더,
  품질 프리셋 관리자, 추가 의존성, 일괄 재인코딩.

## 공식 근거와 검증

[`FFmpeg` 공식 문서](https://ffmpeg.org/ffmpeg-codecs.html#libx264_002c-libx264rgb)의
`crf`·`preset` 계약과 최신 원격 소스
`3b3dc211fed40e7e4f627dffd6a4e221eb481880`의 `libavcodec/libx264.c`,
`tests/fate/enc_external.mak`을 확인했습니다. 화질값을 생략하면 기본 매개변수를 유지하고,
지정하면 `f_rf_constant`에 전달합니다. 상류 인코딩 평가가 반환하는 크기·픽셀 형식·시각을
참고하되 상류 테스트 실행기를 도입하지 않습니다. 공식 위키는 접근이 차단되어 근거로 쓰지 않았습니다.

로컬 `ffmpeg 6.1.1`에서 기본 `CRF 18`과 CLI로 지정한 `CRF 23`의 출력물을 실제
인코딩·디코딩합니다. 결정론적 흑백 세부 패턴에서 원본 대비 픽셀 오차가 감소하는지 확인하고,
원본 크기·코덱·픽셀 형식·GIF 기본값과 잘못된 옵션 거부를 회귀 검사합니다.
별도로 렌더링한 1280×720 텍스트 UI 샘플도 비교합니다. 합성된 시험 자료이며 실제 앱 캡처나
보편적인 가독성·품질 보장으로 취급하지 않습니다. 높은 화질 설정은 파일 크기를 늘릴 수 있습니다.
