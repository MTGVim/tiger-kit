# `tk-inquiry`와 `tk-pr-sweep` 브리핑 변경

## 공개 변경

- 외부 담당자 질문 초안 스킬 이름을 `tk-to-questionnaire`에서 `tk-inquiry`로 변경했습니다. 이전 이름 별칭은 제공하지 않으므로 문서와 자동 실행 설정의 호출명을 새 이름으로 바꿔야 합니다.
- 로그·코드·이슈·대화 기록을 조사해 경위를 재구성한 질문에는 관찰 문제, 출처를 밝힌 확인 사실과 추정, 유형별 확인 요청 및 해결에 필요한 증거를 조건부로 포함합니다. 단순 질문은 짧게 유지합니다.
- 슬랙, `GitHub`, `Jira`, 이메일, Markdown 문서별 서식 레퍼런스를 추가했습니다. `tk-inquiry`는 선택한 채널의 레퍼런스만 읽고, 확인된 자리표시자만 채웁니다.
- `tk-pr-sweep`은 사전 승인 브리핑에 저장소 조회 결과, 대기 항목, 승인 대상 표, 승인 질문 순서를 적용합니다. 승인 대상이 하나여도 표를 유지합니다.

## 계약 이전과 검증

- 행동 평가 계약은 `tk-inquiry`의 이전 이름을 `tk-to-questionnaire`로 기록합니다.
- 분류 평가 사례를 `questionnaire-other-stakeholder`에서 `inquiry-other-stakeholder`로 옮겼습니다. 기존 질문지 안전성 평가를 보존하고, 조사 기반 구성·단순 질문·`GitHub` 영구 링크·확인되지 않은 슬랙 멘션 및 `tk-pr-sweep` 브리핑 순서를 검증하는 사례를 추가했습니다.
- 슬랙, `GitHub`, `Jira`의 현재 공식 서식 문서를 확인했습니다. 각 채널 레퍼런스에 출처 URL을 포함했습니다.
