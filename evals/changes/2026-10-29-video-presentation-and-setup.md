# 영상 선택·슬라이드 작성·음성 설치 안내 보강

- `evidenceMedia`에 자막·강조·설명 카드·슬라이드 테마를 추가합니다. 기존 네 필드와 기본값은
  유지합니다. `tk-video`가 소유하는 공통 참조를 각 소비 패키지에 일반 파일로 동기화합니다.
- 부모·직접 호출 모두 첫 질문 라운드에서 누락된 선택과 기본값 저장 제안을 해결합니다. 이미
  확인된 선택과 저장 거절은 재질문하지 않으며 승인된 키만 원자적으로 병합하고 다시 읽습니다.
- `caption_style: none`은 자막 필터·트랙·SRT와 범위 검사만 끕니다. 선택한 음성, 누락·무음
  검사와 별도로 선택한 설명 카드·확대 검사는 유지합니다. 자막을 읽기 위한 정지 시간은 제외합니다.
- 설명 페이지를 영상용 슬라이드로 다시 작성하고, 라이트 기본 테마·슬라이드 안 강조·전체 문구
  점검을 적용합니다. 명시적인 선택과 실제 화면 캡처의 선택된 확대 동작은 유지합니다.
- 현재 TTS 선택지는 과거 평가로 숨기지 않습니다. 의존성 발견과 모델 준비 여부를 구분합니다.
  `ppaso` 용량은 약 406MB라는 사용자 측정 환경을 구분해 안내하고 하위 의존성 해시 미고정을 공개합니다.
  기존 핵심 패키지·모델 고정값은 바꾸지 않습니다.

`README: no public change`. 호출명·카탈로그 설명은 그대로이고, 각 스킬의 조건부 동작·설정 계약만
수정합니다. 기존 내레이션 선택 공통 블록은 변경하지 않았습니다.

지침 삭제 비교: 공통 선택 절차가 없으면 부모와 직접 호출에서 연출을 나중에 되묻습니다. 슬라이드 작성
지침이 없으면 문서 패널을 잘라 쓰고, 문구 점검이 없으면 종결되지 않은 설명문이 통과합니다. 전체 선택지와
설치 용량 안내가 없으면 과거 평가로 엔진을 숨기거나 모델 크기를 설치 크기로 잘못 전달합니다.
각 지침은 이 결정을 바꾸며, 세부 절차는 조건부 참조에만 둡니다. 추가한 판단형 평가는 명세이며 실제
모델 실행 결과는 아닙니다. 코드 회귀 검사는 실제 설치된 `FFmpeg`로 실행합니다.
