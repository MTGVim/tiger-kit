# 설명·학습 자료의 독립 내용 리뷰와 범위 확인

최신 첨부 요청에 따라 `tk-explain`, `tk-explain-diff`, `tk-teach`의 산출물 완료 절차를
작성 → 별도 내용 리뷰 → 수정 → 현재 저장본 재리뷰 → 통과로 정했다. 일반 채팅과 학습자
답변 피드백은 이 제작 절차를 시작하지 않는다. 리뷰어는 독자·목표·현재 파일·필요한 출처를
받으며 작성자가 의도한 설명으로 누락을 보충하지 않는다. 실행 불가나 차단 지적이 남으면
완료로 보고하지 않고 실제 학습자의 숙달도 추정하지 않는다.

세 스킬의 화면·동작 검증은 사용자가 명시적으로 요청할 때만 실행한다. HTML·SVG·상호작용·
공통 UI나 브라우저 가용성만으로 시작하지 않는다. 출처·정적 검사·독립 내용 리뷰는 유지하며
미요청 화면 검증은 완료 실패가 아니다. 다른 소유자의 UI 검증과 명시적으로 요청된 브라우저
검사의 안전·증거 계약은 유지한다. 기존 조립 평가 3건은 명시적 화면 검증 분기로 이관해
기존 검사를 보존하고 기본 분기 평가를 추가했다.

유형 식별과 공간 행동 수업은 실제 구별 입력, 출발점·목적지와 첫 동작의 근거를 가르친다.
요약표의 이름만으로 범위를 채우지 않고, 문제의 정확한 시작 상태는 해설 공개 전에 제공한다.
단순한 구조 식별·텍스트로 완결되는 문제·명시적인 복습표는 불필요한 경로와 그림을 강제하지
않는다. 이미 반영된 공통 인과 설명, 검증기 사전 점검과 간결한 참고문헌은 중복 확장하지 않았다.

정본 동기화·판정 사례·검사 실행은 구현 근거다. 별도 실행에서는 새 수업의 실제 독립 리뷰와
브라우저 미실행 보고를 받았고, 누락 자료의 별도 리뷰는 차단 문제 3건을 찾았다. 이는 제한된
사례의 근거이며 통제된 평균 개선 효과·실제 학습자 이해도·비용 절감률은 측정하지 않았다.

`README: no public change`: 호출 방식·카탈로그·기본 단일 HTML 형식은 바뀌지 않았다.

## 평가 입력과 한계

기존 내용 평가는 최종 응답만 채점기에 전달했다. 새 의미 평가에는 명시적 `artifact_paths`로
현재 파일과 필요한 JSON 원자료를 지정한다. 새 산출물 평가의 변경 경로 검사도 유지해
원자료나 다른 추적 파일을 바꾼 후보가 통과하지 못하게 한다. 실행기는 채점기가 원본을 바꾸기 전에 실제
UTF-8 바이트와 SHA-256을 복사해 `TK_EVAL_ARTIFACTS_FILE`의 보호된 임시 JSON으로 전달한다.
채점기는 그 파일을 데이터로 읽고 결과에 `artifact_sha256: {path: sha256}`을 반환해야 한다.
누락·잘못된 응답, 경로 이탈·심볼릭 링크·공유 파일·비문자 입력·`1 MiB` 초과 파일 또는 합계
`2 MiB` 초과 입력은 조용히 잘라 전달하지 않고 `Unverifiable`로 처리한다. 기존 응답 전용 평가
인터페이스는 유지한다. 이 명시적 확장은 기존 실행기 안에 있으며 별도 런타임은 추가하지 않는다.

파일 입력은 저장 내용과 목표의 대응을 판단하는 근거다. 해시 확인은 채점기의 내용 판단이나
독자의 이해도를 자동 증명하지 않는다. 기존 어댑터의 최종 응답·자기 보고 이벤트만으로는
실제 리뷰어 호출·재리뷰 순서·브라우저 미실행을 인증할 수 없다. 새 보고 상태 평가는 그 범위로
표현을 한정하고, 실제 제작 절차는 별도 실행과 현재 산출물을 읽은 독립 리뷰 근거로 구분한다.
