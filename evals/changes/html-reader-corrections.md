# HTML 공용 기능과 반복 수정 검토 범위

첨부된 2026-10-26 HTML 산출물 제안 P1~P10을 최신 공용 자산과 비교했다.
문서별 우회 코드는 그대로 옮기지 않고 아래 동작을 정본에서 수정했다.

| 요청 | 반영한 동작과 소유 위치 |
|---|---|
| P1 | 빌더가 미정의 `ht-*` 클래스를 경고한다. 표는 `.ht-table-scroll`, 코드는 `.ht-code`를 사용한다. |
| P2 | 코드 헤더에 라벨·복사·줄바꿈을 제공하고 함수·속성·타입·리터럴·구두점·중첩 템플릿 보간을 구분한다. 복사 시 마지막 줄바꿈도 보존한다. |
| P3 | 로컬 파일에서는 공유를 숨기고 다운로드는 유지한다. 다운로드 아이콘은 SVG로 표시한다. |
| P4 | 용어·목록 항목·인용 역링크와 명시적 미리보기 링크를 지원한다. 도착 강조는 스크롤 종료 후 해제하며 반복 이동·취소·감소된 모션을 처리한다. 외부 링크에 새 탭 표시와 접근 가능한 안내를 제공한다. |
| P5 | 리드 굵기를 400, 제목 굵기를 600으로 조정했다. 기존 `reader-formatting.md`에 장식 대신 의미를 드러내는 강조 원칙을 보강했다. |
| P6 | 첫 전달·주장/출처/결론/학습 내용의 실질적 변경·사용자 요청에 독립 검토를 수행한다. 의미가 보존되는 표현/UI 수정에서는 최신본의 재검토 생략을 밝힌다. 미해결 지적은 그대로 유지한다. |
| P7 | 짧은 도입과 선택지별 단점을 요약에 포함한다. 판단 조건이 없으면 권장안을 단정하지 않는다. 기존 수업 내용·인과 설명은 보존한다. |
| P8 | 공용 셸 위에 범위를 제한한 추가 층만 허용한다. 선택적으로 조립하는 `assets/reader-example.html`을 밀도·상호작용 예시로 추가했다. 사용자 수정 횟수는 대화 안에서만 관찰하며 새 영속 장부는 만들지 않는다. |
| P9 | 접근 가능한 허용된 읽기 전용 관찰을 먼저 확인하고 시각·환경·한계를 남긴다. 인증·쓰기·운영 조작 권한을 확대하지 않는다. |
| P10 | 선례의 관찰·출처의 일반 안내·작성자 제안을 단계별로 구분한다. 수행 주체나 방식이 다르면 동일 절차라고 표현하지 않는다. |

공용 자산은 기존 동기화 경로로 10개 패키지에, 빌더·하이라이터·HTML 참조와 예시는
7개 패키지에 배포한다. 패키지 독립성에 관한 ADR 0003을 유지한다. 코드·인용 세부 규칙은
해당 컴포넌트가 있을 때 읽는 `html-components.md`로 옮겼다. 규칙을 삭제하거나 예산 상한을
높이지 않고 일반 HTML 경로에서 불필요한 상세 로딩을 줄였다.

## 검증 근거와 한계

- Python 검사는 미정의 클래스 경고, 정상 클래스와 사용자 클래스 허용, 예시 조립,
  중첩 보간·불완전 문자열·여러 언어의 원문 보존을 다룬다.
- 로컬 `Chromium` 회귀는 라이트/다크, 1280/390 너비에서 코드·복사·줄바꿈, 툴팁,
  스크롤·연속 클릭·취소·감소된 모션, 외부 링크, 로컬 공유 숨김, 다운로드 유지,
  외부 요청 부재와 무자바스크립트 탐색을 확인한다. 복사 성공/거부는 브라우저 안의
  API 경계 대역으로 분기와 전달 바이트를 확인하며 운영체제 클립보드의 별도 인증은 아니다.
- 원래 공용 셸 회귀와 파일 재내보내기·ZIP 무결성 검사를 유지한다. 알려진 언어의
  하이라이트는 어휘적 보조이며 정규식·JSX 등의 완전한 구문 분석을 보장하지 않는다.
- 검토 재사용/재실행/미해결 지적, 선택지 균형, 관찰과 선례 구분 평가를 추가했다.
  이 판정 사례의 정적 등록과 계약 보존 검사는 실제 에이전트 실행을 증명하지 않는다.
  평균 토큰 절감, 사용자 수정 횟수 감소, 화면 낭독기 실사용과 실제 학습 효과는 측정하지 않았다.

상시 문장 삭제 비교: 관찰·선례 구분을 빼면 미확인을 그대로 남기거나 제안을 선례로
소개하는 사례가 구분되지 않는다. 검토 조건을 빼면 표현 수정에도 반복 검토하거나 미해결
지적을 재사용 통과시키는 양쪽 실패를 막지 못한다. 강조·단점 조건을 빼면 현재 예시의
균형을 일반 생성에 요구하지 못한다. 기존 밀도·인과·근거 규칙은 중복 추가하지 않았다.
이는 계약 수준의 비교이며 실측 비용 절감 실험으로 표현하지 않는다.

`README: no public change`. 호출 이름·카탈로그·설치 방식은 유지된다. 변경된 동작은
소유 스킬과 HTML 참조가 설명한다. 출처와 채택·조정·제외 판단은 `tk-explain`의 `sources.md`에 있다.

기존 카드·진단·참고문헌·좁은 화면 회귀 4건은 한글 글꼴을 포함한 개별 실행에서
약 112초에 모두 통과했다. 전체 검사 래퍼의 60초 제한으로 중단된 첫 실행은 보존했다.
필수 Python 단위 검사 384건은 기본 환경에서 통과했으며 선택 검사 3건은 별도 실행 여부와
구분했다. 새 기능·공용 셸 브라우저 검사는 별도 환경을 지정한 전체 검사에서 통과했다.
