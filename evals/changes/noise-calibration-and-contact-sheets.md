## 선택한 구현과 권한

`Contact Sheet`는 `tk-browser-verify`의 조건부 참조와 작은 패키지 로컬 도우미가 소유합니다.
`Pillow`는 Python 표준 라이브러리만으로 이미지 디코딩을 재구현하는 것보다 작고, `canvas`는
별도 브라우저 구동이 필요하며 외부 서비스는 불필요한 전송을 추가합니다. 기존 `Pillow`만
선택적으로 이용하고 없으면 시트만 생략합니다. 민감 화면, 외부 경로, `symlink`, 손상 이미지와
출력 충돌은 기존 증거를 보존한 채 거부합니다. 시트는 동일 README에만 매핑을 추가합니다.

`A/A`는 기존 `runner`의 명시적 `--calibrate-noise` 분기로 소유합니다. 일반 실행의 CLI 기본값과
출력 형태를 유지하며 진단 모드는 별도로 실행합니다. 소스 확인 공통 함수는 저장소 전용
`scripts/eval_source.py`로 두고, 설치된 스킬에 평가 런타임을 복제하지 않습니다. 호스트 선택
증명은 모델 응답에서 가져오지 않으며 기본 `adapter`의 `installed`는 `observed`가 아닙니다.

## 문구의 필요성과 대조 검토

새 상시 본문은 없습니다. 기존 `visual`/`results` 참조에 조건부 포인터만 추가했습니다.
포인터가 없으면 개요를 요청한 경로에서 원본별 확인과 별개인 시트 절차를 발견하지 못합니다.
포인터만 있고 원본 판정 경계가 없으면 축소판을 전체 판정으로 오인할 여지가 남습니다.
원본과 안전 경계는 새 참조에서도 유지합니다. 단일 캡처, 일반 HTML 생성, 시트 요청이 없는
기존 검증에는 추가 동작이 없습니다. 이는 저자의 삭제 전후 계약 대조이며 실제 모델 행동의
효과 실험을 대체하지 않습니다. `positive`/`negative` `eval`을 추가하고 기존 계약은 보존합니다.
