# 채팅 표 표시 규칙의 일반화

## 근거와 소유 범위

사용자가 제공한 세션 회고와 최신 업스트림 `MTGVim/tiger-kit`의 기준 커밋
`784aa75650870c9b99955feb8c1b72f32f34111e`를 대조했습니다. 선행 변경
`d2d2eae`의 `evals/changes/shared-state-question-preview.md`, `tk-pr-open`의
승인 패킷 절 및 기존 행동 평가를 확인했습니다. 호스트의 표시 메타데이터와 원 세션
로그는 확인하지 않았으며, 표가 원문으로 보인 원인은 단정하지 않습니다.

- `keep`: 기존 ASCII 번호 규칙, PR 승인 미리보기의 표·이미지 격자 한 줄 요약,
  게시 본문과 파일 산출물의 원문 보존 계약을 유지합니다.
- `adapt`: 회고에서 확인된 형식 선택 문제를 공통 `Output Notation`에 반영합니다.
  여러 행이 두 가지 이상의 비교 속성을 공유하면 좁은 GFM 표를 쓰고, 단순 나열은
  목록으로 표시합니다. 머리글·짧은 셀·약 4열 이하를 기본으로 삼으며 박스 문자,
  코드 펜스, 비어 있거나 형식만 갖춘 표를 사용하지 않습니다.
- `omit`: 표 일괄 금지, 일반 채팅의 강제 한 줄 요약, 개인 선호 메모리 수정,
  새로운 스킬과 렌더러 감지 기능은 추가하지 않습니다.

정본은 `scripts/sync_execution_protocol.py`의 `OUTPUT_NOTATION_BLOCK`입니다.
현재 29개 패키지의 `SKILL.md`를 생성 도구로 동기화하고 README와 AGENTS의 공통
출력 설명을 맞췄습니다. 설치된 스킬을 개별 수정하지 않습니다.

## 검증

서로 다른 새 에이전트에 수정된 스킬 경로와 입력만 전달하여 응답을 확인했습니다.
기대 형식이나 수정 의도는 전달하지 않았고 원격 작업·파일 변경은 금지했습니다.

| 입력 | 관찰한 응답 |
| --- | --- |
| 옵션 2개, 비용·복구·오프라인 지원 비교, 원문 표시 가능성 언급 | 옵션 이름을 포함한 4열 GFM 표로 모든 값을 보존했으며 박스 문자와 코드 펜스가 없었습니다. |
| 준비물 이름 3개만 나열 | 표나 추가 속성 없이 세 개의 불릿으로 출력했습니다. |
| 전후 이미지 표가 포함된 PR 승인 미리보기 | 이미지 쌍의 배치를 한 줄로 설명하고 표 원문과 코드 펜스를 출력하지 않았습니다. 빈 체크리스트·주석을 게시 본문에 보존한다고 명시했습니다. |

앞의 두 사례는 `tk-adhd` 평가에 추가했고 기존 `tk-pr-open`의
`pr-open-rendered-section-preview` 평가를 대조군으로 보존했습니다. 기존 동기화
검사는 누락·중복·변형된 블록과 멱등성 및 인접 지침 보존을 검사합니다.

이는 대화 출력에 대한 행동 검사이며 호스트 렌더링, 통계적 전후 성능 차이 또는 모든
모델에서의 재발 방지를 검증한 결과는 아닙니다. 필수 구조·설치·회귀 검사는 커밋된
후보를 대상으로 로컬 릴리즈 게이트에서 수행합니다.
