# `tk-course` 폐기

사용자의 명시적인 폐기 요청에 따라 `tk-course` 패키지, 전용 생성기·플레이어 검사와 평가 계약을 제거합니다. 카탈로그의 `course-complete-explicit`, `course-incremental-explicit`, `course-catalog-explicit`, `course-generic-no-auto`는 실제 폐기 목록에 기록합니다. 이름 변경이나 학습 기능의 포괄 계약 예외를 만들지 않습니다.

`tk-teach`의 사전 복습 전달 평가에서는 없어진 담당자만 다음 HTML 수업으로 바꾸고, 관찰된 답변·남은 불확실성·점수 추정 금지 조건을 유지합니다. 기존 HTML 수업과 다중 챕터 자료·학습 기록 보존, `tk-video`와 `tk-tts`의 독립 사용은 유지합니다. 코스 엔진을 다른 스킬로 이식하지 않으며 상세 재구성은 검토 단계입니다.

README: 폐기한 스킬의 행과 선택 안내를 제거합니다. 장기 결정의 근거와 절충은 `docs/adr/0001-retire-tk-course.md`에 기록합니다. 과거 변경 기록과 생성 산출물은 삭제하지 않습니다.
