# 영상 캡처·나레이션 및 사용자 기본값 개선

첨부 회고와 후속 합의의 F1/F2/F3/F4/F6 및 사용자 설정을 반영합니다. F5 공통 CDP 클라이언트와
프레임 합성 자막 대체 경로, 상주 TTS 서버는 추가하지 않습니다. 다른 스킬의 영상 제안 연결은 유지합니다.

- `tk-browser-verify`는 영상 전용 요청을 `phase: media-capture`로 처리합니다. 수용 기준을 임의로
  만들거나 판정하지 않고 실제 매니페스트, 최종 상태, 정리 사실을 반환합니다. 명시적 수용 검증과
  `headless`·인증·변경 권한·소유 자원 경계는 유지합니다.
- CDP 영상 프레임은 `Page.startScreencast`와 프레임별 수신 확인 응답를 사용하며 실제 시각과 정지 구간을 보존합니다.
  비변경 시나리오만 실측 음성 길이에 맞춰 재캡처할 수 있고, 조립기는 관찰된 `scenes.start_ms`에
  오디오를 배치합니다. 다음 장면/영상 끝을 넘는 음성과 전체 트랙의 혼용은 거부합니다.
- 설치된 `ffmpeg`의 자막 필터와 `Homebrew` `keg`를 탐지하고 명시 경로를 우선합니다. 선택 경로를 반환하며,
  UI 자막은 하단 띠에 배치합니다. 필터가 없으면 기존 SRT/소프트 자막을 보존하고 먼저 설치 안내를 묻습니다.
- `ppaso` 어댑터·매니페스트·전용 테스트를 삭제하고 선택적인 Qwen3 어댑터를 둡니다. `serena` 기본값과
  `sohee`만 제공하며 전용 캐시/`venv`와 고정 스냅샷을 재사용합니다. 실제 청취는 확인할 단어와 함께
  `human_action: listen`으로 남깁니다. 자동 ASR·설치·게시 권한을 추가하지 않습니다.
- `evidenceMedia`는 요청 > 저장소 개인 설정 > 사용자 설정 > 팀 설정 > 안전한 기본값으로 필드별
  병합합니다. 잘못된 객체는 거부하고 안전한 기본값을 씁니다. 설정이 없으면 기존 승인 요약 한 줄에서
  저장을 제안하고 별도 승인을 받았을 때만 원자적으로 병합·재확인합니다. 거절은 현재 대화에서만 기억합니다.
  공유 저장소 문서는 정본 `tk-audit/references/repository-context.md`와 생성 사본을 함께 갱신했습니다.

## 공식 근거와 증류

- `Qwen` 공식 코드 `QwenLM/Qwen3-TTS` HEAD `022e286b98fbec7e1e916cb940cdf532cd9f488e`의 README,
  `generate_custom_voice`와 로컬 로더를 확인했습니다. 실제 런타임 고정값은 `PyPI` `qwen-tts==0.1.1`의
  `wheel` SHA256 `11a290d8dabc7ef91a90c54478c8ab19b3edb1d85c0882313721892bdc4af15d`입니다.
  그 `wheel`의 로더·토크나이저 경로와 `0.6B`에서 `instruct`를 무시하는 분기를 직접 대조했습니다.
  유지: `CustomVoice` API/로컬 스냅샷. 적용: 두 음성·오프라인·승인된 캐시.
  제외: 복제·스타일 모델·웹 서버·저장소 포크.
- `Hugging Face` `Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice` `revision`
  `85e237c12c027371202489a0ec509ded67b5e4b5`의 작은 파일은 직접 받아 SHA256을 계산했고,
  두 `safetensors`는 공식 LFS 메타데이터의 SHA256을 고정했습니다. 이 작업에서 대용량 가중치를 받거나
  실제 추론을 수행한 것은 아닙니다. 설치 후 어댑터가 모든 파일 바이트를 스트리밍 검증합니다.
- `ChromeDevTools/devtools-protocol` `95b1af69d6a20161dc3558f8e38366b7fa7a27d1`의 `Page` 명세에서
  `startScreencast`, `screencastFrame`, `screencastFrameAck`와 영역 자르기 인자 부재를 확인했습니다.
  유지: 이벤트/수신 확인 응답/실측 시각. 적용: 기존 선택 제공자와 소유 캡처 경계. 제외: 새 CDP 클라이언트/레코더 의존성.

## 검증 범위

실제 `ffmpeg`로 MP4/GIF를 조립하고 디코드했습니다. 장면 사이의 무음과 각 음성 구간을 검사하며
겹침·영상 끝 초과를 거부합니다. 별도 테스트로 `keg` 탐지·명시 경로, 스냅샷 변조·추가 파일·심볼릭 링크,
무음 제거와 로컬 오프라인 로드 경계를 검사합니다. 후자는 추론 의존성을 대역으로 대체한 경계 검사입니다.
실제 Qwen3 음성 합성·사람의 청취와 CDP 실녹화는 이 환경에서 재실행하지 않았습니다.
기존 수용 검증과 나레이션 없는 조립 회귀는 보존합니다. 새 행동 평가는 tk-video 3건, tk-prep 4건입니다.

README의 브라우저 검증 카탈로그에 데모 캡처 분기를 반영했습니다. 상시 본문은 해당 분기를 선택하는
짧은 연결과 필수 경계만 추가하고 세부 절차는 조건부 참조에 유지했습니다.
