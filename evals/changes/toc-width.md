# 데스크톱 목차 너비와 본문 간격 보정

사용자 화면에서 목차는 좁고 본문까지의 빈 간격은 목차 폭만큼 컸다. 기준 커밋
`153f688e694179ca50802167b1ae2c2c3314e7fb`의 공통 CSS는 목차를 `12rem`으로
고정하고 본문을 최대 `68rem`으로 가운데 정렬한다. 넓은 화면에서는 왼쪽 여백이
늘어도 목차 너비가 유지돼 제목의 잦은 줄바꿈과 큰 내부 간격이 함께 발생한다.

목차는 남는 왼쪽 공간에 따라 최대 `24rem`까지 넓히고, 최대 폭에 도달하면 본문
가까이에 배치한다. 본문의 기존 폭과 가운데 정렬, 하단 정보와 모바일 목차 동작은
유지한다. 별도 라이브러리나 상류 코드를 추가하지 않고 기존 공통 CSS만 보정한다.

회귀 검사는 같은 본문·글꼴·뷰포트에서 기준 CSS와 후보 CSS를 각각 렌더링해 목차 폭,
본문까지의 간격과 줄 수를 비교한다. 본문·하단 정보의 좌표와 너비, 본문 글꼴·색상은
유지되는지도 확인한다. 기존 문서 셸 검사는 삭제된 지침 코드 예시 대신 실제 생성기로
시험 문서를 만들도록 복구해 화면 검증을 현재 산출물 경로에 연결한다.
