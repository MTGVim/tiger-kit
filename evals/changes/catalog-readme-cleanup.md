# 카탈로그 정리와 README 검증

공개 스킬을 30개에서 28개로 줄였습니다. 제거한 패키지의 설치 목록·호출 평가·공유 가드 소비자와
미사용 이슈 분류·작업 공간 설정 예시를 함께 제거합니다. 기본 브랜치에서 구현할 때 사용하는
`skills/tk-prep/references/local-execution.md`와 `tk-pr-sweep`의 사용자 설정·스크립트는 변경하지 않았습니다.
기존 공개 계약의 실제 폐기는 릴리즈의 명시적 폐기 목록으로 검증합니다.

README는 목적·설치·상황별 시작점·주제별 스킬 목록으로 구성하고 각 원문으로 직접 연결합니다.
릴리즈 게이트가 이미 실행하던 문서 검사를 보강하여 여러 주제 표의 스킬을 모두 집계하고,
연결된 스킬의 호출 방식과 링크가 정확한 소유자 파일을 가리키는지 확인합니다.
잘못된 호출 방식·링크와 주제별 표 누락에 대한 회귀 사례는 수정 전에 실패했고 수정 후 통과했습니다.
독립 검수에서 발견한 링크 누락과 인식되지 않는 스킬 표기 역시 실패하는 회귀 사례를 먼저 추가한 뒤
검사에서 차단했습니다. 문서 검사 모듈의 패키지 실행 `import`는 기존 실행 방식에 맞게 보완했습니다.
기존 QA 환경 영역 검사는 새 CSS 선언 하나 때문에 실패했으므로 줄바꿈·추가 선언과 무관하게
실제 줄바꿈 속성을 검사하도록 수정했습니다. 템플릿의 동작과 스타일은 변경하지 않았습니다.

공유 참조 동기화 과정에서 발견한 변경 설명 전용 시각 지침은 해당 스킬 본문으로 옮겼습니다.
공용 시각 문법 사본은 정본과 일치시키고, 변경된 노드와 관련된 미변경 노드를 구분하는 기존 지침은 유지합니다.
정적 게이트는 실제 호스트의 준비·승인 실행이나 학습 효과를 증명하지 않습니다.
