# 설명의 인과 전개와 공간 범위, 검증기 선행 점검

두 사용자 회고의 중복을 기존 소유자에 통합합니다. 공유 글쓰기는 장면, 주체의 행동, 결과의 이유를 설명한 뒤 추상적 구분을 제시하도록 다듬고, 지시 대상과 경로의 결과를 구체화합니다. 조건과 불확실성은 기제나 유용한 범위 설명에 남기며 안전 및 권한 경고를 보존합니다. 제목과 대기열 대조 예시는 기존 절에 둡니다.

`tk-explain`의 시각 계획은 질문에 필요한 서로 다른 공간 배치를 모두 표현하는지 확인합니다. 공유 주석 그림을 허용하고 비공간 속성 비교에 그림을 강제하지 않습니다. `tk-teach`는 상황의 시작부터 판단 결과까지 가르친 뒤 조건 하나를 바꾸어 다음 선택에 연결합니다. 명시적으로 요청한 짧은 복습표는 보존합니다.

원고와 그림 범위 및 명칭을 확정하고 정적 검사를 수행한 뒤 화면 검증을 시작합니다. 새 검증기는 구문, DOM 관찰, 필요한 실제 입력과 사후 상태 및 소유 자원 종료를 먼저 확인합니다. `Space` 통과와 `Enter` 실패의 검증 범위를 구분합니다. 검증기만 바뀌면 독립성이 입증된 동일 후보의 증거를 보존하고, 제품이나 관찰 조건이 바뀌면 해당 기준을 재검사합니다. 필요한 화면, 키보드, `no-JS` 및 `reduced-motion` 검사는 유지합니다.

참고문헌은 제목 링크, 필요한 기관/버전/날짜와 복귀 링크를 인라인으로 두고 자연스럽게 줄바꿈합니다. 내부 검토 메모는 출처 기록에, 독자에게 필요한 한계는 본문에 둡니다. 기존 보고서 생성기는 이미 이 구조를 사용하므로 동작을 중복 구현하지 않았습니다. 기존 `ReportParser`로 생성 결과의 블록 부재, 메타데이터 및 두 복귀 링크를 검사하며 기존 브라우저 회귀 파일에 넓은/좁은 화면 및 긴 제목 검사를 보강합니다.

`check_report.py`의 파서/트리와 기존 테스트를 확인했습니다. 해당 CLI는 연구 보고서의 정확한 스타일/스크립트 및 섹션 계약을 검사하므로 `tk-explain`/`tk-teach`에 그대로 실행하도록 안내하지 않습니다. 이번 변경에는 새 공통 검사기나 제공자 실행기가 필요하지 않습니다. 기존 정본 동기화만 사용하며 `AGENTS.md`, 설치본과 사용자 학습 자료는 수정하지 않습니다.

상류의 고정 리비전을 최신 HEAD와 대조하고 본문을 읽었습니다. 근거와 유지/적응/제외 판단은 `skills/tk-rewrite/references/sources.md`에 기록합니다. `korean-humanizer`의 평가 안내는 고정 예제가 모델 품질의 성공률을 측정하지 않음을 명시합니다. 이식한 지침의 효과나 자원 절감률을 상류 결과로 주장하지 않습니다.

## 추가 문구의 필요성 검토

새 상시 문구를 뺀 기존 계약과 추가한 계약을 사고 및 대조 사례 질문에 대조한 저자 검토입니다. 독립된 동일 조건의 새 모델 실행이나 의미 품질의 실측 개선 증거가 아닙니다.

| 문구 | 기존 계약만으로 남는 차이 | 보존할 대조 사례 |
|---|---|---|
| 장면과 행동을 먼저 설명 | 주체와 인과의 존재만으로 추상적 경고 선행을 통과시킬 수 있음 | 승인 전 삭제 금지와 미검증 성능은 약화하지 않음 |
| 지시 대상과 경로 결과 복원 | 독자가 보지 못한 상황과 그림의 화살표를 추측하게 할 수 있음 | 이미 정의된 처리 흐름과 명확한 문장은 유지 |
| 조건을 기제/범위 설명에 통합 | 한계를 유지해도 모호한 면책문만 남을 수 있음 | 필수 안전 및 권한 경고는 명시적으로 유지 |
| 인라인 참고문헌 | 링크의 존재는 보장하지만 자동 설명 블록을 제한하지 않음 | 긴 제목과 좁은 화면의 자연스러운 줄바꿈 허용 |

조건부 공간 범위와 검증 순서는 기존 참조에만 두었습니다. 공유 글쓰기의 첫 문장을 같은 의미로 압축하고 새 문구도 압축하여 기존 부하 한도를 늘리지 않았습니다. 부하 단위 테스트는 상시 참조 합산 밖의 스킬을 대상으로 같은 증가/중복 조건을 검사하여, 별도 합산 한도가 먼저 실패하면서 원래 판정을 가리지 않도록 격리했습니다. 회귀 평가 13개는 기존 사례를 보존하며 의미 판단 기준으로 추가합니다. 단어 금지나 SVG 개수로 자연스러움과 공간 범위를 판정하지 않습니다.

## 검증 범위

기존 동기화, 문서/언어/부하, 단위 검사, 설치 사전 점검와 최신 `main` 대비 릴리즈 게이트를 실행합니다. 실제 결과는 실행 근거에서 확인합니다. 로컬 `Chromium`이 없어 추가한 화면 회귀 검사는 실행하지 못했습니다. 독립된 모델 생성과 문장별 삭제 전후 실행도 수행하지 않았으므로, 모델 행동의 개선 효과와 자원 절감량은 미검증입니다. 저자 검토를 모델 실험으로 대체 표기하지 않습니다.
