# HTML 차트 참조 보완

## 근거와 선택

- `diagram-design`의 `0a8ea20ae69b33a5edce6018eedd3a9d26e90c1c`에서 유형 선택·축·레이블·시각 위계를 가져와 적용했다. 고정 브랜드·외부 글꼴·엄격한 노드 수는 제외했다. `MIT` 고지를 배포 패키지 여섯 곳에 보존했다.
- `Graphify-Labs/graphify`의 `a9860f70dc3cc2e9c2d8cb923484cfa0592b9067`에서 노드 선택·이웃 강조·근거 상세라는 상호작용만 참고했다. `Apache-2.0` 코드·문구·자산은 복사하지 않았고 추출 엔진·지속 그래프·외부 서비스 의존성은 제외했다.
- 사용자가 원하는 둥근 막대·절제된 그라데이션·상세 툴팁을 자체 구현했다. 첨부 이미지의 미검증 성능 수치는 사용하지 않았다.

## 변경과 평가

- HTML 소비 스킬 여섯 개에 공통 설계 참조와 실행 가능한 막대·선·영역·산점도·관계도 예제를 제공한다. 차트가 필요한 분기에서만 읽는다.
- 기존 표 형식 규칙과 PR 미리보기 계약은 변경하지 않는다.
- 동기화 검사에 새 참조·예제의 누락과 변조 복구 사례를 추가했다.
- 독립 생성 평가에서 `0`, `12.5`, `28` 값과 긴 레이블을 가진 오프라인 HTML을 생성했다. 모바일 폭, 키보드 툴팁과 닫기를 브라우저로 확인했다.
- 예제의 데스크톱·모바일, 밝은·어두운 테마, 툴팁, 키보드, 범례 전체 숨김, 노드 선택과 초기화, 외부 요청 없음, 스크립트 비활성 상태의 차트·표 보존을 실제 브라우저로 확인했다.
- 독립 검수에서 발견한 단독 차트 초기화 오류와 두 패키지의 출처 고지 누락을 수정했다. 그래프·테마 없이 선 차트만 추출한 실행도 통과했다.
- 전체 보조공학 인증이나 모든 차트 유형에 대한 완전한 검증을 주장하지 않는다.
