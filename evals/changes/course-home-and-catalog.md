# 코스 머리글·전체 홈·본문 면 개선

2026-10-22 사용자 회고를 최신 소스 `1c23ebaf`와 대조하여 `F1-F3`을 반영합니다.
`F4`는 기존 `Skill Feedback` 규칙으로 다루므로 새 규칙을 추가하지 않습니다.

- `KEEP`: 코스별 수동 진도, 단일 코스의 독립 홈, 외부 요청 없는 단일 파일,
  코스 홈 링크, 테마 컨트롤, 플레이어 및 기본 50% 자막 배경입니다.
- `ADAPT`: 머리글에는 코스 제목을 한 번 표시하고 강의 진입 시 강의 제목을 추가하며,
  홈 복귀 시 강의 제목을 비웁니다. 빌드한 모든 레슨 페이지를 `HTML` 파서로 검사합니다.
  모바일에서도 강의 제목을 숨기지 않고 줄바꿈하도록 합니다.
- `ADAPT`: 원본 `<topic>/course.json`과 `<topic>/build/`를 분리하는 기본 경로 계약,
  직접 빌드와 `build/`의 호환 탐색, 표지가 있는 카탈로그만 원자적으로 갱신하는 계약,
  첫 슬라이드 `SVG`·설명·수준·강의 수·기록된 음성 길이를 표시하는 갤러리,
  제목·설명·목표·강의 제목을 검색하는 오프라인 필터와 전체 홈 복귀 옵션입니다.
  카탈로그는 코스를 수정하지 않고 각 코스 빌드에 필요한 상대 경로를 반환합니다.
  기존 빌드의 길이는 추측하지 않고 미기록으로 표시합니다.
- `ADAPT`: 홈 본문에 기존 `--panel`·`--line` 토큰으로 독립된 면을 주며,
  학습 목표 구획은 선으로 나눕니다. 시작 카드와 본문 면은 나란히 둡니다.
- `OMIT`: 전역 진도 `DB`, 코스 자동 병합, 단일 코스에 빈 카탈로그 생성, 다른 스킬의
  설치본 수정입니다. `course-builder`에는 다중 코스 갤러리·검색 출처를 귀속하지 않으며
  `Udemy` 화면이나 코드를 조사·복사했다고 주장하지 않습니다. 이 변경은 소스에서 검증한
  구체적 사건을 교정하므로 새로운 외부 프레임워크를 도입하지 않습니다.

실제 두 코스를 원본과 `build/`로 나눠 생성하고, 반복 실행·내용 보존·중복 `ID` 거부·표지가
없는 파일과 심볼릭 링크 거부·`SVG` 프리뷰·상대 링크와 번들 프레임 탈출 계약을 검사합니다.
검색과 머리글 갱신은 실제 `JavaScript`를 `Node/DOM` 대역에서 실행합니다. `WAV` 시험 파일로 측정값을
확인하되 실제 `TTS` 합성이나 실청이라고 주장하지 않습니다. 기존 평가 `ID`와 계약을 보존합니다.

이 환경에는 `Playwright` 라이브러리만 있고 `Chrome/Chromium` 실행 파일이 없습니다.
실제 헤드리스 화면, `390px` 가로 넘침, 밝은/어두운 테마 배경과 링크 왕복은 미실행입니다.
`Node`/정적 테스트는 이 화면 검수를 대신하지 않습니다.
