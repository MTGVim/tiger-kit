# tk-course: 미디어를 분리한 기본 배포

사용자가 대용량 `index.html`을 열지 못한 현상을 제보했고, 현재 생성기에서 음성·영상·이미지의
Base64 삽입과 강의 HTML 전체 재포장을 확인했습니다. 기본 CLI와 `dist` 빌드는 작은 진입 HTML,
강의 HTML 및 선택한 강의만 읽는 `classic-script` 로더, 내용 해시별 미디어와 공개 파일 목록을
생성합니다. `srcdoc`과 상대 경로 `base`를 함께 사용해 기존 진도·선호 저장 출처를 유지합니다.
`fetch`·`ES modules`·학습자용 서버는 추가하지 않습니다. `no-dist` Python 호환 API는 기존 기본값을
유지하며 `single_file=False`로 새 출력을 선택할 수 있습니다.

단일 HTML은 --single-file로 선택하며 최종 UTF-8 10 MB를 초과하면 배포 전에 거부합니다.
ZIP은 명시된 파일 목록만 포함하고 누락·심볼릭 링크·예상하지 않은 경로를 거부합니다. 제작용
`course.json`·`changes.json`·계획·원본 디렉터리를 훑어 담지 않습니다. 이전 단일 HTML 코스도
카탈로그에서 계속 읽습니다. 안정적인 ID와 기존 --previous 변경·날짜·진도 계약을 보존합니다.

`course-portable-external-media-delivery` 평가를 추가하고 빌드·중복 제거·압축 이동·선택적
단일 HTML·누락 및 경로 검사·`PNG/JPEG/WebP`·영상과 압축 음성 검사를 수행합니다. 기존의
HTML 전용 ZIP 기대값은 공개 파일 목록으로 바꾸며 개인정보 제외 검사는 유지합니다.
현재 환경에는 브라우저 실행 파일이 없어 실제 `file://` 화면·재생 검사는 미실행입니다.
이동 후 파일 검사와 `Node` 대역 검사는 실제 브라우저·음성 증거로 주장하지 않습니다.

README: 스킬 이름·호출·카탈로그 설명과 설치 방식이 바뀌지 않아 수정하지 않습니다.
