# 사용법 영상 제작의 반복 수작업 개선

`README: no public change`

대상은 `tk-video`의 조립·계획, `tk-browser-verify`의 선택형 캡처 표시·인증 입력·원본
보존과 `tk-prep`의 영상 제안입니다. 이름·호출·카탈로그는 바꾸지 않습니다.

- F1: `--caption-size`와 출력 높이 5% 기본값을 추가하고, UI 아래 자막 띠 크기와 중앙
  여백을 함께 계산합니다. SRT와 플레이어 자막 대체 경로는 유지합니다. 예시의 471픽셀은
  `H.264` 짝수 높이에 맞춘 472픽셀로 검사하고, 1020픽셀와 별도 32픽셀 지정도 검사합니다.
- F2: 패키지 로컬의 제거 가능한 오버레이를 조건부 참조로 연결합니다. 커서·클릭·키캡·
  반복 키·강조를 제공하며 비밀번호·OTP·카드 입력·불투명 사용자 요소를 마스킹합니다.
  실제 입력·브라우저·타이밍은 기존 검증 담당자가 유지하고 표시 도우미는 입력을 실행하지
  않습니다. 입력 결과 즉시 확인, 확대 전 영역 강조와 판정 화면 전 제거를 명시합니다.
- F3: 형식·해설·입력 표시는 기존 선택에서 함께 결정합니다. 새 기능은 사용법, 기존 변경은
  수정 전후 영상으로 제안하고 구현·검증 후 만듭니다. 설명용 정지 장면의 자동 상영 시간는
  3초·글자당 125밀리초·해설+800밀리초 중 최댓값이며 명시 상영 시간와 실제 녹화 시각은 보존합니다.
- F4: 사용자 확정 전 원본 프레임·음성·매니페스트를 보존하고 프레임 용량을 보고합니다.
- F5: 별도 로그인 세션을 우선하고 종료 전 앱이 갱신한 승인 필드만 보호 파일에 반영합니다.
  기존 단일 갱신 담당·원자적 저장·비노출 계약을 재사용합니다. 401의 원인을 토큰 회전
  경합으로 단정하지 않습니다. 해당 앱의 30분 인증 재사용 실험은 수행하지 않았습니다.
- F6: 실행 예시 앞에 매니페스트 내부 입력·새 출력 경로와 WAV 재사용 제한을 명시합니다.
- F7: 영상은 UX 검수에 도움을 줄 수 있으나 기능 판정을 대신하지 않는 기존 계약을 유지합니다.

## 근거와 경계

반복 제작 사례와 실제 스크립트가 포함된 사용자 회고를 재사용 가능한 단일 사례 근거로
확인했습니다. 스크립트는 페이지 선택자·로컬 경로·외부 의존성을 제거해 직접 작성했습니다.

- 유지(`keep`): 실제 입력/관찰 시각, 원본 UI, 독립 판정 증거, 명시적 해설 선택, 경로 보호,
  플레이어 자막 대체와 비밀 입력 수명주기를 유지합니다.
- 반영(`adapt`): `FFmpeg`의 `subtitles`·`force_style` API만 사용합니다.
  https://ffmpeg.org/ffmpeg-filters.html#subtitles-1 의 현재 문서를 2026-10-21에 확인했습니다.
  SRT 기본 좌표 변환은 이 실행의 실제 디코드 검사로 확인한 호환 동작입니다.
- 반영(`adapt`): `ChromeDevTools/devtools-protocol`의
  `71ba93da82a97855a7912c41c276d9360e227c58`, `pdl/domains/Input.pdl`에서
  키 이벤트·문자 입력·좌표 계약을 확인했습니다. 호출 계약만 사용하며 코드를 복사하지 않습니다.
  https://github.com/ChromeDevTools/devtools-protocol/blob/71ba93da82a97855a7912c41c276d9360e227c58/pdl/domains/Input.pdl
- 제외(`omit`): 브라우저 공급자 교체, 공용 녹화 실행기, 설치·상시 프로세스, 화면별 선택자,
  특정 시간 입력 칸의 고정 키 순서, 토큰 회전 원인 단정과 전체 쿠키 내보내기를 추가하지 않습니다.

## 검증 범위

실제 MP4를 디코드해 두 해상도와 크기 지정의 자막 위치를 확인합니다. 현재 호스트에 한국어
글꼴이 없어 위치 회귀 검사는 영문을 사용하며 한국어 글리프 가독성은 검증하지 못했습니다.
오버레이 VM 테스트는
그룹·반복·마스킹·화면 경계 좌표·제거·재주입을 실행합니다. 실제 브라우저 실행 파일이
없어 오버레이 픽셀 배치와 CDP 입력·판정 스크린샷 조합은 `Unverifiable`입니다.
VM 실행을 브라우저 검증으로 표시하지 않습니다.

조건부 오버레이 설명은 새로 선택된 캡처만 읽습니다. 상시 계획 문장은 첫 선택에 표시
옵션이 빠지는 문제를, 반환 문장은 디코드 직후 원본을 지우는 문제를 각각 방지하므로
유지합니다. 공통 인증 정책과 README에는 같은 지시를 복제하지 않습니다.
