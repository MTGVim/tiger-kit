# 질문·조사·보고 계약과 코스 공유 개선

사용자가 제공한 `2026-10-22/23` 회고를 `733a388e` 소스와 대조했습니다.
질문 참조 미로드의 원인은 가설로 남기되, 여러 진입 경로에서 같은 형식 누락이 반복된
사례와 실제 소스의 기본 음소거·WAV 전용·작업/공유 중복을 교정 근거로 삼았습니다.
외부 실행 체계는 도입하지 않습니다.

- `question_policy.py`의 공통 블록에 구분선·질문·권장 형식과 마지막 블록·선행 결정
  계약을 직접 넣고 33개 사본을 동기화했습니다. 상세 복구·도구 규칙은 기존 참조에
  남깁니다. `2026-10-20`의 선택적 시각 질문과 달리 매 질문의 최소 계약입니다.
- `sweep`의 승인 전 상태 줄 충돌, 설계 전 티켓·상대 계약 조사와 변경 경로 검색,
  조사 가능한 문서 위치·기존 동작, 미병합 코드보다 합의 요건을 보존하는 원칙을
  추가했습니다. 단일 대응의 같은 판단은 `respond`에도 좁게 적용합니다.
- `prep`은 값 규칙 변경일 때만 생성·수정·부분 수정·복제·가져오기·기존 자료의
  관련 경로별 정책과 행동 검증을 준비합니다. 독립 질문과 종속 승인을 구분합니다.
- `compound`는 범위 한 줄·조치 후보·선택 질문을 기본으로 하고, 상세 근거는 현재
  세션에서 요청 때 설명합니다. 후보가 없으면 질문 없이 변경 없음으로 끝납니다.
  읽기 전용 권한과 기존 근거·기각·변경 없음 판정은 보존합니다.
- `retro`는 근거 보고서, 외부 패키지만 담은 재사용 가능한 이슈 초안, 사용자 소유의
  정확한 수정 전후 제안, 변경 없음으로 나눕니다. 같은 세션·패키지 초안에 추가하고
  정확한 파일·절을 알립니다. 제안 전용, 익명화와 저장 후 검사, 질문 없는 종결은
  유지합니다. 보고서의 기존 절 구성은 바꾸지 않습니다.
- `course`는 독립 재생 선호·기본 소리·정책 거부 시 음소거 재시도와 토스트,
  접히는 목차와 한 줄 `breadcrumb`를 제공합니다. 기존 볼륨 팝업과 진도 형식은 유지합니다.
- 음성은 원본을 보존하고 기본 `Opus 32kbps`, 선택 `MP3 48kbps/WAV`로 빌드합니다.
  압축 파일은 도구 존재·전체 디코드·무음·길이를 검사하며, 작업 `manifest`에 크기와
  길이를 남깁니다. 합성 시험음은 실제 나레이션·청취 증거가 아닙니다.
- CLI는 작업 `manifest`와 공유 HTML을 분리하고 선택할 때만 작업용 레슨 페이지를
  만듭니다. 공유 HTML 앞 `64KB`의 `manifest`만으로 코스 하나부터 탐색기를 자동
  갱신하고, 표지가 있는 탐색기·ZIP만 교체합니다. 상대 링크와 로컬 메시지 응답으로
  이동을 확인하고, 단독 파일은 탐색기 항목을 숨깁니다. 작업/공유 경로 겹침은 거부합니다.

기존 기본 음소거와 최소 코스 2개 규칙은 사용자의 최신 명시 요청으로 재검토합니다.
이전 `course-complete-objective-player`의 판단 문구만 기본 소리·차단 시 대체에 맞추고,
기계적 검증 및 나머지 목표·출처·미디어·진도 계약은 유지했습니다. 기존 인프로세스
빌드 호출의 작업용 통합본은 호환용으로 남기되, 공개 CLI의 기본 공유 경로는 새 계약입니다.

검증은 Python 빌드·경로·증분·`manifest`·ZIP·실제 `FFmpeg` 인코딩/디코딩 검사와
실제 JavaScript 제어기·선호·실패/일시정지 경합 검사로 수행합니다. 독립 소스 검수에서
찾은 경로 겹침과 일시정지 후 재시도 문제도 회귀 검사에 포함했습니다. 새 대화 문맥의
`sweep`·`handoff` 표본은 올바른 첫 질문과 질문 뒤 상태 줄 부재를 확인했지만,
참조 미로드가 원인이라는 인과 실험이나 여러 호스트의 모델 평가를 대신하지 않습니다.
브라우저 다운로드가 손상된 응답으로 실패하여 화면 치수·파일 출처 이동·실제 재생은
이번 환경에서 검증하지 못했습니다. `Chrome`/`Firefox`/`Safari` 호환성, 실제 코스의 15MB
기준 및 사람 청취는 아직 확인하지 않았으며 완료로 주장하지 않습니다.
