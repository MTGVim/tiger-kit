별도의 12개 양성·음성 입력에서 여섯 설명문의 기존/개선본 선택은 동일했습니다.
각 양성 입력에서는 본문을 읽고 준비/변경/발행 권한을 구분했습니다.
두 버전 모두에서 발견된 `tk-pr-respond`의 자동 호출 정보와 명시적 호스트 선택 문구
불일치는 일치하는 단일 PR 요청의 호스트 선택으로 명확히 하고 자연어 호출 평가를 추가했습니다.

별도의 새 실행자에게 경계·정상 입력 7개를 주었습니다. 누락된 기준 화면 정보는
Unverifiable로 남기고 완전한 기준 화면은 단계 `Pass`와 `verification_complete: false`로
반환했습니다. 지원 불명인 자식 인증, 심볼릭 링크 제외 파일, 구형 `applied` 주장도
권한·파일 경계를 지켰습니다. 명시적 공유 요약과 단일 PR 자연어 호출 판정을 확인했습니다.

## 크기와 해석

동일한 `str.split()`으로 메타데이터 포함 기본 `SKILL.md`를 측정했습니다.
26개 합계는 45,574단어에서 약 34,900단어로 약 23% 감소했습니다. tk-learn은 약 41%,
tk-browser-verify는 약 36%, SDD 기본 참조는 약 37% 줄었습니다.
이는 공백 기준 단어 수이며 토큰 단위 측정이나 전체 작업 비용 절감률이 아닙니다.
해당 분기를 실행하면 상세 참조를 추가로 읽으므로 그 경로의 총 읽기량은 늘 수 있습니다.

## 회귀 보호

파일 쓰기 금지 스킬과 쓰기 스킬의 설치 본문을 구분하고, 저장·UI 로컬 참조의
누락과 변형을 검사합니다. SDD 새 참조도 기존 생성 복사 검증에 포함했습니다.
이동된 복구 규칙의 기존 테스트는 실제 소유 참조와 본문의 연결을 확인하도록 옮겼습니다.
기존 평가의 기계 검사와 안전 표시는 보존하고, 새 상태 필드와 공유 요약 규칙은
개별 평가 이관으로 기록했습니다. 릴리스 게이트에 포괄 면제는 추가하지 않았습니다.

이 관찰은 이번 세션의 제한된 사례입니다. 모든 호스트나 다른 모델의 성능을
측정한 결과가 아니며, 정적 릴리스 게이트도 모델 행동 평가를 대신하지 않습니다.

## 독립 검수 보완

독립 검수 두 곳과 별도 검증자가, 예상 밖 사용자 입력을 만날 격리 자식에게
상호작용 참조가 처음부터 전달되지 않을 수 있음을 확인했습니다. 모든 자식 지시에
짧은 경계·조건부 참조 경로·지원 불명 시 반환 규칙을 넣는 의무를 기본 SDD 본문에
복원하고 두 사용자의 회귀 사례를 추가했습니다. 시각 증거 문서의 옛 절 링크도
실제 결과 계약을 소유한 참조로 고쳤습니다.

학습 평가의 반환 상태와 후보 적용 상태가 다르다는 의심도 별도 검증했습니다.
평가 어댑터는 반환 상태를 독립적으로 받으며 기존 버전에도 같은 구분이 있어,
새 변경이 일으킨 결함이라는 근거는 확인되지 않았습니다. 적용 승인·실제 쓰기
경계와 기존 평가 기대는 변경하지 않았습니다.
