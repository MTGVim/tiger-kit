## 근거와 범위

제공된 반복 제작 회고와 4개 변형의 1인 선호 비교를 확인했습니다. 실험 사본의 코드는
제공되지 않았으므로 공개 API와 실제 렌더링을 바탕으로 구현했습니다. 선호 점수를
통계적 효과나 새 기본값의 근거로 쓰지 않습니다.

최신 기준에는 이미 문장별 박자·그룹별 수량·실제 숨김 확인, 관련 요청을 기준으로 한
1초 대기 표시, 중첩 스크롤 밖의 포인터·대상 위치 재확인, 간격과 박자 경계 검수,
긴 한국어 자막 경고, CDP 캡처 주의 및 타임스탬프 정렬·중복 제거가 있습니다.
`tk-tts`의 `--target-lufs`, 기본 -18, 대안 -23과 실제 출력 음량 재측정 검사도 있습니다.
같은 규칙이나 옵션을 다시 만들지 않고 관련 평가와 회귀 검사를 유지합니다.

새 선택형 기능은 다음을 추가합니다.

- `caption_style: band | overlay | overlay-rounded`. 기본 띠와 원본·SRT는 유지합니다.
  새 상자는 실제 설치된 `libass`로 글자 범위를 측정하여 줄바꿈·여백을 계산합니다.
- 원본 프레임 좌표의 흰 설명문 카드. 겹침·범위 초과·미지원 글리프를 성공으로 숨기지 않습니다.
  해설을 반복하지 않는 추가 사실을 표시하도록 기존 해설 참조에만 지시합니다.
- 모든 강조 사각형과 동시 설명문을 포함하는 고정 크기 `zoompan` 확대. 관찰 시각은 유지하고
  배율·이동은 500밀리초 `smoothstep`으로 전환합니다. 정수 크롭의 미세한 흔들림 한계는 공개합니다.
- 출력 프레임 전체 구간에서 자막과 보호 영역을 대조합니다. 아래가 겹치면 위로 옮기고 경고,
  양쪽 모두 겹치면 작성 오류로 중단합니다. ASS의 10밀리초 양자화 후 실제 표시 구간을 사용합니다.
- 녹화 담당자는 하단 약 15% 안전 영역과 좌표 배율·크롭 기준을 전달합니다. 원본 표시와
  독립 판정 스크린샷의 경계는 유지하며 별도 녹화 런타임을 만들지 않습니다.

## 출처와 선택

`references/sources.md`의 2026-10-28 출처 검토: 현재 `FFmpeg`
`c69954c34522c53234dfd43fa7a0cb3b02f39e47`의 `vf_zoompan.c`, 해당 필터 문서,
실제 설치된 6.1의 같은 구현, `libass` 형식 안내, `Aegisub` 벡터 태그 문서를 확인했습니다.
고정 출력·입력 프레임 수·ASS 도형 계약은 반영(`adapt`), 원래 시각·캡처 담당자는
유지(`keep`), `openscreen`의 데스크톱 녹화기·코드와 자동 설치는 제외(`omit`)합니다.
`Fluent`의 1초 기준과 EBU R128의 -23 기준을 재확인했습니다. `Primer`는 불확정 대기 표시의
근거로만 사용하며 해당 문서에 없는 정확한 1초 기준을 귀속하지 않습니다.

## 검증과 지침 비용

실제 MP4/GIF 디코드로 고정 높이, 자막 여백, 카드 여백, 시간 일부만 겹치는 충돌,
확대의 모든 대상·카드 보존, 시작·종료 전환, 글자에 포함된 ASS 태그 무력화,
잘못된 좌표 및 `libass` 부재를 검사합니다. 기존 단일 조립기 독립성 검사는 같은 패키지의
새 도우미까지 복사하되 TTS 엔진·형제 패키지는 계속 제외합니다.

별도 한국어 폰트 설정의 실제 프레임에서 50자 넘는 두 줄 자막과 카드를 검사합니다.
독립 사용 검증은 합성 대시보드와 비무음 테스트 WAV를 사용하며 음성 발음·`Qwen` 합성
검증으로 주장하지 않습니다. 실제 업무 관리 화면을 재녹화하거나 공개하지 않습니다.

추가한 상시 SKILL 문장은 기존 `assembly` 참조와 중복되어 제거했습니다. 조건부 설명의
삭제 비교: 좌표 변환 지시가 없으면 DPR/크롭 좌표를 혼합하고, 안전 영역이 없으면 녹화 때
자막 공간을 확보하지 않으며, ASS 양자화 지시가 없으면 짧은 카드 충돌을 놓칩니다.
설명문·확대 필드 계약과 실제 픽셀 검수만 해당 분기에 두고 공통 정책은 복제하지 않습니다.

화면 끝의 2픽셀 테두리와 높은 배율 충돌 재현도 추가했습니다. `RGB` 크롭과 위쪽 정수 반올림·경계 제한으로 끝 테두리를 보존하고, 충돌 검사에도 실제 정수 크롭 크기·좌표를 반영합니다.
