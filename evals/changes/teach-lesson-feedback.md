# `tk-teach`를 수업별 HTML과 실제 답변의 피드백으로 정리

검토한 공개 구현의 수업 단위와 답변 판별 방식을 기존 교육 계약에 맞게 증류합니다. 새 주제는 수업별 독립 HTML을 기본으로 하고 필요한 목록만 갱신합니다. 기존 단일 문서와 명시적으로 요청한 다중 챕터 자료는 보존합니다. 실제 답변이 있을 때만 별도 피드백 참조를 읽고, 정답과 추론·부분 이해·미응답을 구분하며 풀이 요청과 종료 선택을 존중합니다.

기존 재개·출처 범위·선수지식·실행 연습 판별·HTML 검증·형식 보존 계약은 유지합니다. 과거 코스 제작기를 이식하거나 서버·전역 학습 상태·별도 매체 포장 기능을 추가하지 않습니다. 공개 구현의 고정 버전과 유지·적응·제외 근거는 `skills/tk-teach/references/distillation.md`가 소유합니다.

기존 `study-answers-resume-research`와 `study-sufficient-context`는 단정 검사에 이미 지정된 과거 경로를 요청에도 명시합니다. 기본 경로와 서로 다르던 설명을 일치시키며 전체 자료·선수 순서·출처·숙달 추정 금지 검사를 약화하지 않습니다. 새 기본 수업과 다음 수업 보존, 실제 답변별 피드백을 별도 평가 사례로 추가합니다.

README: `no public change` — 스킬 이름·호출·카탈로그 설명·설치 방식은 유지합니다. 구체적인 제작 경로와 수업 계약은 `skills/tk-teach/SKILL.md`와 참조가 소유합니다. 결정 이유는 `docs/adr/0002-use-lesson-files-for-teaching.md`에 남깁니다.

독립 검수에서 공통 포장 도구가 연결한 과거 HTML의 내보내기 정보까지 다시 쓰는 경로를 확인했습니다. 수업 추가 시 공개 허용 목록의 일반 복사본에서 포장하고 새 수업·승인된 목록만 반영하도록 보완합니다. 이전 원본과 비공개 학습 기록을 그대로 보존하며 공통 포장 도구나 실행 체계를 새로 만들지 않습니다.
