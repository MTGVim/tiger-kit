# 블라인드 비교 갤러리

사용자가 제공한 한국어 TTS 블라인드 청취 운용 사례(44개 클립 평가 완료, 페이지 5회 재작성)를
재사용 절차로 증류합니다. 원본 세션·44개 결과 파일을 이번 작업에서 재검증하지 않았으며,
오디오 외 매체의 실제 사람 평가와 복수 평가자 운용은 검증되지 않았습니다.

## 근거와 처분

- 최신 TigerKit `main` `d3c4c982`의 `tk-qa-sheet`, `tk-prototype`, `tk-tts`와 공유 HTML·산출물·평가
  계약을 먼저 확인했습니다. 단일 정답 QA·후보 생성·음성 합성의 기존 경계를 KEEP했습니다.
- 사용자의 실제 운용에서 드러난 라벨 충돌·점수 이전·파일명 정체 노출·호스팅 형식·로컬 파일 요구를
  ADAPT했습니다. 안정적인 불투명 후보 ID와 내용 `fingerprint`, 항목별 `seed` 섞기, 내장 미디어,
  실패 카드, 버전, 공개 전 평균 숨김, JSON 가져오기/내보내기와 저장 실패 처리를 추가합니다.
- 별도 비교 담당자가 없다는 현재 소스의 차이와 구체적 단일 재사용 사례가 근거입니다.
  무관한 외부 프레임워크·서버·DB·후보 생성·자동 승자·통계 검정은 OMIT했습니다.
- HTML 공용 자산 동기화 대상을 한 줄 추가하며 기존 스킬 본문은 바꾸지 않습니다.
  README에는 공개 이름과 한 줄 설명만 추가합니다. 소스에서 불러오는 스킬이므로 `Work` 진입 스킬은 변경하지 않습니다.

## 검증과 한계

정적·실행 검사로 5후보×9항목의 실패 표시·DOM 정체 노출, 추가/삭제/재배열 시 안정적 ID,
내용 변경 평가 분리, 이미지·텍스트 표현, 잘못된 JSON과 점수·중복·실패 점수 거부를 확인합니다.
브라우저에서 로컬 파일 평가·재로드·후보 추가·JSON·공개·저장 거부·반응형·테마를 별도로 확인합니다.
자동 생성한 테스트용 미디어는 기능 검증용이며 실제 TTS 품질·청취 평가 결과가 아닙니다.

파일 안에 공개용 정답 데이터가 있으므로 소스 분석까지 막는 보안은 제공하지 않습니다.
후보 이름은 기본 DOM과 화면에 없고, 별도 대응표도 보존합니다. 매체별 의미적 익명화와
정규화는 담당 에이전트가 해당 참조에 따라 수행·검수하며 빌더의 문자열 검사가 이를 대체하지 않습니다.
복수 평가자 병합은 지원하지 않으며 1개 브라우저의 1인 평가 결과만 집계합니다.

새 본문의 각 절차는 구별되는 분기를 소유합니다. 제안/실행 분리를 삭제하면 취향 비교에서
무단 생성이 발생하고, 이전 `key/fingerprint`를 삭제하면 라벨 변경 또는 출력 변경에 잘못된 평가가
이어집니다. 정규화 참조를 삭제하면 매체별 단서가 남고, 실패/공개/저장 거부·내보내기를 삭제하면
원사례의 누락과 평가 손실이 재발합니다. 단순 일반 작성 조언은 공유 참조에 남겨 중복하지 않습니다.

독립 검토에서 확인한 평가자 혼합·제거 후보의 JSON 백업 누락·입력의 추가 필드에 의한 집계 정보
덮어쓰기를 수정했습니다. 설명 총량 한도는 기존 설명을 바꾸지 않고 새 스킬 143자만큼 4143자로
조정하며, 다른 스킬 동작은 변경하지 않습니다.

브라우저는 격리된 `headless Chromium 153`에서 실제 로컬 파일을 열었습니다. `1440/390px`와
`light/dark/system` 테마, 44개 WAV 디코딩, 실패 카드, 키보드 점수·메모, 새로고침, 후보 추가·삭제·재추가,
JSON 백업·가져오기, 평가자 혼합 거부, 저장 차단과 JavaScript를 끈 상태의 읽기를 확인했습니다. 검증 환경의
한국어 글꼴 누락은 실행 전용 `Noto Sans CJK KR`로 보완했으며 산출물이나 시스템 글꼴 설정은 바꾸지 않았습니다.
버튼은 사용자 피드백에 따라 `결과 공개` / `결과 가리기`로 표시합니다.

새 패키지에 공유 참조를 복제한 뒤 `diff` 공백 검사에서 정본 `html-figures.md`의
기존 EOF 빈 줄을 발견했습니다. 정본과 동기화 사본의 마지막 빈 줄만 제거하며 동작은 바꾸지 않습니다.
