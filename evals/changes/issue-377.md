# #377: 의미가 있는 서법 보존

## 원본과 차이

고정 원본은 `epoko77-ai/im-not-ai@92b2936956d65d62ff4b19b75cccad8e3429bf43`입니다.
`skills/humanize-korean/references/ai-tell-taxonomy.md`의 A-10과 G-2,
`git show 0aedd76a1e6a1bc2b5f5f99e340988bf860fb685`의 수정 이유를 읽었습니다.
A-10은 기존 단정 전환 금지만으로는 다른 완곡어로 교체하면서 발생하는 강도 변경을 막지 못한다고
설명하며 의학, 법률, 정책 문서에서는 반복이 많아도 형태 분산을 적용하지 않도록 수정했습니다.
G-2는 같은 이유로 중첩 완곡어 제거의 적용 제외 범위를 확장했습니다.

`tests/test_restore_modality.py`에서 완곡어 및 의무 표현의 단정 전환 복원,
의미가 유지되는 표현 변경의 허용, 문장 병합과 분할 시 자동 복원 보류 사례를 확인했습니다.
`empirical-validation.md`의 과업 편향과 일반화 한계도 확인했습니다. 원본 테스트는 실행하지 않았습니다.
원본에서 주장하는 55편 중 40편 복원과 모델별 실증 수치는 재현하지 않았으므로 `unverified`입니다.

기존 TigerKit은 확실성 보존과 반복을 줄이기 위한 가능성의 단정 전환 금지를 이미 명시합니다.
이번 차이는 완곡 표현 사이에서도 발생하는 강화와 약화, 의무와 권고의 상호 변환을 명시하고
동등한 기능 표현까지 문자 그대로 고정하는 과잉 교정을 막는 것입니다.

- `keep`: 원문 의미, 조건, 주체, 권한과 불확실성을 보존합니다.
- `adapt`: 분야를 제한하지 않고 의미가 있는 서법과 주장 강도를 양방향으로 대조합니다.
  동등성이 불분명하면 원래 서법을 유지하고 어순이나 문장 경계를 조정합니다.
- `omit`: 특정 분야 목록, 4회 반복 기준, 완곡어 사전, 표지 개수 게이트, 자동 복원기,
  다중 호출 런타임, 영속 후보 장부와 AI 작성 판정은 가져오지 않습니다.

## 회귀 평가

기존 평가 52개를 변경하지 않고 6개를 추가했습니다. 강화, 약화, 의무의 권고화,
권고의 의무화, 의미가 동등한 기능 표현 변경, 네 번 반복되는 가능형의 보존을 각각 다룹니다.
평가는 특정 완곡어의 출현 횟수나 금칙어 목록 대신 의미를 판정합니다.
이는 실행할 평가 계약이며 실제 모델 실행 통과율이나 원본 대비 성능 향상을 주장하지 않습니다.
공유 사본 동기화와 최종 릴리즈 검사는 통합 담당자가 수행합니다.
