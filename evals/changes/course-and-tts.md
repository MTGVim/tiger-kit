# 완결 코스·로컬 TTS와 미디어 선택 경계

사용자가 검수한 코스 시제품과 최종 승인에 따라 tk-course/tk-tts를 추가합니다.
자막 배경은 기본 50%이며 슬라이드·영상 모두 설정에서 조절합니다. `tk-teach`는 실제 답변·오개념과
다음 수업을 소유하는 개인 과외로 유지하고, `tk-explain`은 특정 개념·상황 설명을 소유합니다.
완결 코스는 생성 후 반복 대화 없이 학습할 수 있어야 합니다. 기존 `tk-teach`/`tk-study` 자료를 옮기거나
학습 기록을 코스 수동 진도로 바꾸지 않습니다. 기존 행동 평가와 식별자는 보존합니다.

## 근거와 처분

- TigerKit `main` `68b14419cdef1ac9c2c93766c3926f0a192e2098`의 HTML/`tk-teach`/`tk-video`와 평가 계약을 확인했습니다.
  기존 `Qwen` 파일을 tk-tts로 이동하고 호출자와 소스 테스트 경로를 갱신했습니다. 기존 조립기는
  음성 엔진 없이 계속 작동합니다. `8bit`와 공식 `PyTorch` 경로/핀/캐시는 보존합니다.
- `course-builder` `1913b09bd1bf947b5ee2d1a75eab4396e669fbd3`의 MIT 플레이어/CSS와 교차 자료 검사 원칙을
  ADAPT했습니다. 원본의 다중 에이전트 실행 구조·서비스·`Marp`·불충분한 자동 검사는 OMIT했습니다.
  실제 사용자 피드백으로 확인한 미디어 중심 화면, 자막/설정/진도/무음 복구/탐색 계약을 KEEP했습니다.
- `Qwen3 CustomVoice 0.6B MLX 5bit` `ea57eb1094e142071162f79568581c9315dfd2e7`와 `ppaso`
  `53d09664c4f636a5fb6f2ebe3ec22cd83ee249b9`의 공식 모델 카드/작은 파일·LFS 메타데이터를 확인했습니다.
  `5bit`는 `Apple Silicon` 기본 추천, `ppaso` ONNX CPU는 경량 선택으로 ADAPT했습니다. 실제 사용자 실험의
  모델 SHA는 첨부에 없으므로 이 핀을 실험에 사용한 SHA로 표시하지 않습니다. 가중치·추론 설치는
  이번 저장소 검증에서 실행하지 않았으며 실제 발음·실청은 남아 있습니다.
- `ppaso`의 G2P/사전은 고정 스냅샷에서만 불러옵니다. 샘플/아바타/VRM/립싱크/RKNN/`Vocos`는 OMIT했습니다.
  공식 `PyPI` 메타데이터에서 선정 버전/플랫폼 휠 해시를 확인했습니다. 독립 사용 시험에서 빠진 맥
  ONNX와 MLX 휠 해시를 발견해 보완했고 `Mecab` 사전도 별도 핀으로 기록했습니다.
- 캐시/문장 정책을 맞춘 최장 입력 시험과 실제/기대 버전 복구 안내를 ADAPT했습니다. 짧은 문장의
  무음/뭉갬은 미해결로 유지하며 검증되지 않은 재시도·엔진 교체·ASR 도입은 REJECT했습니다.

## 행동과 범위

완결 코스는 고정 셸, 목표/선행관계/출처/평가 검사, 안정적 ID·내용 버전, 새 디렉터리 빌드와
코스별 진도를 사용합니다. 변경/삭제 강의의 과거 완료·메모를 보존하고, 손상된 진도 위에 저장하지
않습니다. 여러 주제의 상위 홈은 명시적 선택 분기이며 정적 링크만 만듭니다. 전역 학습자 DB나 자동
병합/숙련도 추론은 추가하지 않습니다. 기존 자료는 커리큘럼/출처 자료와 함께 증분 편집합니다.

미디어를 제작하는 `tk-prep`/`tk-explain`/`tk-explain-diff`/`tk-teach`/`tk-course`/`tk-video`는 TTS·기존 음원·무음을 먼저
확인합니다. 이미 답한 선택은 재사용하고 목소리 기본값을 동의로 간주하지 않습니다. 정적 텍스트/HTML에
불필요한 음성 인터뷰를 강제하지 않습니다. 같은 블록을 `narration_policy.py`가 동기화/검사하여 누락을
실패시킵니다. 합성은 tk-tts, 장면/인코딩은 tk-video, PR 발행/첨부는 기존 소유자와 권한을 따릅니다.

README는 기존 섹션·표·두 줄 소개 예산과 100자 이내 카탈로그를 유지하며 역할 소개와 새 호출을
추가했습니다. 설명/라우팅/트리거·행동·릴리즈 중요 평가를 함께 추가했고 기존 계약을 폐기하지
않았습니다. 새 본문은 선택/완료/권한/실패 경계를 유지하며 상세 데이터/설치는 조건부 참조에 둡니다.

## 실제 검증과 한계

`Qwen` 기존 17개 테스트, `ppaso`/선택/핀·휠/무음/공통 질문 동기화 테스트, 실제 코스 빌드·증분
내용 버전·손상 진도·코스 모음·단일 영상·원고/출처 검사, 발행 HTML의 JS 구문과 실제 상태/불투명도/
재채점 이벤트를 검사합니다. 음성 없는 조립 회귀와 기존 평가 계약은 보존합니다.

새 코스 스킬을 별도 실행자에게 클로저 입문 두 강의 제작 요청으로 사용하게 했습니다. 이 과정에서
참고 자료 탭의 데모 링크 잔여물과 `JavaScript` 없는 퀴즈 선택지 누락을 발견해 소유 템플릿에서
고치고 재생성했습니다. TTS 독립 실행은 실제 옵션/CLI 진단과 없는 의존성·스냅샷을 구분했습니다.
이 시험을 실제 음성 합성/실청이나 브라우저 포인터/배치 검증이라고 주장하지 않습니다.

`Chrome`/`Chromium` 실행 파일이 없으므로 실제 브라우저·키보드·전체 화면과 한국어 음성 출력 검수는
이번 환경에서 미실행입니다. `Node`/DOM 대역, 정적 검사와 `FFmpeg` 결과의 범위를 구분합니다.
릴리즈 게이트 자체는 별도의 정확한 커밋/최신 기준 비교에서 확인합니다.

독립 검수에서 시작 버튼·슬라이드 음량/배속·강의 파일 이름 충돌·코드 세 번째 줄·코스 모음 URL·영상 자막 구간/종료 후 탐색·증분 내용 식별 문제를 확인했습니다. 실제 빌드와 이벤트 회귀 검사에서 실패를 재현하고 수정했습니다. 증분 비교는 관련 목표 설명과 빌드 시 기록한 미디어 해시를 포함합니다. 노트 중복도 제거했습니다.
