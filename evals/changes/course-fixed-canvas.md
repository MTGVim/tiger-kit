# tk-course 고정 슬라이드 캔버스와 과밀 판정

## 근거와 정책 변경

사용자가 제공한 사고 증거는 코스별 `aspect-ratio:auto`/`height:auto` 후처리와 공유 제작·평가 공백을 구분합니다. 해당 코스 원본과 과거 검증 기록은 이번 작업에서 수정하거나 복구하지 않았습니다. 최신 정본의 이미지 분기·세로 배치 생성기·도표 스타일과 기존 회귀 검사를 대조했습니다. 이 변경은 기존의 내용에 따른 높이 확장·세로 배치 정책을 명시적으로 변경합니다.

주요 상류인 `tobyilee/course-builder`의 `HEAD`는 2026-10-24에 `1913b09bd1bf947b5ee2d1a75eab4396e669fbd3`으로 다시 확인했습니다. 같은 리비전의 `.claude/skills/slide-authoring/SKILL.md`에서 단일 설명 단위·유형, 넘치는 내용의 분할, 슬라이드 변경 후 큐 재매핑을 읽었습니다. 유지: 원본 수정과 큐 정합성. 조정: 의미 경계 분할과 전체 프레임 판정. 제외: `Marp`, 고정 장수, 글자 수만으로 합격하는 방식. 상류의 실행·평가는 수행하지 않았으며, 해당 문서가 16:9를 규정한다고 주장하지 않습니다. 16:9는 사용자가 요청한 이 매체의 정책이며 보편적 학습 효과를 입증한 결과가 아닙니다.

## 변경과 경계

- `SVG`와 미디어 콘텐츠 영역은 데스크톱·좁은 화면·전체 화면에서 16:9를 유지합니다. 영역별 공간 예산을 초과하면 슬라이드 식별자·영역을 포함해 원본 재저작을 요구합니다. 자동 자르기·글씨 축소·내부 스크롤로 통과하지 않습니다.
- 도표는 범례·값을 가로 공간에 배치합니다. 이미지는 고유 비율을 유지하고 강조 영역도 동일 좌표를 사용합니다. 긴 권리·출처는 링크로 여는 노트와 자바스크립트가 없는 본문에 보존합니다.
- `scripts/slide_geometry.js`는 실제 브라우저에서 캔버스·프레임·경계·스크롤과 필수 벡터 라벨 크기를 판정합니다. 경계 검사만 통과하는 작은 라벨은 별도 실패 사례입니다. 래스터 라벨은 여전히 실제 픽셀 판독이 필요합니다.
- 노트·목차·대본·바깥 콘텐츠의 스크롤, 코스·강의 식별자·진도·음원·단일 `HTML`·전체 화면 복귀는 유지합니다. 실제 사용자 코스 재저작은 원본을 확인하는 별도 구현 작업입니다.

## 검증 설계

기존 파이썬 도표 입력과 브라우저 평가기를 확장합니다. 세로 두 패널 합성의 거부와 명시적인 분할 대조, 정상 정사각형·이미지·도표, 정적 경계, 실제 스타일 재정의 실패, 화면 크기·목차·대본 상태 조합, 기본·대체 전체 화면, 메타데이터 링크, 큐 강조와 원본 데이터 보존을 검사합니다. 전체 프레임을 한 장에 캡처하며 문서의 도달 가능성을 합격 근거로 쓰지 않습니다. 같은 실패 입력에서 이전 버전은 세로 캔버스를 생성하고 이후 버전은 원본 단계에서 거부해야 합니다.

본문의 캔버스 계약을 제거하면 이미지 비율 보존만으로 충분하다고 판단할 수 있고, 스크롤 영역 구분을 제거하면 문서 스크롤을 오판합니다. 좁은 화면·전체 화면 및 전체 프레임 조건을 제거하면 이전 검사 공백이 남습니다. 세부 숫자·실행 검사는 조건부 제작 참조가 소유합니다.
