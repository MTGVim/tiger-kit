# 반복 참조의 복귀 위치 표시

본문의 같은 용어를 여러 번 참조할 때 위첨자 `[1]`, `[2]`를 붙이고 설명 아래 역링크에도
같은 번호를 표시한다. 참고문헌은 출처 번호를 유지하면서 `[1.1]`, `[1.2]`로 인용 위치를
구분한다. 번호와 링크는 기본 HTML에 포함하며 공용 스크립트는 실제로 클릭한 출발점의
역링크에만 `읽던 곳`을 추가한다. 단일 참조, 직접 진입과 새로고침에는 추측한 위치를
표시하지 않는다. 복귀와 다른 위치 이동 시 표지를 해제하고 기본 브라우저 탐색을 유지한다.

소유 위치는 `tk-explain`의 `html-components.md`, 공용 자산, 선택 예시이며 기존 동기화
도구로 패키지 사본과 내장 템플릿을 일치시킨다. 연구 템플릿의 두 인용에도 대응 번호를 적용한다.
기존에 만들어진 독립 HTML 파일은 소급 수정하지 않는다.

`backlinks.test.cjs`는 반복 용어·인용, 단일 참조, 키보드 이동, 출발점 교체, 수정키·취소 클릭,
뒤로/앞으로 이동, 새로고침, 절 제목·문장 미리보기, 접근 가능한 이름 복원, 좁은 화면,
라이트/다크와 무자바스크립트 복귀를 검사한다. 기존 공용 셸·읽기 기능 검사는 유지한다.
화면 낭독기 실사용과 일반 생성 에이전트의 성공률은 측정하지 않는다.

문장 삭제 비교: 대응 번호 규칙을 없애면 기존처럼 출발점을 구분하지 못한다. 출처와 인용 위치의
번호를 구분하지 않으면 여러 출처로 오인할 수 있다. 정적 HTML 요구를 없애면 스크립트 없이
번호나 복귀 링크가 사라질 수 있다. 관찰된 출발점과 표지 해제 규칙은 잘못된 복귀 위치를
표시하는 실패를 방지한다. 새 규칙은 컴포넌트가 있을 때만 읽는 기존 참조에 둔다.

`README: no public change`. 호출·카탈로그·설치 방식은 유지하며 변경한 공개 동작은 위 소유
참조에서 설명한다. 선례와 채택·조정·제외 판단은 `tk-explain/references/sources.md`에 기록했다.

검증 결과: 필수 Python 검사 384건은 통과했고 선택 브라우저 검사 3건은 기본 실행에서
건너뛰었다. 별도 로컬 `Chromium` 실행에서 새 역링크 검사와 기존 공용 셸·읽기 기능 검사가
통과했다. 새 검사는 390/1280 너비의 라이트·다크 및 무자바스크립트 복귀를 포함한다.
첫 브라우저 실행은 무자바스크립트 모바일 목차가 열린 상태여서 클릭이 가려졌다. 독자가
목차를 닫는 동작을 검사에 추가한 뒤 통과했으며 실패 기록도 보존했다. 독립 검수에서 발견한
연구 생성기의 구형 출력과 긴 문단 미리보기 문제를 수정하고 재검수에서 통과했다.
새 생성 평가의 계약 등록 검사는 실제 에이전트 생성 평가를 실행한 결과와 구분한다.
