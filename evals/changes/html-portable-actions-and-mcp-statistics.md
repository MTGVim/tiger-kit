# HTML 문서의 다운로드·공유와 MCP 통계 기본값

`README: no public change`

HTML 문서를 다른 곳으로 전달하려고 원본 위치를 다시 찾아야 한다는 사용자 피드백을 반영했습니다.
공유 계약의 정본은 기존 `tk-explain/references/html-output.md`이며, 기존 동기화 도구가 여섯 소비 패키지의
CSS·JavaScript·문서·패키징 도구를 같은 내용으로 유지합니다. 연구 보고서 생성기는 단일 HTML에
다운로드 데이터를 자동으로 포함합니다. 다른 생성 경로는 최종 편집 뒤 패키징 도구를 실행합니다.

- 보존(`keep`): 네이티브 라디오, 저장된 테마 우선순위, 무네트워크 읽기, 해시·인용·목차와 기존 QA 동작을 유지합니다.
- 반영(`adapt`): 테마를 접근 가능한 `40px` 아이콘으로 표시하고 왼쪽에 다운로드를 배치합니다. 단일 HTML 또는
  명시한 연결 파일 목록만 ZIP으로 내보내며, ZIP의 UTF-8 경로·CRC·압축 해제 후 재다운로드를 검사합니다.
  실제 파일 공유를 지원하는 환경에만 공유 버튼을 노출하고, 취소는 조용히 처리하며 실패 시 다운로드를 유지합니다.
- 제외(`omit`): 런타임 파일 탐색·네트워크 수집, 저장소 전체 압축, 외부 호스팅·자동 게시, 미리보기 주소 복사,
  외부 압축 라이브러리와 기존 MCP 등록 설정 변경은 포함하지 않습니다.
- 비용: 내장 원본과 무압축 ZIP으로 파일 크기가 늘어납니다. 큰 자료 묶음은 직접 아카이브로 전달하고
  문서 버튼의 한계를 알립니다. 중복된 테마·대화·용어 안내를 기존 담당 절로 합쳐 정적 문서 예산을 유지합니다.

## 검증 근거

- `Web Share` 정본: https://www.w3.org/TR/2023/REC-web-share-20230530/ 의 파일 검증·사용자 동작·취소 계약을
  확인했습니다. API 계약과 기능 탐지만 도입하며 사이트 코드나 UI를 복제하지 않았습니다.
- `Chrome DevTools MCP` 정본: `bf8c6d9bc70d24523c353f43775a6542a45e8c56`의 README를 읽고
  `--no-usage-statistics`의 기본 수집 비활성화 동작을 확인했습니다.
  https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/bf8c6d9bc70d24523c353f43775a6542a45e8c56/README.md
- `watchdog` 프로세스와 메모리 수치는 사용자가 제공한 `macOS 1.11.0`의 단일 측정 근거이며 이 실행에서
  재현하지 않았습니다. 환경 전체의 메모리 절감량이나 브라우저 조작 회귀 통과로 일반화하지 않습니다.
- 기존 스크립트 테스트에 새 내보내기 테스트를 연결했습니다. 실제 생성된 `Blob`을 ZIP으로 읽어 CRC와 모든
  엔트리, 상대 링크, 한글 파일명, 재내보내기를 검사하고, 공유 성공·미지원·취소·실패를 별도로 검사합니다.
- 로컬 브라우저 실행 파일을 찾지 못하여 화면 배치, 실제 다운로드 UI와 운영체제 공유 창 검증은
  `Unverifiable`입니다. 모의 실행 결과를 화면 검증으로 보고하지 않습니다.

영향 경로는 여섯 HTML 소비 패키지의 `assets/html-theme.*`, `references/html-output.md`,
`scripts/package_html.py`, 두 기존 템플릿, 연구 보고서 생성기, 기존 동기화·검증 도구와
`tk-browser-verify/references/environment.md`와 `tk-wizard/references/consumer-handoffs.md`입니다.
이름·설명·호출·공개 카탈로그는 바꾸지 않습니다.
