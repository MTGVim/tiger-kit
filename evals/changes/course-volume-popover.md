# 볼륨 패널을 열 때 컨트롤 막대가 늘어나는 문제

추가 피드백 6번을 최신 소스 `351111d1`과 대조했습니다. 기존 항목 1-5와 전달용 작성 표기
제거는 이미 반영되어 있으므로 그대로 보존합니다. 사용자 측 높이 측정은 제보 근거이며
이번 환경에서 재현한 브라우저 측정이라고 주장하지 않습니다.

- 폭이 늘어나는 인라인 슬라이더를 음소거 버튼 위의 절대 위치 패널로 바꿉니다.
  컨트롤 막대의 레이아웃에는 버튼만 참여합니다. 패널 크기는 뷰포트에 제한하며,
  공간이 부족하면 아래로 배치하고 좌우 및 위아래 위치를 보정합니다.
- 호버, 버튼 클릭 및 키보드 포커스로 엽니다. 방향키는 네이티브 범위 입력에 맡기고,
  `Esc`로 닫으면 버튼으로 포커스를 돌려주며 즉시 다시 열리지 않도록 합니다.
  패널을 숨기는 과정에서 슬라이더가 먼저 포커스를 잃는 경우도 검사합니다.
- 버튼과 패널 사이에는 마우스가 지나갈 수 있는 연결 영역을 둡니다. 바깥 탭과
  포커스 이동으로 닫고, 스크롤·크기 변경·전체 화면 전환에서는 위치를 다시 계산합니다.
  무음 모드에서는 패널을 닫고, 기존 음소거·볼륨·선택 음성 동작은 유지합니다.
- 볼륨 버튼의 펼침 상태와 패널 관계를 접근성 속성으로 연결합니다. 패널 상태와
  위치는 `controls-ui.js`가 소유하고 오디오 재생 상태는 기존 플레이어가 소유합니다.

`Node`에서 실제 제어기와 다섯 폭의 좌표 보정, 포커스 복귀·터치 경계·해제를 검사합니다.
명시적으로 설치된 브라우저가 있을 때 실제 코스를 빌드하여 `390/600/800/1024/1440px`,
밝은/어두운 테마, 막대 높이 유지, 패널 경계, `Tab`·방향키·`Esc`와 터치 동작을 검사하는
회귀 테스트도 추가했습니다. 실행 파일이 없는 현재 환경에서는 이 브라우저 검사를
건너뛰며, 논리 검사를 실제 화면 검증으로 대체하지 않습니다.

기존 볼륨 제어와 검증 절차를 개선합니다. 라이선스와 직접 게시 댓글 표기는 바꾸지 않습니다.
