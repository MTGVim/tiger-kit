# 입력 경로의 원문 전달과 미확정 사고의 예방안

2026-10-13 사용자가 제공한 두 사고 보고서를 TigerKit 정본
`563ff80ca82fba0641e8fa07e61ae5a5580300d5`의 공용 입력 계약,
`tk-browser-verify` 환경 참조, `tk-retro` 본문과 경험적 진단 절차에 대조했습니다.
제보의 55건 중 21건 요약·마지막 메시지 4건 원문 전달은 사용자 제공 근거입니다.
이번 작업에서 원본 호스트 기록을 직접 조회한 수치나 모든 호스트의 성공률로 주장하지 않습니다.
구체적인 실패·대조 사례와 명시적 재사용 요구가 계약 보강의 근거입니다.

- 유지: 상대·절대 경로, 비밀 값의 채팅 입력 금지, 저장 감지, 정확한 필드 검증,
  동일 스냅샷 소비, 주입 직후 정리, 사실·가설 구별과 제안 전용 회고 권한을 유지합니다.
- 변경: 준비와 지원되는 유한 백그라운드 감시를 먼저 수행하고, 실제 경로는 마지막
  일반 텍스트 메시지에 독립된 줄로 전달합니다. 같은 턴의 후속 도구 호출은 하지 않습니다.
  입력 대기 중 실행 소유 서버·브라우저와 서버 잠금을 유지하지 않습니다. 공유 인증의
  요청 소유권은 서버 잠금과 구별하며, 다른 실행이나 사용자 소유 자원은 종료하지 않습니다.
- 변경: 호스트의 감시 지속·자동 재개 기능이 없으면 그 한계를 밝히고 같은 입력 파일과
  재개 방법을 보존합니다. 턴 종료를 작업 취소로 해석하지 않으며 데몬을 만들지 않습니다.
- 변경: 화면 전달 사고는 접근 가능한 현재 세션의 노출 본문과 표시 메타데이터를 먼저
  확인합니다. 숨겨진 추론과 관련 없는 세션은 조사하지 않습니다. 원인이 미확정이어도
  결정적 근거를 시도하고 가능한 원인 모두에 유효한 예방책·소유자·판정 기준을 제시합니다.
  안전한 예방책이 없다면 이유를 밝히며 억지 패치를 만들지 않습니다.
- 제외: 공용 스킬 문제를 개인 메모리나 현재 저장소 한정 수정으로 대신하지 않습니다.
  실제로 확인된 소비자 설정 문제는 해당 설정 소유자에게 제안할 수 있습니다.
  특정 앱이 로그인 경로에서 쿠키를 지우는 동작은 공용 규칙으로 일반화하지 않습니다.

공용 정본은 `scripts/artifact_policy.py`이며 설치 패키지 사본을 동기화했습니다.
README와 AGENTS의 기존 입력 감시 순서도 함께 수정했습니다. 별도 실행기·호스트 통합·
비밀 감시 데몬은 추가하지 않았습니다. 기존 `tk-retro` 출처의 근거 구분과 최소 실험 원칙은
유지하며, 새 외부 실행 기반이나 원인 확정 기법을 도입하지 않았습니다.

회귀 평가에는 일반/공유 인증의 마지막 메시지, 감시 미지원 호스트, 대상 환경 확인,
호스트 전달 기록, 미확정 원인의 예방안, 안전한 예방책 부재, 공용 스킬과 개인 메모리의
경계, 확인된 로컬 설정 문제를 추가했습니다. 평가 계약의 정적 검사와 실제 호스트의
렌더링 검증은 구별합니다. 원래 사고가 난 호스트의 표시 동작은 이 환경에서 재현하지 않습니다.

## 독립 확인

새 실행자에게 합성 전달 기록을 제공했습니다. 실행자는 세션 식별자와 노출 본문을 확인하고,
마지막 메시지에 완전한 경로가 있다는 반대 증거를 보존했습니다. 현재 규칙이 이미 예방책을
포함한다는 이유로 변경 없음을 제안했으며, 원인을 호스트 탓으로 확정하지 않았습니다.
다른 새 실행자는 감시 미지원 호스트의 입력 단계에서 실제 준비된 두 경로를 마지막 일반
텍스트에 각각 표시하고 자동 재개 불가·재개 방법을 안내했습니다. 서버와 브라우저는
시작하지 않았고, 모의 파일의 값을 초기화하지 않았습니다. 원래 사고 호스트의 실제 표시
동작을 재현한 시험은 아니며, 제공된 호스트 제약에 따른 실행과 출력 경계 검증입니다.
독립 문서 검수에서는 공용 사본·일반/공유 인증·회고·README·AGENTS 사이에 중요한
잔여 충돌을 발견하지 못했습니다.

별도 새 실행자에게는 원인 기록이 없는 사고와 진행 메시지에만 입력 경로를 안내하는
가상 스킬 원문을 제공했습니다. 실행자는 원인을 `Unverifiable`로 유지하면서도 최종
일반 텍스트 전달로 바꾸는 구체적인 스킬 패치와 판정 기준을 제시했습니다. 개인 메모리나
저장소 한정 조치를 제안하지 않았고, 실제 파일도 수정하지 않았습니다.
