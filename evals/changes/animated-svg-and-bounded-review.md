# 이슈 481·482: 독립 SVG 설명과 대형 변경 구간 읽기

두 후보를 최신 소유 스킬과 대조했습니다. SVG의 설명 목적·자료 조사·내용 검토·산출물 소유자는
기존 `tk-explain`과 같습니다. 독립 산출물 형식만으로 새 호출을 추가하지 않고 명시적인 SVG
분기로 통합했습니다. 기본 HTML 경로와 일반 정적 그림 요청은 유지합니다. `tk-video`의 영상·음성,
`tk-explain-diff`의 변경 설명과 수업 소유권을 확장하지 않습니다.

## 상류와 증류 판단

- `praveenvijayan/animdiagram@a8edca75f041ebb75c74ac9d3b3fbec3b9cd5486`의 `README.md`,
  `SKILL.md`, `scripts/timeline.py`, `scripts/check.py`를 읽었습니다. 공유 사건 시간축,
  정적 구조·사건 순서와 `reduced-motion`을 유지하고, 표준 라이브러리만 사용하는 작은 장면
  생성기로 재작성했습니다. 새 런타임·플레이어·브라우저 자동 실행·영상 내보내기·상류 스타일과
  코드 복제는 제외했습니다. 라이선스는 MIT이며 상류 코드·자산·지시문을 복제하지 않았습니다.
- `EveryInc/compound-engineering-plugin@00d0a5bbf1300b2138b65ce724b325dd4dff77ba`의
  `ce-code-review` 배포 템플릿과 PR `#1911`의 실제 변경·검사 근거를 읽었습니다.
  필요한 구간을 도구 한도 안에서 한 번 읽는 조건은 유지하고, 파일 내부의 큰 `hunk`와 필요한
  관계 재독·잘린 구간 복구를 기존 독립 리뷰 프로토콜에 적용했습니다. 고정된 파일 분할기,
  검토자별 사전 파일 제한, 부모 대화 저장소와 상류 실행기는 추가하지 않았습니다.

## 검증과 한계

SVG의 대기열·재시도·사건 전파 예제 3개는 실제 JSON에서 생성합니다. 생성물과 입력의 일치,
사건 순서·동시성·대기 간격·정적 라벨, 입력 수치·노드·간선·라벨 검증, XML·키프레임과
외부 리소스 부재, 기존 파일 보존을 검사합니다. 한국어 글꼴을 갖춘 정적 렌더와 실제 로컬
브라우저에서 각 예제의 이동, 정적 라벨 경계, 이미지 내 재생 및 `reduced-motion`을 별도로
확인합니다. 정적 검사만으로 GitHub 재생이나 모든 문서 서비스의 호환성을 주장하지 않습니다.
처음 제공된 브라우저 다운로드는 손상되어 사용할 수 없었고, 격리 경로에 정상 브라우저를
확보하여 검증합니다. 글꼴과 브라우저는 검증용 임시 의존성이며 산출물에는 포함하지 않습니다.

대형 변경은 현재 합성 `full.diff` 38개 파일·2,471행·152,120자로 모델 행동을 한 번 확인했습니다.
모델은 경계를 먼저 찾은 뒤 겹치지 않는 세 구간을 읽고, 반복되는 합성 주석만 출력에서
생략하여 22,308자의 변경 내용을 출력했습니다. 모든 파일의 변경 코드를 확인하고 멀리 떨어진
생산자·소비자의 필드 계약 불일치를 찾았습니다. 자동 잘림이나 전체 변경 재생성은 없었습니다.
이는 기존 규칙과의 대조 실험, 실제 제품 PR의 전체 리뷰 또는 상류 대비 성능 개선 수치가 아닙니다.
명확한 반복 주석의 출력 생략을 일반 코드·설명 누락 권한으로 해석하지 않습니다.

조건부 구간 읽기 문구를 빼면 이미 받은 파일을 통째로 다시 출력하는 문제가 남습니다.
파일 간 관계 및 제한적 재독 조건을 빼면 비용 절약을 위해 정확성을 줄이거나 `finding` 확인을
금지할 수 있으므로 함께 유지합니다. 상시 본문을 늘리는 대신 기존 공통 리뷰 참조 한 곳에서
정본을 관리하고 기존 동기화로 패키지 로컬 사본을 유지합니다. 이는 행동 평가 1회와 저자의
계약 대조이며 보편적인 개선 효과를 입증하지 않습니다.

README: `tk-explain`의 공개 출력 선택지에 SVG가 추가되어 짧은 카탈로그와 에이전트 설명을
함께 갱신했습니다. 스킬 이름·기본 호출·설치 방식은 바꾸지 않았습니다. SVG 전용 진입 문장은
독립 파일 요청에서만 읽는 참조를 선택하도록 하며, 기존 HTML·정적 요청에 동작을 추가하지 않습니다.
