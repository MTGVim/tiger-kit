# 문장 간결화와 학습 내용 보존

후속 첨부안의 비교 실행에서 첫 적용안보다 대조군이 낫다는 독자 판정이 보고됐습니다.
수정안은 상황·앞쪽 그림·이해 확인을 되찾았지만 독자의 최종 비교 판정은 아직 없습니다.
이 상태를 검증 완료로 올리지 않고 다음의 좁은 교정만 반영합니다.

- 짧게 쓰는 대상을 문장으로 한정하고, 필요한 상황·그림·인과 단계·선택한 요약 및
  이해 확인을 분량 때문에 삭제하지 않도록 합니다.
- 현실적인 상황이 동기가 되는 주제는 상황을 먼저 제시하고 핵심 그림을 읽는 순서에서
  가까이 둡니다. 가로 배치를 강제하지 않습니다.
- 표에서 직접 비교하는 해시·버전·키의 정확한 값에는 코드나 칩을 허용합니다.
- 독립 검토에서도 간결화를 위해 필요한 설명이 빠졌는지 확인합니다.

요약 상자의 기본 생성과 첫 문단에 대한 별도 강제 규칙은 미검증 후보로 유지합니다.
요약과 이해 확인의 기존 선택 기준은 바꾸지 않습니다. 문장별 주장 하나라는 기존
기준은 유지하며 중복 규칙을 추가하지 않습니다. 서식 참조는 기존 도구로 각 패키지의
일반 파일에 동기화합니다. 문맥 예시와 서식 수치만으로 독자 이해 향상을 주장하지 않습니다.

기준 대비 확인: 같은 내용의 간결화 요청에서 상황·그림·선택된 이해 확인을 보존하는
경로와, 표 값 자체가 비교 대상인 경로를 평가에 추가했습니다. 기존 문장 명료성·출처
연결·검증 수준과 선택형 이해 확인 계약은 유지합니다.

독립 검토에서 발견한 평가 충돌도 교정했습니다. 새 평가를 기존 문서 교정이 아닌 새 HTML
생성 요청으로 구성하고, 구체적인 비교 값과 출력 경로를 제공합니다. 판정자는 최종 링크만
보지 않고 지정된 파일을 읽습니다. 이전 서식 평가의 복사·검색 전용 조건은 명시적
마이그레이션을 통해 정확한 비교 조건까지 허용하며 기존 나머지 기준은 유지합니다.
