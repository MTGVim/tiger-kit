# 설명 대상 보존 및 문서 탐색 개선

- #443의 원 사건은 첨부된 수학 명제를 HTML에서 생략한 사례입니다. 이미 존재하는 자기완결성 계약을 대상·조건의 충실한 재현과 산출물만 읽는 독자 확인으로 좁게 보완합니다. 기존 일반 설명 평가와 #376/#384의 문맥 판단을 유지하며, 금지 표현 정규식과 원본 이미지 강제 복제는 도입하지 않습니다.
- 제공된 이미지를 충실히 전사한 입력, 대상 누락 반례, 대상 보존 성공 사례, 일반 개념 설명 대조군을 기존 평가에 추가합니다. 판단은 의미 기반이며 정적 문자열 검사로 명제의 의미를 판정하지 않습니다. `tk-explain-diff`는 자체 완결적인 배경과 전후 동작을 유지하면서 정확한 SHA·경로·행 근거를 각주로 참조할 수 있습니다.
- #444는 기능적 UX 관찰을 바탕으로 독립적으로 구현한 변경입니다. 기존 테마 CSS·JS 정본을 확장하여 문서에만 선택적으로 플로팅 목차·상하 이동·각주·하단 참고문헌을 적용하고 연구 보고서 템플릿을 갱신합니다. 패키지 사본 및 템플릿 인라인 블록은 기존 동기화 검사로 보호합니다. 제품 시제품과 QA 체크리스트에는 문서 셸을 강제하지 않습니다.
- 유지: 네이티브 해시와 방문 이력, JavaScript 없이 읽기와 목차·인용 탐색, 시스템/라이트/다크, 동작 감소, 오프라인 단일 파일, 기존 출처 결합, 키보드 초점, 설치 패키지 자기완결성. 제외: 외부 UI 코드·스킨·문서·아이콘 복제, 새 런타임이나 서브에이전트 계층, 프레임워크, 호버 미리보기.
- 원생성 `details` 및 네이티브 앵커 동작과 부드러운 스크롤 조건은 2026-10-09에 MDN `<details>` 및 `scroll-behavior` 문서를 확인했습니다. 외부 코드를 복사하지 않았으며, 나무위키 UX 관찰은 #444에 기록된 기능 요구만 적용합니다. 문서 콘텐츠 라이선스를 UI 소스 라이선스로 취급하지 않습니다.
- 현재 소스와 계약 대조, 독립적인 개념 설명 실행, `Playwright`의 `headless` 탐색 회귀, 공통 자산 정합성·설치 검사 및 로컬 릴리즈 게이트로 확인합니다. 브라우저 검증은 기존 설치된 `Chromium` 131을 재사용하며 외부 접속과 사용자 프로필을 사용하지 않습니다. 검증용 한글 글꼴은 일시적인 `FONTCONFIG_FILE`에서만 사용하고 패키지 자산에 포함하지 않습니다.
