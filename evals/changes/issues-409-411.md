# #409-#411: 자동연구 평가 무결성과 모델 호출

기준 `main`: `578313ae35fa5ec50ac6118c1e66027c39f84911`.

## 동작 변경

- 지표로 평가할 때 평가 명령·기준·데이터와 수정 가능 범위를 고정하고, 간접 설정 변경까지 검사합니다. 평가기 수정은 새 계약과 기준 평가로 분리합니다.
- 합리적으로 확보할 수 있는 독립 검증 근거는 채택 판단에 사용하며, 검증 근거를 탐색에 재사용한 한계를 보존합니다. 정성 연구와 별도 검증이 불가능한 조사도 계속할 수 있습니다.
- 예산·시간·우선순위 때문에 실행하지 않은 후보는 실제 실패·반증과 구분합니다. 실제 반증과 기반 환경 문제도 분리합니다.
- 중요한 확률적 결과는 비용과 변동성에 맞게 독립 반복을 검토하며, 불확실성이 남으면 확정적인 채택을 보류합니다. 결정론적 실험에는 반복 횟수를 강제하지 않습니다.
- 독립 검증에는 객관적인 계약과 원래 근거를 전달하며 불필요한 자기평가와 선호 방향은 제외합니다.
- 필요한 항목에만 파생 근거 링크를 남기고 상위 방향에 근거가 있는 교훈을 반영합니다. 자식 결과를 다른 항목에 무조건 전이하지 않으며 전체 트리 실행 체계는 추가하지 않습니다.
- 사용자 추가 요청에 따라 `tk-autoresearch`를 `hybrid`로 바꾸고 모델 호출을 허용합니다. 구체적인 지속 연구·재개 요청과 바깥 `/loop`는 기존 로컬 권한으로 계속할 수 있으며, 모델 선택이나 저장된 상태만으로 권한을 만들지 않습니다.

## 근거와 범위

`Arbor`, `Gyubin/autoresearch`, `Luxas`의 최신 기본 브랜치를 고정해 비교했습니다. 적용·제외 판단은 패키지 `references/sources.md`에 기록하고 원본 라이선스와 필요한 NOTICE를 보존합니다. 라이선스 파일이 없는 `karpathy/autoresearch` 원본과 사용자 정의 라이선스인 `AI-Scientist-v2`는 증류 원본에 편입하지 않았습니다.

## 검증 계약

- 기존 행동·호출 사례를 삭제하거나 약화하지 않고 행동 사례 17건과 호출 사례 10건, 카탈로그 사례 2건을 추가합니다.
- 모델 호출의 검증 사례는 긍정 9건과 부정 9건으로 일회성 조사·학습·구현 경계까지 확인합니다.
- 독립 정책 시뮬레이션은 예상 정답 없이 새 행동 사례의 요청과 설치 패키지 정본만 제공합니다. 별도 검수자는 이슈 원문과 변경을 대조합니다.
- 최종 커밋은 최신 `origin/main` 기준 `run_seed_release_gate.py`로 검사하며, 필수 로컬 검사·소비자 설치·기존 평가 계약 보존을 확인합니다.

이 정책 시뮬레이션은 규칙 적용을 검증합니다. 실제 호스트의 `/loop` 장기 운영, 상류 실행 체계와 연구 성능을 재현했다고 주장하지 않습니다.
