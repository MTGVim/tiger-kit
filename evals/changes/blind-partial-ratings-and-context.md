# 블라인드 비교의 부분 평가와 평가 맥락

## 근거와 처분

- 조사 기준은 `92d6e5349786b127fe9a04592c85d4ebccbd31d5`이며, 최종 검증은 `cf1584d67865d0cf6d813dd4d52b395b63db486e`에 재적용한 소스를 사용합니다.
  사용자 회고는 일부 미평가 항목, 주제·대본의 스크롤 문제, 실제 `select` 입력을 검증하지 못한 사례를 제공합니다.
  원래 평가 JSON이나 수정된 갤러리가 이번 요청에 없으므로 실제 평가 결과와 당시 구현은 재판정하지 않습니다.
- 현재 소스의 공개 버튼에는 완전 평가를 요구하는 조건이 없습니다. 기존 부분 내보내기·공개 동작은 `KEEP`하고,
  첫 공개 시 현재 평가 가능한 출력의 미평가 수를 확인한 뒤 취소하거나 계속하는 선택을 `ADAPT`합니다.
  실패한 출력과 제거·변경된 과거 출력은 해당 수에 포함하지 않습니다. 공개 이력은 다시 가려도 보존합니다.
- [고정 위치 명세, 2025-10-07](https://www.w3.org/TR/2025/WD-css-position-3-20251007/#sticky-pos)의
  항목 컨테이너 안에서 유지되는 `sticky` 위치를 `ADAPT`합니다. 각 항목의 주제·제목·공통 대본·평가 안내를
  함께 표시하고 긴 내용은 화면 높이의 45% 안에서 키보드로 스크롤할 수 있게 합니다.
- [확인 대화상자 명세, 2026-10-22](https://html.spec.whatwg.org/multipage/timers-and-user-prompts.html#dom-confirm-dev)의
  확인·취소 선택을 `ADAPT`하며 미평가 상태에서 확인하지 않으면 기존 공개 이력과 평가를 보존합니다.
  별도 다이얼로그 프레임워크·서버·DB는 `OMIT`합니다.
- 기존 `summarize`는 `null`과 생략된 행을 이미 미평가로 집계합니다. 그 계산은 `KEEP`하며,
  `stdin` 입력·저장 없는 `stdout`·익명 집계 옵션을 `ADAPT`합니다. 후보 이름 공개 권한은 노출 이력과 구분합니다.
  대화에서 집계를 놓친 일을 범용 분석 스킬이나 `tk-browser-verify` 결함으로 승격하지 않습니다.
- 자동 승자, 불균등 표본의 통계적 우열, 점수 조작, 실제 사용자 평가 결과 산출은 `OMIT`합니다.
  `README: no public change`. 대상은 기존 `skills/tk-blind-comparison/`의 내부 동작과 명령 참조이며
  공개 카탈로그 이름·설명·호출 방식은 바뀌지 않습니다.

## 지시문과 검증

상시 본문은 기존 검증 목록에 부분 공개 확인·취소와 실제 `native` 점수 선택을 추가하며,
항목 문맥을 고정하는 계약만 보강합니다. 이 계약을 제거하면 `description`만 일반 문단으로 출력하던
기존 동작으로 돌아갑니다. 익명 집계와 `stdin` 사용법은 결과 처리 분기에서만 읽는 참조에 둡니다.

회귀 검사는 공개 취소 시 저장값·공개 이력 보존, 미평가 상태의 명시적 공개, 실패·과거 평가 제외,
대본의 이스케이프와 정체 단서 거부, 익명 부분 집계·전체 개수 정합성, `stdin` 중복 키 거부와 파일 미작성을 다룹니다.
브라우저 증거와 릴리즈 관문 결과는 이번 실행의 무시된 `evidence` 디렉터리에 보존합니다.
