# `tk-course` 실제 화면 선택과 플레이어 안정성

## 근거와 변경

2026-10-24 사용자가 제공한 후속 사고를 최신 정본의 제작 계약·플레이어·브라우저 판정과 대조했습니다. 앞선 시각 자료·대기·고정 캔버스 개선은 이미 정본에 있어 반복하지 않았습니다.

- 실제 화면을 요청한 수업에서는 제공 자료와 원본 후보의 픽셀·버전·언어·사용 범위를 확인합니다. 자체 도식은 보조 자료이며 요청한 실제 화면을 대신하지 않습니다. 별개 개념은 시각 자료가 있는 장면으로 나누고 필수 화면을 확보하지 못하면 해당 목표를 미완성으로 보고합니다.
- 모든 자막은 표시된 미디어 안의 오버레이를 사용합니다. 대본 열림 기준 열·행을 유지하여 닫을 때 미디어·내부 이미지·컨트롤을 확대하지 않습니다. 정상 대기는 버튼과 비흐름 접근성 알림 영역으로 알리며 오류·완료 안내는 보존합니다.
- 홈·현재 강의 링크·목차·다음 강의·진도 재진입은 정지 상태를 준비합니다. 명시적인 재생 동작과 기존 실제 미디어 시간 축·5초/1.8초/1.2초/문장 간격을 유지합니다.
- 이미지 입력만 기존 `ffprobe`/`ffmpeg`로 코덱·컨테이너·크기·전체 디코딩을 확인합니다. `PNG` 청크 `CRC`/`IEND`, `JPEG` 표식·종료 구조와 `WebP` `RIFF` 완결성을 함께 확인하여 `FFmpeg`가 허용하는 잘림도 거부합니다. `JPEG`의 정상적인 후행 자료와 점진적 형식은 보존합니다. 파일·픽셀·할당·시간 한도를 두고 `Pillow` 필수 가져오기를 제거합니다.
- 동일한 `hook` 제목은 한 번 표시하고 별도 강조문은 보존합니다. 기존 리비전별 재생 위치 키와 코스/강의/큐 식별자·원본 음원·학습 이력·독립 스크롤·권리 고지를 유지합니다.

## 검증과 범위

기존 `Python`·브라우저 평가를 보강하여 `Pillow` 없는 실제 하위 프로세스의 `PNG`/`JPEG`/`WebP` 빌드·임베딩, 손상/잘림/위장/과대/시간 초과, 경로 안전·내용 지문, `hook` 제목, 모든 도식의 자막 오버레이, 데스크톱·좁은 화면·중간 분기 폭의 반복 토글·기본 전체화면·창 안 확대, 실제 음원 재생 종료 이벤트에 따른 대기와 좌표 불변, 재생 전 장시간 정지와 재생·일시정지 전환·저장 위치 진입을 확인합니다. 학습 적합성과 청취 효과는 기계 검사로 확정하지 않습니다.

실제 사용자 코스의 작성 원본·원래 미디어가 제공되지 않았으므로 백필이나 기존 배포본 교체는 수행하지 않습니다. 회귀 검사 입력은 적용 경로만 증명합니다. 별도 환경 설치·사용자 환경 삭제·새 스킬·`CI`·실행 환경은 추가하지 않습니다.

상시 추가 문장은 실제 화면 요청을 일반 도식 선택으로 희석하는 행동과 기계 검사만으로 완료하는 행동을 제한합니다. 내부 크기 계산과 도구 수치·백필 절차는 조건부 참조와 실행 도구가 소유합니다.
