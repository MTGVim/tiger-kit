# 선택한 설명 영상의 담당 분리

`tk-video` 후보는 소프트웨어·개념의 선택한 MP4/GIF 조립과 검사만 소유합니다. 실제 브라우저·데스크톱 캡처와 앱 판정은 기존 담당자, 게시 권한은 `tk-pr-media`에 남깁니다. 패키지 사이에는 캡처·장면 매니페스트를 전달하고 실행 스크립트를 직접 가져오지 않습니다. 내레이션 모듈을 제거한 설치에서도 자막 영상이 생성됩니다.

기존 `evidence`의 관찰 시간은 유지합니다. 새 `explainer`는 장면 표시 시간과 실측 음성 길이를 사용하고 `timing: presentation`을 반환합니다. 완성본의 디코딩·형식·길이·선택 음성·자막 범위 검사와 실제 시각·발음 확인은 구분합니다. 앱 판정을 뜻하는 기존 `verification_status: not-assessed`는 보존하고 미디어 검사에 별도 `media_validation`을 씁니다.

설계 출처와 `keep | adapt | omit`은 `skills/tk-video/references/sources.md`에 기록했습니다. 원본 코드·자동 설치·받아쓰기 검증·터미널 릴·`Windows` 지원은 도입하지 않습니다. 공통 `questions.md` 내용은 확장하지 않습니다. `README`와 `MIGRATION.md`는 새 패키지 후보에 맞춰 갱신합니다.

채택 조건은 사용자 피드백의 `I1-I7/N1-N4` 실제 통합 검증 전체 통과입니다. 정적 카탈로그·패키지 설치 검사나 단독 조립기 시험을 스킬 간 통합 검증으로 세지 않습니다. 호스트의 실제 로드 기록, 매니페스트, 디코딩 결과와 실행 전후 캐시·메모리 비교가 없는 항목은 `Unverifiable`이며, 이 조건을 충족하기 전 `main`에 채택하지 않습니다.
