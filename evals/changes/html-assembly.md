# 설명·학습 HTML 조립 비용 절감

`tk-explain`, `tk-explain-diff`, `tk-teach`의 기본 단일 HTML 출력을 유지하면서, 본문 조각을
공통 UI와 조립하는 `build_html.py`를 추가했다. 테마·글자 크기·목차·이동·내보내기 UI와
공통 CSS/JS는 모델이 재작성하지 않고 로컬에서 삽입한다. 공통 자산의 정본과 패키지별
자체 완결성은 기존 동기화·불일치 검사에 연결한다. 기존 생성기 수정과 특수 UI는 보존한다.

추가 지침은 새 HTML 조립 분기에만 읽는다. 원인·결과 설명, 출처/스냅샷, 연습과 피드백,
접근성 및 정적·브라우저 검증은 유지한다. 채팅 선행 질문과 MD 중간 단계는 추가하지 않는다.
상류 조사와 유지·수정·제외 판단은 각 스킬의 기존 출처 파일에 기록했다.

독립 실행은 실제 로컬 코드를 설명하는 새 HTML을 생성하며, 설치 패키지 테스트는 목차·
이스케이프·테마 설정 보존·기존 파일 보호·내보내기 왕복을 확인한다. 이는 실행/구조
근거이며 통제된 모델 비용·전체 생성 시간 또는 학습 성과 측정으로 간주하지 않는다.

`README: no public change`: 세 스킬의 호출 방식·카탈로그 설명·출력 형식은 바뀌지 않았다.
