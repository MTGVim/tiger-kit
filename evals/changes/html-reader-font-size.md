# 공통 HTML 글자 크기 선택

사용자의 명시적인 재사용 기능 요청을 기존 공통 테마에 반영합니다. 기준은 `cf4ea4f`의
`tk-explain/assets/html-theme.{css,js}`, 두 인라인 템플릿, 공통 HTML 및 시각 질문 지침입니다.
외부 테마나 새 런타임을 도입하지 않습니다.

- 보존(`keep`): 기존 테마 라디오, 브라우저 저장 거부 처리, 오프라인 및 JavaScript 없는 읽기와 100% 글자 크기를 유지합니다.
- 반영(`adapt`): 테마 바로 왼쪽에 네이티브 선택기를 자동 삽입합니다. 50-200%를 25% 단위로 제공하며 기본은 100%입니다. 선택값은 테마와 다른 키에 저장합니다.
- 반영(`adapt`): 공통 글꼴 토큰과 문서·코드·목차의 고정 글꼴, QA 전용 글꼴을 같은 비율로 조절합니다. 페이지 확대·미디어 크기는 바꾸지 않습니다.
- 제외(`omit`): 스킬별 복제 UI, 별도 설정 파일, 기존 사용자 산출물의 일괄 수정은 추가하지 않습니다.

10개 패키지의 실제 배포 JavaScript를 실행하는 기존 모의 DOM 테스트를 확장하여 전체 선택값,
100% 기본값, 새 실행의 저장값 복원, 잘못된 저장값과 읽기/쓰기 거부, 테마 독립성을 검사합니다.
QA의 실제 인라인 스크립트와 체크리스트 초기화가 두 읽기 설정을 보존하는지도 검사합니다.
이것은 실제 브라우저 렌더링이나 키보드 조작을 입증하지 않습니다. 이 환경에는 설치된 브라우저가
없으므로 화면·모바일 줄바꿈·실제 키보드 검증은 수행하지 못했습니다.

새 지침의 삭제 비교: UI 위치·자동 삽입 설명을 빼면 생성자가 선택기를 중복 작성할 수 있습니다.
배율을 한 번만 적용한다는 지침을 빼면 사용자 정의 `px`/`rem` 글꼴이 그대로 남거나 공통 토큰이
중복 확대될 수 있습니다. 줄바꿈·JavaScript 미사용 및 검증 경계를 빼면 고정 높이 잘림이나 저장 거부를
누락할 수 있습니다. 수치·저장 상세는 배포 코드로도 검사합니다. 필수 생성 규칙 968바이트를
추가하며 해당 항상 읽기 묶음의 한도만 1000바이트 올립니다.

`README: no public change`: 공개 이름·설명·호출·카탈로그는 유지하며 공통 테마, 생성 지침,
기존 템플릿과 회귀 테스트만 변경합니다.
