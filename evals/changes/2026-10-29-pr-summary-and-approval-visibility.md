# PR 요약 이미지와 승인 대기 상태 개선

- 캡처 스크립트와 두 패키지의 SVG 변환기에서 실제 경로로 CLI 진입 여부를 판정합니다.
  모듈을 불러올 때 실행하지 않는 동작, 기존 파일 덮어쓰기 방지와 브라우저 부재 오류를 유지합니다.
- PR·이슈용 요약 이미지 요청에는 PNG 한 장을 만들고, 명시적인 HTML 요청과 변경 정확성 리뷰는
  유지합니다. 업로드와 필수 실행 근거 검증은 기존 담당 스킬에 남깁니다.
- PR 미디어 결과 머리말은 사용자 언어를 따릅니다. 기계 판독용 키와 상태 줄, 업로드 검증은 유지합니다.
- 실제 승인이 없을 때만 모든 답변 첫 줄에 구현 전 상태를 표시합니다. 승인 후에는 표시를 중단하며,
  부수 질문에 대한 짧은 긍정은 실행 승인으로 해석하지 않습니다.

`README: no public change`. `skills/tk-explain/SKILL.md`, `skills/tk-pr-media/SKILL.md`,
`skills/tk-prep/SKILL.md`의 카탈로그 메타데이터와 호출 담당은 바뀌지 않았습니다.

지침 삭제 전후 비교: 목적지 분기가 없으면 보고된 긴 페이지가 허용되고, 승인 대기 안내가 없으면
부수 답변에서 구현 상태가 드러나지 않으며, 언어 분기가 없으면 영어 머리말이 유지됩니다.
추가한 지침은 각각 이 결정을 바꿉니다. 이미지 전용 검사는 조건부 참조로 분리하고 기존 근거·리뷰·업로드
규칙을 재사용합니다. 추가한 판단형 평가 사례는 명세이며, 모델 평가를 실제로 실행했다는 주장이 아닙니다.
