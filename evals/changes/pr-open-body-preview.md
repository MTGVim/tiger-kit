# PR 본문 구성과 승인 미리보기

2026-10-08 사용자가 제공한 회고와 현재 `tk-pr-open` 본문을 대조했습니다.
본문의 구성 단위, 미리보기에서 생략할 템플릿 문구, 필수 읽기 자료의 위치가 명확하지 않았습니다.
최신 `mattpocock/skills`의 `skills/engineering/pr/SKILL.md`도 소스 식별자
`84dd4fb2f068e9f6282690235d20dd505b418119`에서 확인했습니다. 상류의 간결한 본문과
관심사에 맞는 설명 원칙은 유지하고, 강제 템플릿이나 새로운 발행 방식은 도입하지 않았습니다.

- 최신 `base...HEAD` 전체 변경을 리뷰 가능한 관심사별로 설명합니다. 기존 PR을 갱신할 때는
  영향을 받은 절을 다시 도출합니다. 커밋 나열은 저장소 지침이나 템플릿이 요구할 때만 사용합니다.
- 승인 미리보기에는 제목과 이번 발행에서 채우거나 바꾼 절만 보여줍니다. 변경 없는 템플릿 제목,
  주석과 체크리스트는 생략하지만 게시용 전체 본문에는 그대로 보존합니다.
  변경한 체크리스트 항목은 미리보기에서도 확인할 수 있으며 전체 본문은 요청 시 보여줍니다.
- 승인에 필요한 읽기 자료는 대화 또는 기존 발행 계획 규칙이 파일을 요구할 때 저장소의
  `.tigerkit/` 산출물로 제공합니다. 세션 전용 임시 경로는 읽기 자료로 안내하지 않습니다.

실행 계약의 변경은 `skills/tk-pr-open/SKILL.md`에 한정합니다. 제목 판단 우선순위,
템플릿의 절 순서와 원문 보존, 정확한 발행 계획, 기존 승인 경계는 유지합니다.
README의 PR 준비 및 승인된 발행 설명은 여전히 같은 동작을 설명합니다.

기존 템플릿 평가가 기본 미리보기에도 `Checklist` 출력을 요구하여 새 규칙과 충돌했습니다.
해당 사례에는 전체 본문을 요청하는 입력 조건을 추가해 원문 구조 보존과 출력 확인을 유지했습니다.
기본 발행 계획 평가도 내부 전체 본문과 사용자 미리보기를 구분하도록 맞췄으며,
기존 원격 수정 금지와 승인 대기 검사는 모두 유지합니다.
관심사별 구성, 최신 범위 재도출, 템플릿 문구 생략, 읽을 수 있는 미리보기 위치 사례를 추가했습니다.
이 변경의 검증은 소스와 평가 계약을 대조하는 간접 검증이며 실제 업무 PR을 생성하거나 수정하지 않습니다.
