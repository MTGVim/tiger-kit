# 통제된 연구 비교

같은 합성 자료에서 기존 bounded 조사와 통합 연구를 비교합니다. 기존 조사는 짧은 비교를 끝낸 뒤 추가 질문이 필요하면 부정 결과를 제공하고 다시 조사합니다. 양쪽에 같은 이전 근거와 실제 도구를 제공합니다. 사례는 (1) 대소문자가 다른 ID와 발생 횟수 보존 방식의 짧은 비교, (2) lower-case·set 실패를 재사용하고 철자와 독립적인 signed-session 신호를 찾는 후속 조사입니다.

기록 항목은 최종 결정·발견·중복 탐색·전체 소요와 마지막 결과까지 시간(첫 통찰 지연의 대용값임을 명시)·토큰 사용·추적 변경·상태/HTML 생성·후속 개입·부정 결과 재사용입니다. 양쪽의 read-only/로컬 상태 권한 차이를 공개하며 HTML 생성 비용을 결과의 품질 향상으로 간주하지 않습니다. 실제 외부 조사, 운영 데이터, 통계적 성과와 장기 호스트 재개는 검증 범위가 아닙니다. 동률과 후보 비용 증가도 그대로 기록합니다. 새 상태나 보고서가 생겼다는 사실만으로 우위를 선언하지 않습니다.

같은 `sources/contract.md`, `sources/observations.json`, 후속 `prior-result.md`를 사용하고 실험 시 계약 자료의 해시를 고정합니다. 이전 실패를 재실행하지 않고도 independent signed-session 정보를 실제 관찰에서 찾는지 비교합니다. 고정 자료는 `case.json`에 있습니다. 실행 산출물은 저장소의 무시되는 증거 폴더에 두며 아래 관찰은 이 한 과제의 결과이며 일반적인 성능 우위를 뜻하지 않습니다.

## 실제 실행 관찰

2026-10-07의 `codex-cli 0.160.1`에서 같은 합성 입력·300초 제한으로 실행했습니다. 정책 답변 비교와 실제 도구 실행을 구분합니다. 기존 bounded 경로를 짧은 조사 뒤 같은 부정 결과로 다시 호출했습니다.

| 과제 | 기존 bounded | 통합 후보 | 판단 |
| --- | --- | --- | --- |
| 짧은 ID·빈도 비교 | 27.905초, 출력 1,255토큰 | 111.337초, 출력 5,739토큰 | 결정은 동률입니다. 후보는 상태 없이 HTML을 만들었으나 비용이 늘었습니다. |
| 부정 결과를 제공한 후속 탐색 | 108.884초, 출력 5,102토큰 | 300초 제한에서 미완료 | 기존 경로도 서명 신호를 발견했습니다. 후보의 기록·평가 틀은 효용 우위가 입증되지 않았습니다. |

후속 후보의 부분 산출물은 실패 근거로 보존했습니다. 작은 결정에서는 한 정본에 재개 정보와 부정 결과를 보존하고, 별도 거래 영수증·중복 설명·평가 틀을 기본 생성하지 않도록 지침을 축소했습니다. 같은 부분 근거에서 다시 시작한 보정 실행도 300초 안에 완료하지 못했으며, 독립적인 새 입력 비교로 계산하지 않습니다. 실패를 `REJECT`나 성공한 재개로 바꾸지 않습니다.

시간은 최종 출력까지의 지연이며 첫 유용한 통찰 시각은 측정하지 않았습니다. 토큰은 출력 기준이고 모델 호출의 누적 입력/캐시 차이는 별도 실행 기록에 남깁니다. signed-session 신호가 독립적이라는 관찰은 위조 판정의 실증이 아니며 실제 서명 검증·정답 레이블이 없어 그 효능은 미확인입니다. 운영 자료, 장기 세션 재개, 통계적 성능은 검증하지 않았습니다. 이 비교는 필요한 기록·HTML과 연구 결과 품질을 분리하고, 추가 ceremony를 정당화할 근거가 없음을 보여줍니다.
