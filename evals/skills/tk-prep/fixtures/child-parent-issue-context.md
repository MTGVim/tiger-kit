# 자식·상위 이슈 맥락 (평가용 예시)

## 자식 이슈 `WEB-812`

배너 양식에 `pt-BR` 지원을 추가한다. 번역이 없을 때는 연결된 API 동작을 따른다.

## 상위 이슈 `WEB-700` 본문

모든 배너 양식에 적용할 공통 규칙: 선택한 언어의 번역 콘텐츠가 없으면 항상 영어 콘텐츠를 표시한다. 이 제품 규칙은 배너 다국어 적용의 모든 자식 이슈에 적용한다.

## 상위 이슈 댓글

- 제품 담당자: "모든 배너 화면에 영어 대체 규칙을 계속 적용합니다. 자식 이슈에서 이 결정을 다시 열지 않습니다."
- 백엔드 담당자: "API는 요청한 로케일로 번역된 필드만 반환합니다. 번역이 없는 필드는 생략되며, 클라이언트가 제품 대체 규칙을 적용할 수 있습니다."

## 연결된 API 문서

API는 요청한 로케일로 번역된 필드만 반환합니다. 번역하지 않은 필드는 응답에서 생략됩니다. 이 문서는 전송 동작을 설명하며 제품 화면 표시 정책을 정하지 않습니다.
