# 현재 head 요약

6. 처리 가능한 답글이나 코드 변경을 성공적으로 발행하고 처리 가능한 모든 스레드를 닫은 뒤, 정확한 현재 head를 새로 읽고 현재 head 요약 코멘트가 정확히 하나이며 `<!-- tigerkit:pr-summary:<HEAD_SHA> -->`를 포함하는지 확인합니다. `<HEAD_SHA>`는 정확히 관찰한 head SHA로 바꿉니다. 이 요약은 재검토 요청이 필요하지 않아도 필수입니다. 이번 실행에서 답글이나 코드 변경을 발행하지 않았다면 요약을 생략합니다. 요약은 스레드를 닫은 뒤 게시하거나 갱신해야 합니다. 현재 head의 마커가 이미 정확히 하나 있으면 시점과 재검토 마커를 검증합니다. 스레드를 닫기 전에 작성되었거나 불완전하면 중복 생성하지 말고 같은 코멘트를 갱신합니다. 확정해 둔 코드 변경 집합에서 요청 가능한 각 검토자에 대해 같은 코멘트 안에 숨겨진 `<!-- tigerkit:pr-rereview:<HEAD_SHA>:<LOGIN> -->` 마커를 하나씩 포함합니다. 계정 봇, 작성자, 인증된 사용자, 아직 유효한 승인자, 멘션만 가능한 검토자 또는 답글만 필요한 지적에는 이 마커를 추가하지 않습니다. 이전 head의 요약으로는 이 요건을 충족할 수 없습니다. 요약은 내부 처리 기록이 아니라 검토자에게 보내는 실제 메시지로 작성합니다. 식별 가능한 모든 사람 검토자를 `@mention`으로 지칭하고, 각 지적을 처리 분류, 근거, 코드 대응, 후속 티켓 상태에 대응시켜 자연스러운 문장이나 그에 맞는 표로 설명합니다. 검토자가 멘션만 가능하면 이를 명시합니다. 검사나 합계만 나열하는 3인칭 완료 로그를 발행하지 않습니다.
