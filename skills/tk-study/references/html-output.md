# HTML Output

Use an available renderer when suitable; otherwise choose a minimal presentation around the
already verified lesson content. One offline HTML file must inline CSS, SVG and any JavaScript,
with no external assets or runtime requests. Source hyperlinks are allowed. Escape all source/code
text for its HTML or script context; never insert retrieved markup as executable content.
Use semantic headings, keyboard-accessible controls, readable contrast and non-color-only cues.
Preserve code whitespace with `<pre><code>`. Keep answers collapsed until an explicit reveal;
labels and initial styles must not expose correctness. Offline HTML cannot hide answers from
source inspection, so do not claim exam security. Inspect saved HTML and interactions when a
local renderer is available without launching the user's browser. Disclose unperformed rendering.
