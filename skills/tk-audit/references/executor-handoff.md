# Cheaper-model handoff

Write each `AUD-*` finding so the next model can act without this conversation
or the audit session.

- **Context closure**: include exact paths/symbols, current evidence,
  repository conventions, and a relevant exemplar.
- **Boundaries**: include in/out scope, assumptions, dependencies, and concrete
  STOP/report-back conditions.
- **Verification**: include commands, expected results, audited HEAD, and drift
  handling.
- **Safety**: include only a secret location and credential type; never copy
  values, cookies, tokens, or private identity.

This contract prepares a candidate for `tk-drive`; it grants no implementation,
unit, or remote-publication authority.
