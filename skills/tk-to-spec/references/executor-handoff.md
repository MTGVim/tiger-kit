# Cheaper-model handoff

Write a Ready source that a cheaper executor can use without this conversation,
the audit session, or another artifact in memory.

- **Context closure**: inline the goal, exact paths/symbols, current-state
  evidence, repository convention, and the relevant exemplar.
- **Boundaries**: list included and excluded scope; do not say “as discussed”.
- **Verification**: name commands and expected results already verified during
  preparation; include the source HEAD and drift check.
- **Decisions**: record confirmed decisions, assumptions, implementation
  constraints, and concrete STOP/report-back conditions.
- **Secrets**: record only a path and credential type; never copy values,
  cookies, tokens, or private identity into the artifact.

This is a handoff quality contract, not permission to implement, create ticket
status, publish remotely, or bypass the owning skill's gates.
