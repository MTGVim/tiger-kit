# 단일 대응표의 모델 추천 판단 기준

모델 선정은 `derive()`나 점수표로 자동 실행하지 않습니다. 에이전트가 최신 원본을 조사하고 사용자가 선택한 관점(고성능 / 표준 / 절약)에 따라 공급자·`light`·`standard`·`top`별 후보를 제안합니다. 선택 관점은 저장하지 않습니다. 티어별 업무와 독립 리뷰 정의는 [위임 계약](../../tk-engineering/references/delegation.md)을 따릅니다.

## 1. 비교 근거

1. **우선 자료**: 코딩 에이전트의 실제 작업 성능과 작업당 비용입니다. 인용할 벤치의 정확한 이름·버전·실행 호스트·모델 ID·effort·측정 날짜·출처를 제시합니다. 우선 확인처는 [Artificial Analysis Coding Agent Index](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex), 공개 SWE-bench/Terminal-Bench 등과 모델 제공자의 공식 지원·가격 문서입니다.
2. **조건 통제**: 같은 호스트·벤치 버전에서 각 후보가 실제로 사용할 effort로 측정한 수치만 직접 비교합니다. 모델 간 agent 도구나 측정 조건이 다르면 각각의 조건과 수치를 구분해 제시합니다. 동일 작업당 API 비용, 성공당 비용, 실행 시간은 별개의 지표입니다. API 사용량을 사용자의 구독 한도 소모로 환산하지 않습니다.
3. **종합 지능 점수**: 후보를 탐색하는 보조 기준이며 SWE·코딩 성능의 대용이 아닙니다. 모델·effort별 해당 시점의 확인된 값을 사용하며 결측은 미확인으로 표시합니다.
4. **커뮤니티**: Reddit·공개 실험의 모델·effort·작업 범위·성공/실패·재시도·비교 조건을 기록합니다. 사례의 질과 표본 크기를 구분합니다. 구현 성공과 리뷰 품질은 각 역할의 실제 근거로 별도 평가합니다.
5. **실행 신뢰성**: 조기 종료, 거짓 완료, 미착수, 재지시, 반복 실패를 따로 표시합니다. 사용자 관찰은 위험 신호이지 재현된 실패율이 아닙니다. [Terra Effort 고정 시범](../../../docs/adr/0009-route-mode-terra-retrial.md)을 참고합니다.

## 2. 최적화 관점

- **고성능**: 코딩 완료율과 품질, 독립 리뷰의 실효성을 최우선으로 하며 비용이 더 높아도 허용합니다.
- **표준**: 검증된 성능과 작업당 비용의 균형을 우선하며 품질 향상 대비 추가 비용을 제시합니다.
- **절약**: 업무별 품질 하한을 먼저 설정한 뒤 작업당·성공당 비용과 실패에 따른 재시도 비용을 검토합니다. 무조건 한 단계 낮추는 규칙이 아니며 `top` 변경도 평가합니다.

## 3. 추천 판정

- `변경 제안`: 직접 비교 결과가 이점으로 뒷받침되거나 명시한 사용자 정책에 따라 변경을 제안합니다. **벤치 근거 추천과 사용자 정책 추천을 구분**합니다.
- `후보만 제시`: 유망하지만 현 설정 대비 직접적인 비교 우위가 미측정 또는 불확실합니다.
- `유지`: 변경해야 할 확실한 근거가 부족하거나 기존 설정의 이점이 여전히 유효합니다.

추천 표는 각 티어마다 현재값과 후보 모델/effort, 최신 SWE/코딩 벤치 점수·버전, 각각의 작업당 비용, 있으면 성공당 비용과 시간, 판단 이유와 링크를 포함합니다. 자료가 없으면 `미측정`으로 표기합니다. 추천 우선순위가 높다는 이유만으로 변경 제안으로 승격하지 않습니다. 기존 override와 사용자 설정은 유지하고 변경은 사용자의 별도 승인 후에만 적용합니다.

## 4. 지원 및 적용

최신 모델은 후보에 포함하되 단지 새 버전이라는 이유로 승격하지 않습니다. 공식 Active/Deprecated/Shutdown 상태와 이전 기한을 확인합니다. Codex의 정확한 모델 ID와 effort 지원은 현재 계정의 `model/list`로 확인하고 미확인 별칭은 임의 교체하지 않습니다. 모델 설정 추천, 레거시 별칭 정리, 사용자 파일 이전, 호스트 프로필 적용은 별도 변경 항목입니다. 모두 최종 승인 후에만 적용합니다.

역사적 벤치마크나 [2026-11-18 Sol 검토](model-review-2026-11-18.md)는 과거 결정의 근거이지 이후 실행의 최신 수치를 대신하지 않습니다. 자체 코딩 벤치는 자동 실행하지 않습니다. 설계와 마이그레이션 근거는 [ADR 0010](../../../docs/adr/0010-route-mode-single-mapping.md)에 기록합니다.
