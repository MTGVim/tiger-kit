# 무협 연출 프리셋: wuxia

이 프리셋을 선택했을 때만 읽습니다. 기본 축은 `ink-brush + action + splash`이며 개별 명시 옵션을 우선합니다.

- 붓선·먹의 농담·움직이는 옷과 소품으로 힘과 방향을 표현합니다. 필요한 경우 에너지 흐름·충격파·빛을 비유에 사용합니다.
- 충돌의 원인, 작용하는 방향과 결과를 패널별로 보여 주며 장식적인 기운이 기술적 관계를 대신하지 않게 합니다.
- 배경의 바람·안개·낙엽 등은 움직임을 보조하지만 말풍선·라벨·핵심 소품을 가리지 않아야 합니다.
- 원문과 무관한 전투·파괴를 추가하지 않으며 비유의 크기나 강도를 실제 성능·위험의 수치로 오해하지 않게 합니다.
