# 패키지와 결과 계약

콘티·프롬프트·이미지를 저장하거나 전달할 때 읽습니다. 이미지 도구 부재는 최종 프롬프트를 만드는 데 필요한 추가 사용자 결정이 아닙니다. 확정된 범위로 준비물을 완성하고 실제 생성과 분리해 보고합니다.

## 패키지 내용

| 경로 | 내용 |
| --- | --- |
| `README.md` | 주제·독자·언어, 적용 옵션, 요청한 단계, 페이지별 선택 프롬프트와 실제 이미지/asset ID, 원문·콘티·캐릭터·참조 파일의 검증 당시 해시, 검사 결과, 외부 생성 순서와 차단 사유를 기록합니다. |
| `structured-content.md` | 출처 경로/URL·revision/시점에 연결한 사실, 정확한 문구·숫자·단위·조건, 창작 비유와 미확인 항목을 기록합니다. |
| `outline.md` | 표지 유무, 페이지 ID·목적·순서, 읽는 방향, 연결 관계를 기록합니다. |
| `storyboard.md` | 페이지·패널 ID, 위치·상대 크기, 장면·행동, 정확한 대사·화자·라벨, 출처와 시작/종료 상태를 기록합니다. |
| `characters/characters.md` | 등장인물이 있을 때만 식별 특징, 복장·색·소품, 허용되는 상태 변화와 필요한 시트 구성을 기록합니다. |
| `prompts/NN-page-<slug>-vNN.md` | 각 페이지의 최종 프롬프트를 독립적으로 재사용할 수 있도록 저장합니다. 표지는 실제 요청한 경우에만 `00-cover-...`로 저장합니다. |
| `prompts/characters-vNN.md` | 캐릭터 참조 시트를 만들기로 했을 때 그 완전한 프롬프트를 저장합니다. 페이지 생성보다 먼저 실행하도록 안내합니다. |
| `references/manifest.md` | 참조 ID, 출처·사용 조건, 실제 파일/호스트 참조, 용도 `direct/style/palette`, 사용할 페이지, 누락·미지원 사항을 기록합니다. 참조가 없으면 `none`과 이유를 씁니다. |

`--storyboard-only`에는 `prompts/`가 필요하지 않습니다. 생성 단계에 도달한 경우에만 실제 이미지, 도구와 출력 크기를 기록합니다. 호스트가 이미지를 관리하는 경우 존재하지 않는 로컬 파일 경로를 만들지 말고 실제 반환된 asset을 연결합니다. 참조 파일은 사용 권한이 있고 패키지에 포함할 수 있는 것만 복사하며 무관한 원문·비밀 파일을 함께 넣지 않습니다.

## 독립 프롬프트

각 프롬프트에 다음을 직접 포함합니다. `앞 페이지와 동일`, 다른 프롬프트 경로만으로 정의·대사를 생략하지 않습니다.

1. 페이지 ID·교육 목표·출력 언어·실제 비율/가능한 크기와 선택한 표현·톤·레이아웃·프리셋의 구체적 지침을 씁니다.
2. 해당 페이지의 등장인물 특징, 정확한 복장·색·위치, 소품 상태, 시작·종료 상태를 씁니다. 필요한 참조 ID와 실제 전달할 대상을 구분합니다.
3. 패널 ID·위치·상대 크기·읽는 순서, 행동과 기술적 관계, 말풍선 화자 및 **정확히 렌더링할 모든 문자열**을 씁니다. 그 페이지에 허용된 대사만 포함합니다.
4. 과장해서는 안 되는 기술 조건, 비유의 한계, 추가하면 안 되는 라벨·대사·관계와 다른 페이지 텍스트 혼입 금지를 씁니다.
5. 출처·정확한 용어·숫자를 대조합니다. 그림에 인용문을 모두 표시하라는 뜻이 아니며 외부 모델에는 허용된 최소 내용만 보냅니다.

## 참조와 기능 확인

현재 도구의 생성·참조 입력·지원 비율·동시 호출·출력 접근 계약을 확인합니다. `direct` 참조는 실제 파일 또는 호스트가 지원하는 대화 이미지 인자로 전달했는지를 기록합니다. 텍스트 특징만 추출한 경우에는 `style/palette`와 그 한계를 기록합니다. 명시적으로 요구된 직접 참조, 반복 캐릭터의 필수 동일성, 특정 비율을 현재 도구가 지원하지 않으면 조용히 약화하지 않고 해당 생성 단계를 `Blocked`로 남깁니다.

여러 참조를 동시에 지원하지 않을 때도 임의로 하나를 버리지 않습니다. 원래 요청이 스타일 추출을 허용한 경우에만 문자 설명을 사용하고, 그 밖에는 외부 인계 자료에 누락 사항을 표시합니다. 사용 가능한 기능과 이미지 참조 전달은 구별하며, 실제 생성하지 않은 시트를 보냈다고 기록하지 않습니다.

## 결과 상태

종합 `status`에는 `Pass | Fail | Blocked | Unverifiable`만 사용합니다. `not-requested`는 요청하지 않은 **단계 필드**에만 사용하며 새 종합 상태를 만들지 않습니다.

| 실제 결과 | 보고 |
| --- | --- |
| `--storyboard-only`의 콘티와 필요한 근거·캐릭터 정의가 검증됨 | `status: Pass`, `preparation: Pass`, `rendering: not-requested`, `deliverable: storyboard` |
| `--prompts-only`의 콘티·모든 프롬프트가 검증됨 | `status: Pass`, `preparation: Pass`, `rendering: not-requested`, `deliverable: prompts` |
| 래스터 요청, 도구/필수 기능 부재, 외부 인계 자료 완성 | `status: Blocked`, `preparation: Pass`, `rendering: Blocked`, `deliverable: external-handoff-ready` |
| 필요한 콘티·출처·참조가 없어 준비물을 검증할 수 없음 | 해당 단계는 `Blocked` 또는 `Unverifiable`이며 `preparation: Pass`나 인계 준비 완료를 주장하지 않습니다. |
| 실제 이미지가 있으나 픽셀을 열 수 없거나 필요한 독립 리뷰가 없음 | `status: Unverifiable`이며 생성 사실과 미확인 항목을 따로 기록합니다. |
| 검사에서 대사·수치·연속성 오류가 남음 | `status: Fail`이며 실패 페이지와 보존한 기존 검증본을 밝힙니다. |
| 요청된 모든 실제 래스터와 최종 선택 조합의 정확성·가독성·필요한 리뷰가 통과함 | `status: Pass`, `preparation: Pass`, `rendering: Pass`, `deliverable: raster-comic` |

외부 인계 시에는 캐릭터 시트가 필요한지, 어떤 순서로 어느 프롬프트와 실제 참조를 넣는지, 비율과 정확한 문구를 어떻게 검사하는지 안내합니다. 외부 서비스 설치·인증·업로드를 자동 실행하지 않습니다. SVG 콘티는 텍스트 패키지에 자동 포함하지 않으며 사용자가 별도로 수락한 경우에만 `벡터 콘티`로 제공합니다.
