# 패키지와 결과 계약

콘티·프롬프트·이미지를 저장하거나 전달할 때 읽습니다. 이미지 도구 부재 시 [로컬 폴백 또는 준비물만 전달](../../tk-writing/references/local-image-fallback.md)을 선택하게 하되, 준비물은 이미 승인된 제작 범위에서 계속 만듭니다. 확정된 범위로 준비물을 완성하고 실제 생성과 분리해 보고합니다.

## 패키지 내용

| 경로 | 내용 |
| --- | --- |
| `README.md` | 주제·독자·언어, 적용 옵션, 요청한 단계, 페이지별 선택 프롬프트와 실제 이미지/asset ID, 원문·콘티·캐릭터·참조 파일의 검증 당시 해시, 검사 결과, 외부 생성 순서와 차단 사유를 기록합니다. |
| `structured-content.md` | 출처 경로/URL·revision/시점에 연결한 사실, 정확한 문구·숫자·단위·조건, 창작 비유와 미확인 항목을 기록합니다. |
| `outline.md` | 표지 유무, 페이지 ID·목적·순서, 읽는 방향, 연결 관계를 기록합니다. |
| `storyboard.md` | 페이지·패널 ID, 위치·상대 크기, 장면·행동, 정확한 대사·화자·라벨, 출처와 시작/종료 상태를 기록합니다. |
| `characters/characters.md` | 등장인물이 있을 때만 식별 특징, 복장·색·소품, 허용되는 상태 변화와 필요한 시트 구성을 기록합니다. |
| `prompts/NN-page-<slug>-vNN.md` | 각 페이지의 최종 프롬프트를 독립적으로 재사용할 수 있도록 저장합니다. 표지는 실제 요청한 경우에만 `00-cover-...`로 저장합니다. |
| `prompts/characters-vNN.md` | 캐릭터 참조 시트를 만들기로 했을 때 그 완전한 프롬프트를 저장합니다. 페이지 생성보다 먼저 실행하도록 안내합니다. |
| `prompts/all-in-one-vNN.txt` | `prompts-only`와 외부 인계 시 **항상** 만듭니다. 한 파일로 전체 생성 순서를 전달하는 묶음이며, 아래 [한 번에 붙여 넣는 묶음](#한-번에-붙여-넣는-묶음) 계약을 따릅니다. |
| `references/manifest.md` | 참조 ID, 출처·사용 조건, 실제 파일/호스트 참조, 용도 `direct/style/palette`, 사용할 페이지, 누락·미지원 사항을 기록합니다. 참조가 없으면 `none`과 이유를 씁니다. |

`storyboard-only`에는 콘티에 필요한 파일만 포함합니다. 생성 단계에 도달한 경우에만 실제 이미지, 도구와 출력 크기를 기록합니다. 호스트가 이미지를 관리하는 경우 존재하지 않는 로컬 파일 경로를 만들지 말고 실제 반환된 asset을 연결합니다. 참조 파일은 사용 권한이 있고 패키지에 포함할 수 있는 것만 복사하며 무관한 원문·비밀 파일을 함께 넣지 않습니다.

## 독립 프롬프트

각 프롬프트에는 `앞 페이지와 동일`이나 다른 프롬프트 경로 대신 다음 정의와 대사를 직접 포함합니다.

1. 페이지 ID·교육 목표·출력 언어·실제 비율/가능한 크기와 선택한 표현·톤·레이아웃·프리셋의 구체적 지침을 씁니다.
2. 해당 페이지의 등장인물 특징, 정확한 복장·색·위치, 소품 상태, 시작·종료 상태를 씁니다. 필요한 참조 ID와 실제 전달할 대상을 구분합니다.
3. 패널 ID·위치·상대 크기·읽는 순서, 행동과 기술적 관계, 말풍선 화자 및 **정확히 렌더링할 모든 문자열**을 씁니다. 그 페이지에 허용된 대사만 포함합니다. 로컬 폴백에서는 ID·화자·정확한 문자열을 별도 식질 명세에 두고, 모델에 전달하는 독립 장면 프롬프트에는 말풍선·문자·ID를 그리지 말라는 제약만 넣습니다.
4. 과장해서는 안 되는 기술 조건, 비유의 한계, 추가하면 안 되는 라벨·대사·관계와 다른 페이지 텍스트 혼입 금지를 씁니다.
5. 출처·정확한 용어·숫자를 대조합니다. 그림에 인용문을 모두 표시하라는 뜻이 아니며 외부 모델에는 허용된 최소 내용만 보냅니다.

## 한 번에 붙여 넣는 묶음

`prompts-only` 또는 외부 인계에서는 `prompts/all-in-one-vNN.txt`를 반드시 저장합니다. 첫머리에 다음 생성 지시를 분명하게 넣습니다.

> 각 장을 **별도 이미지**로 지정된 순서대로 생성하고, 모든 장을 완성할 때까지 멈추지 말 것. 각 페이지의 인물은 첫 캐릭터 시트(있는 경우)의 외형을 따를 것. 다른 페이지에 지정된 문자열을 섞거나 추가하지 말 것.

그다음 캐릭터 시트 프롬프트(있을 때)를 먼저, 이어서 페이지 `1..N`(요청한 표지가 있으면 표지부터)을 순서대로 넣습니다. 각 단위는 시작·끝과 페이지 ID를 구분할 수 있도록 경계를 표시하며, **독립 프롬프트 본문은 수정·요약·생략하지 않고 그대로** 이어 붙입니다. 파일명·버전을 적어 원본을 추적할 수 있게 합니다. 실제 이미지 참조가 필요한 경우 묶음 텍스트만으로 전달되었다고 주장하지 않고 참조 파일/호스트 자산을 별도로 명시합니다.

독립 프롬프트가 수정·재생성되면 묶음도 다시 생성하고, `README.md`에 개별 프롬프트와 묶음 파일의 검증 당시 해시를 함께 기록합니다. 묶음 순서·본문 일치 여부와 README 해시를 확인해야 준비 완료로 보고합니다.

## 참조와 기능 확인

현재 도구의 생성·참조 입력·지원 비율·동시 호출·출력 접근 계약을 확인합니다. `direct` 참조는 실제 파일 또는 호스트가 지원하는 대화 이미지 인자로 전달했는지를 기록합니다. 텍스트 특징만 추출한 경우에는 `style/palette`와 그 한계를 기록합니다. 명시적으로 요구된 직접 참조, 반복 캐릭터의 필수 동일성, 특정 비율을 현재 도구가 지원하지 않으면 조용히 약화하지 않고 해당 생성 단계를 `Blocked`로 남깁니다.

여러 참조를 동시에 지원하지 않을 때는 필요한 참조 전체와 지원되지 않는 참조를 구분해 보존합니다. 원래 요청이 스타일 추출을 허용한 경우에만 문자 설명을 사용하고, 그 밖에는 외부 인계 자료에 누락 사항을 표시합니다. 사용 가능한 기능과 이미지 참조 전달은 구별하며, 실제로 생성하고 전달한 시트만 전달 기록에 포함합니다.

## 결과 상태

종합 `status`에는 `Pass | Fail | Blocked | Unverifiable`만 사용합니다. `not-requested`는 요청하지 않은 **단계 필드**에만 사용하며 종합 상태는 위 네 값으로만 제한합니다.

| 실제 결과 | 보고 |
| --- | --- |
| `storyboard-only`의 콘티와 필요한 근거·캐릭터 정의가 검증됨 | `status: Pass`, `preparation: Pass`, `rendering: not-requested`, `deliverable: storyboard` |
| `prompts-only`의 콘티·모든 독립 프롬프트와 `all-in-one` 묶음이 검증됨 | `status: Pass`, `preparation: Pass`, `rendering: not-requested`, `deliverable: prompts` |
| 래스터 요청, 도구/필수 기능 부재, `all-in-one` 묶음을 포함한 외부 인계 자료 완성 | `status: Blocked`, `preparation: Pass`, `rendering: Blocked`, `deliverable: external-handoff-ready` |
| 필요한 콘티·출처·참조가 없어 준비물을 검증할 수 없음 | 해당 단계는 `Blocked` 또는 `Unverifiable`이며 `preparation: Pass`나 인계 준비 완료를 주장하지 않습니다. |
| 실제 이미지가 있으나 픽셀을 열 수 없거나 필요한 독립 리뷰가 없음 | `status: Unverifiable`이며 생성 사실과 미확인 항목을 따로 기록합니다. |
| 검사에서 대사·수치·연속성 오류가 남음 | `status: Fail`이며 실패 페이지와 보존한 기존 검증본을 밝힙니다. |
| 요청된 모든 실제 래스터와 최종 선택 조합의 정확성·가독성·필요한 리뷰가 통과함 | `status: Pass`, `preparation: Pass`, `rendering: Pass`, `deliverable: raster-comic` |

외부 인계 전달 메시지의 **첫 줄**에는 `이 파일 하나를 이미지 도구의 새 대화에 붙여 넣으세요`와 `prompts/all-in-one-vNN.txt`의 **절대 경로**를 적습니다. 호스트가 클립보드 복사를 지원하면 묶음 내용을 복사해 두고 복사했음을 알립니다(지원하지 않으면 복사했다고 주장하지 않습니다). 이후에는 도구가 한 장만 만든 채 멈추면 `다음 장`이라고 입력하라는 안내와, 글자가 틀린 페이지만 해당 개별 프롬프트로 다시 생성하라는 안내만 덧붙입니다. 필수 실제 참조 자료가 있으면 접근 경로를 별도로 전달하고 묶음 하나만으로 전달 완료됐다고 주장하지 않습니다. 외부 서비스 설치·인증·업로드는 정확한 행동과 대상에 대한 별도 승인 뒤에만 실행합니다. SVG 콘티는 텍스트 패키지에 자동 포함하지 않으며 사용자가 별도로 수락한 경우에만 `벡터 콘티`로 제공합니다.

## 로컬 폴백 산출물

[분리 식질 계약](../../tk-writing/references/local-image-fallback.md#분리-식질)에 따라 모델 원본, 별도 텍스트 명세, 식질본을 구분합니다. README에 실제 모델·revision/양자화·4-step 설정·참조 지원·설치 승인/재사용·수동 배치·폰트와 후처리·검사 한계를 기록합니다. 요청한 식질과 최종 픽셀 검사가 끝난 경우에만 최종 래스터 완료로 보고합니다.
