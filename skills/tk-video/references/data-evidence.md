# 수치·데이터 에셋의 근거 인계

논문·조사 결과·측정값을 설명 영상에 사용할 때 기존 조사 근거와 원고 점검 목록을 재사용합니다.
별도 조사나 필수 `claims.json`을 만들지 않습니다. 데이터가 없는 일반 UI 흐름에는 이 절차를 추가하지 않습니다.

## 원고와 출처의 대조

각 중요한 주장과 해당 장면·문장을 기존 근거 행에 연결합니다. 숫자가 없는 효과·인과 주장도 포함합니다.
값만 대조하지 말고 지표 이름, 단위, 분모·표본, 측정 조건, 비교 기준, 상태(보고·재현·예시·예정)와
필수 한계를 원문과 대조합니다. 예를 들어 `성공률 95%`를 `정확도 95%`로, `250ms`를 `250초`로
바꾸거나 예정값을 측정 결과로 제시하면 숫자가 같아도 실패입니다. 출처에 같은 숫자가 있다는 사실은
해당 주장의 근거가 아닙니다. 전역 숫자 허용 목록이나 자동 백분율 환산으로 사실 검증을 대신하지 않습니다.

합성 전 목록에서 원고·낭독형·자막·그림 레이블을 같은 근거와 대조하고, 전달 전 실제 자막과 대표
디코딩 프레임에서도 값·단위·범위가 유지되는지 확인합니다. 이미 제공된 조사·설명 근거는
그대로 인계받고, 전달받지 못한 부분만 미검증으로 남깁니다. TTS의 실제 발화는 기존 청취 확인을 유지합니다.
근거 누락·상충·의미 변경이 있으면 해당 문장·그림을 고치거나 결과 주장으로 사용하지 않습니다.
관련 없는 장면의 제작을 멈추거나 일상적인 승인 단계를 추가하지 않습니다.

## 선택한 데이터 에셋의 무결성

데이터 그림·표·측정 이미지를 제작에 선택했을 때만 기존 실행 근거 안에 해당 파일의 상대 경로,
종류, 원출처 또는 생성 명령·인자·seed, 확인한 SHA256을 기록합니다. 출처의 revision·입력 데이터와
필요한 사용 조건도 같은 근거에 보존합니다. 생성 명령은 기록이며 자동 실행 권한이 아닙니다.
장식용 생성 이미지와 실측·보고 데이터는 구분합니다. 해시는 최초 검토한 바이트에 대해 기록합니다.

기존 실행 소유 디렉터리 안에 아래 형식의 JSON을 두고 조립 직전에 현재 설치된 `tk-video`의
`scripts/check_assets.py`를 실행할 수 있습니다. `file`은 이 JSON이 있는 디렉터리 안의 상대 경로입니다.
영상 조립 manifest와는 별도 입력이며, 이 도우미는 파일을 수정하거나 명령을 실행하지 않습니다.

```json
{"assets":[{"file":"plot.png","kind":"measured","made_by":"python plot.py --seed 42; input results.csv@<revision>","sha256":"<64 hex characters recorded after review>"}]}
```

```bash
python3 <installed-tk-video>/scripts/check_assets.py /absolute/run/asset-evidence.json
```

종류는 `measured | reported | illustration | generated` 중 하나입니다. 정상은 종료 코드 0,
목록 내 에셋의 변경·누락·빈 파일·심볼릭 링크는 1, 잘못된 기록·경로·읽기 실패는 2로 반환합니다. 목록에 없는 파일은 검사하지 않으므로
실제로 선택한 데이터 에셋이 빠지지 않았는지는 원고·조립 입력과 별도로 대조합니다. 디렉터리 전체 감사가 아닙니다.
실패한 에셋은 조립에 사용하지 않습니다. 변경 이유와 원출처를 다시 확인하여 필요하면 재생성하고
그림의 의미를 재검토한 뒤 기록을 갱신합니다. 통과시키기 위해 해시만 갱신하지 않습니다.
해시 일치는 출처의 진실성·데이터 계산·그림의 의미·발음을 검증하지 않습니다.
