# Change-flow video

Pass the pinned comparison, supported claims and ordered scene outline to `tk-video`. Real
base/head browser states belong to `tk-browser-verify`; native window states belong to
`tk-app-verify`. Capture requires its owner's approved runtime boundary; an explanation request
authorizes no product mutation, authenticated-profile attachment or production data changes.
Preserve capture provenance and actual timing independently from explanatory holds. Label
rendered diagrams as rendered; unavailable old behavior is a stated gap, not a reenactment.
Link the returned MP4/GIF from the explanation document with its source/inspection limits.
Media checks do not prove application correctness and optional-media failure cannot change an
existing verdict. Missing `tk-video` retains the explanation and names the undelivered movie.
No sibling script imports, automatic installs, Git mutation or uploads belong to this handoff.
