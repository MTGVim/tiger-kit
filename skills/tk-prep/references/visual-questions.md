# Visual question aid

Read only when spatial alternatives can change an unresolved user-owned choice. Keep the numbered plain-chat question, a short description of every option and the recommendation complete without opening a file. Add the complete absolute HTML link in that question; users still answer by number.

After Artifact Paths checks, create one external-resource-free HTML file in `.tigerkit/tmp/<calling-skill>/<run-id>/questions.html`. Show comparable low-fidelity wireframes, option numbers, pros/cons and the recommended option. Offer single-option and side-by-side views when useful, with keyboard-accessible controls and no focus outlines on passive scroll targets. Match the same viewport/content across options; do not add decorative imagery or implementation code. Reuse this file for later visual rounds in the same run; do not generate files for nonvisual questions, a plan recap or a resolved choice.

If writing or viewing the HTML is unavailable, finish the text round and disclose only the missing visual aid. A missing repository does not justify initializing Git or using an external temporary path. Preserve source/config/Seed and approval boundaries apart from the canonical minimal ignore setup. This aid is not a product prototype or approval to implement it.
