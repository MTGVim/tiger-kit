# UI 근거 수집

UI 문구·경로를 인용·검증·전달할 때 읽습니다. 수집 절차는 호출 스킬에 이미 부여된 UI 조사 권한 안에서만 적용합니다. 전달만 하는 호출자는 제공된 근거와 공백을 보존하며 새 조사를 시작하지 않습니다. 이 참조는 새로운 브라우저, 변경 또는 발행 권한을 부여하지 않습니다.

기존 UI label은 언어, 대소문자, 문장 부호와 공백을 보존하여 그대로 인용합니다. 탐색 안내에는 모든 메뉴/breadcrumb label과 경로의 각 연결에 대한 근거가 필요합니다. 검증된 목적지 제목이나 route는 그 진입 경로를 입증하지 않습니다. 식별자, enum, i18n key, 도메인 용어와 ticket 문구는 현재 render 경로에서 입증되지 않는 한 현재 UI의 근거가 아닙니다. 제안 문구는 기존 label과 분리합니다. label을 몰래 선택하거나 서로 호환되지 않는 경로를 합치지 말고 출처 간 충돌을 보고합니다.

각 주장에는 대상/환경/locale/역할이 일치하는 런타임 근거, render 경로에 연결된 소스 또는 출처가 있는 제공 캡처를 사용합니다. API 텍스트에는 실제 응답과 그 응답의 rendering/변환 연결 근거가 필요합니다. schema는 형태만 입증합니다. 다른 저장소, 호스트 shell, API, 설정이나 권한이 누락된 구간을 제어한다면 확인된 경계와 아직 검증하지 못한 부분을 명시합니다. 추론이라는 단서를 붙이더라도 그럴듯한 경로를 안내로 제시하지 않습니다.

승인된 브라우저 검사 중에는 진입 후 초기 rendering이 끝나면 label을 추측하거나 selector로 하나씩 조회하기 전에 `document.body.innerText`를 한 번 수집합니다. 이를 현재 render된 텍스트의 목록으로 취급하며 완전한 메뉴 트리로 취급하지 않습니다. 필요한 경우에만 안전한 접힌 탐색 메뉴를 펼치거나 빠진 영역을 검사합니다. 도구 출력, 저장한 근거와 보고서에서 비밀과 무관한 민감한 페이지 데이터를 제외합니다. 전체 body를 안전하게 반환할 수 없다면 관련 탐색/header 영역을 검사하고 그 한계를 기록합니다. 나중에 PR/QA에서 사용할 수 있도록 관련 literal을 대상/환경/locale/역할 및 캡처 출처와 함께 보존합니다.

눈에 보이는 breadcrumb와 페이지 header는 실제로 표시하는 label의 첫 번째 출처로 사용합니다. Breadcrumb는 표시된 label 문자열과 목적지 계층을 뒷받침합니다. 페이지 제목만으로는 그 제목만 뒷받침됩니다. 어느 쪽도 실제로 거친 메뉴 경로나 sidebar label이 breadcrumb label과 일치함을 입증하지 않습니다. 메뉴에서 다른 메뉴로 클릭해 이동하는 안내에는 실제 각 단계를 검증하고 그 label과 결과 연결을 캡처합니다. Breadcrumb 근거만 있다면 표시된 계층만 설명합니다.

조사 권한 안에서 접근 가능한 출처로부터 누락 근거를 구하거나, 대상과 안전한 접근이 가능할 때 브라우저 담당자를 통해 읽기 전용 브라우저 검사를 시도합니다. 승인된 검사를 진행할 수 있다면 저장소에서 찾지 못했다는 이유로 멈추거나 브라우징을 제안하는 데 그치지 않습니다. 접근이나 근거를 확보할 수 없다면 해당 주장을 `Unverifiable`로 표시하고 구체적인 한계를 설명하며, 필요한 최소 입력을 요청합니다. 관련 label/계층/route 필드가 포함된 민감 정보 제거 메뉴 API 응답, 소유 소스 또는 탐색 메뉴가 보이는 screenshot이 이에 해당합니다. 채팅에서 자격 증명이나 민감 정보를 제거하지 않은 payload를 절대 요청하지 않습니다. 요약, QA와 인계에 검증된 부분 결과와 대기 중인 근거를 보존합니다. 전달만 담당하는 소유자는 새 조사를 시작하지 않고 요청을 전달합니다.

완료 보고와 발행 전 준비에서는 아직 검증하지 못한 모든 필수 label 또는 탐색 연결을 명시적으로 나열합니다. 해당 주장, 확보한 근거/출처, 구체적인 한계와 해결에 필요한 최소 입력을 포함합니다. 공백을 몰래 생략하거나 검증된 것으로 계산하지 않습니다. 사용자가 제공한 정확한 label이나 캡처는 대상/환경/locale/역할 맥락과 함께 항목별로 수용합니다. 텍스트뿐인 label은 독립 관찰이 아니라 사용자 제공으로 표시합니다. 정확한 문구를 보존하고 뒷받침되는 주장만 해결하며, 뒷받침되지 않는 연결은 `Unverifiable`로 유지합니다. 미해결 항목을 PR/QA의 한계와 인계에 포함하여 사용자가 각 누락 항목을 제공할 수 있게 합니다.
