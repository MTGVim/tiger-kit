# 설명용 삽화 선택·배치·밀도

설명 페이지나 여러 절을 갖춘 문서에서 이미지의 필요성·위치·밀도를 결정할 때만 사용합니다. 기존 [근거](evidence.md), [시각 출력 선택](visual-output.md), [래스터 일러스트레이션](raster-illustration.md), [설명 페이지 작성과 검사](author-check.md)가 소유하는 승인·프롬프트 보존·실제 이미지 생성·정확성 검사는 다시 구현하지 않습니다.

1. **근거와 콘텐츠 고정:** 원문 주장·조건·숫자·범위·라벨을 유지한 채 독자 질문과 절별 개념을 뽑습니다. 표현 개선 때문에 새로운 사실이나 절을 임의로 추가하지 않습니다.
2. **필요성 판단:** 추상적 공간 관계, 구성 요소, 단계 변화, 차이 비교처럼 글만으로 인지 부하가 큰 내용에 그림을 권장합니다. 짧은 정의, 이미 명확한 예제, 같은 관계의 반복은 그림을 생략합니다. 이미 표나 정확한 도해가 담당하는 내용을 AI 이미지로 반복하지 않습니다.
3. **위치 결정:** 그림은 해당 주장 직후 또는 같은 읽기 단위 안에 두고 설명과 그림을 오가며 추측하게 만들지 않습니다. 제목 아래의 장식용 이미지, 내용 없는 추가 컷은 제외합니다. 문서의 읽기 순서와 모바일 폭을 유지합니다.
4. **밀도 제한:** 기존 설명 페이지는 기본 AI 일러스트레이션 한 장을 유지합니다. 다중 섹션 문서는 필요한 후보를 모두 추린 다음 독립적인 이해 이득이 있는 그림만 남깁니다. 정확히 몇 장을 만들어야 한다는 할당량은 없으며, 전 절에 그림을 하나씩 강제하지 않습니다. 같은 메커니즘의 중복 그림을 제거합니다. `0장`도 적절할 수 있습니다.
5. **시각 통일:** 제작할 그림들에 동일한 독자 언어, 공통 색상 의미, 일관된 선/텍스처·레이블·종횡비 정책을 적용합니다. 그림마다 레이아웃은 정보 구조에 맞게 달리할 수 있습니다. 스타일 참조 이미지는 도구가 지원할 때만 실제 참조로 전달하며, 미지원일 때 동일하게 재현된다고 주장하지 않습니다.
6. **최종 검증:** 그림을 넣기 전·후 본문을 대조해 사실·숫자·조건·단락이 누락되지 않았는지 확인합니다. 각 그림에 설명하는 주장, 위치, 선택 이유, 필요 없는 대안의 폐기 근거를 남깁니다. 최종 픽셀의 라벨과 관계는 원본 사실에 대조합니다. 오류가 있으면 재생성하거나 해당 그림을 생략합니다.

## 비교 사례

컨테이너 설명의 고정 원문에 정의, 구성 요소, VM과의 차이, 개발→테스트→운영 흐름이 있다면, 전체 내용은 그대로 두고 관련 구성 요소의 그림을 정의 근처에, VM 대비는 비교 절 안에 배치합니다. 기존에 정확한 VM 도해가 있다면 새 AI 삽화는 추가하지 않아도 됩니다. 짧은 정의만 제공된다면 시각 자료를 자동 증식하지 않습니다.
