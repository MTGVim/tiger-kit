  페이지 내부 기본 그림은 이미 선택·위임받은 구성을 재사용하고 독립 F3의 미확정 스타일 확인과 구분합니다.
  이미지 도구 부재 때 완성 프롬프트를 먼저 권장하고 SVG→PNG는 `임시 대체물, baoyu 생성본 아님`으로 함께 제공합니다.
  이는 baoyu의 래스터 전용 성공 조건을 충족하지 않는 TigerKit의 명시적 대안이며 AI 생성은 미충족으로 남습니다.
- `omit`: 후보 세 개 선택만으로 세 변형·긴 페이지 생성, 무조건 보드·질문형 제목,
  도구 부재를 성공으로 처리하는 동작, 공급업체 routing·설정·자동 설치와 원본 구현 복제입니다.

한국어 `@architecture` 선택과 선택적 영문 UI 치환은 TigerKit의 로컬 계약입니다.
