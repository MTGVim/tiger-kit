# AI raster illustration

Read for an AI-illustrated infographic, a `baoyu`-like result, character illustration or a
selected raster format. The output-defining behavior is raster image generation. HTML/SVG,
canvas or code-drawn art is not a successful substitute, even when the topic is technical.
A precise source-code/measurement figure uses the separate static summary-image route when
requested; offer it as an alternative, not a silently completed AI illustration.

## Bind content before appearance

Reuse the run's `evidence.md` and exact source snapshots. Write structured content in the
run's temporary directory: reader objective, conclusion, sections, source-bound claims,
visual relationships and an exact label/data list. Introduce no new facts. Preserve numeric
strings, units, denominators, qualifications and condition boundaries from the source.
Never send secrets or private source code to an image tool without the relevant task authority.

Infer the information layout from the content (for example a sequence, comparison, central
scene or grouped facts). Under the selection reference's third round, show that concrete
layout with style options and the target aspect, and confirm unresolved style/aspect choices
before generating. Do not ask the internal layout name as another axis. An explicit style,
aspect or delegated `알아서` choice is already resolved; if all axes are specified, announce
the inferred layout×style/aspect and proceed. This adapts the donor's Step 4 to the user's
ordered selection contract, not a second approval ceremony or fixed default combination.
Use fitting options such as illustrated hand-drawn characters, restrained graphic treatment,
painted storybook or technical illustration; never imply those styles establish factual scale.

## Save the prompt, then generate

Create a new standalone prompt file under the run's `prompts/` before every image-tool call.
Use the prompt skeleton below: specifications (layout,
style, aspect, language), core constraints, text requirements, layout/style guidelines,
structured content and the complete exact label list. Fill every field; pass that saved
prompt's full content and the confirmed reference images/aspect to the runtime-native image
generation tool under its actual contract. Keep required license/asset attribution. Do not
copy a cached backend command or install a generator as part of this route.

If no image-generation tool is available, return `Blocked`/`Unverifiable` with the missing
capability and clearly identified alternatives. Do not generate HTML/SVG as if it were raster
success. Report failed generation honestly; retries retain previous candidate files.
When the tool owns output persistence, respect that lifecycle rather than reconstructing its
image bytes; save a local copy only when the actual tool contract and requested artifact require it.

## Check final pixels and facts

Inspect the actual raster at its intended reading size. Compare every label, numeric string,
unit, relationship, condition and emphasis with the structured source content. Apply the same
source, author and independent accuracy review policy as summary PNG, including default
independent review for `change`. Use the exact final image plus evidence and the label list;
`visible_text.py` cannot extract pixels and is not an image accuracy verdict.

If text is wrong, unreadable or missing, revise the prompt and regenerate to a new prompt/image
path. Never paint over, erase or rewrite text programmatically, including via SVG, Pillow or
canvas overlays. Preserve the flawed candidate privately as diagnostic evidence. Crop/resize/
compression may not alter text or meaning, and required review binds to the resulting final bytes.
A failing tool or uninspected material figure cannot receive `Pass`. Deliver the actual raster,
alt description, selected layout/style/aspect and truthful checks; no publication is authorized.

This is an adapted runtime-native route, not a claim that the upstream skill, its backend or
its complete style gallery ran. The four HTML/SVG principles remain distinguishable adaptations.

```markdown
- Aspect ratio: <confirmed W:H>
- Language: <reader language>

## Core constraints

<Source-bound conclusion, conditions and limits. No invented facts, measurements or causal links.>

## Text requirements

<Legible text at the intended display size; preserve exact numeric strings and label wording.>

## Layout guidelines

<Section positions, verified relationships, sequence and grouping; keep source order where material.>

## Style guidelines

<Confirmed style treatment without decorative scale or causality claims.>

## Structured content

<Reader objective, necessary prerequisites, mechanism, grounded facts and caveats.>

## Exact text labels

<Complete label/title/value list in the selected language, with source bindings in the private evidence.>
```
