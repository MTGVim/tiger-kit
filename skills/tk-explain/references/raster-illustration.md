# AI 이미지 제작 위임

F3 AI 래스터, 요청한 설명 페이지의 기본 일러스트레이션 한 장 또는 문서의 AI 보조 삽화가
필요할 때만 읽습니다. 제작 정본은 같은 설치 컬렉션의 [tk-illustrate](../../tk-illustrate/SKILL.md)입니다.
일반 대화, 정밀한 코드·측정값·로고·다이어그램은 기존 F2/F6 및 정적 경로를 유지합니다.
이 참조는 이미지 제작 절차와 프롬프트 틀을 복제하지 않습니다.

## 부모가 확정해서 전달할 내용

- 원문 스냅샷과 `evidence.md`, 출처에 연결된 사실·정확한 라벨·숫자·단위·조건을 전달합니다.
  관찰·추론·예시를 구별하고 외부 이미지 도구에 보낼 수 있는 범위만 추립니다.
- 독자, 언어, 설명 목표, 선택한 설명 기법과 최종 형식, 그림의 역할·문서 위치·필요한 개수를 전달합니다.
  단일 그림은 `single`, 한 장의 정보 포스터는 `infographic`, 승인된 문서 삽화 묶음은 `article`로 지정합니다.
  기본 설명 페이지의 그림은 한 장이며 페이지 전체를 F3로 바꾸지 않습니다.
- 사용자가 확정한 스타일·레이아웃·비율·참조와 위임한 축을 구별합니다. 기본 페이지의 그림에는
  승인된 페이지 구성을 재사용하며 나머지 제작 선택도 위임합니다. 이미 답한 주제·스타일을 다시 묻지 않습니다.
  독립 F3의 미확정 제작 조합만 `tk-illustrate`의 질문 절차를 한 번 적용합니다.
- 부모가 경로 계약으로 확인한 최종 목적지, 실행 소유 준비물 경로와 필요한 독립 리뷰 조건을 전달합니다.
  `artifacts.durableRoot`의 결정·도우미 실행은 `tk-explain`에 남기고 제작 스킬에 역의존시키지 않습니다.

설치 소유자·식별·자원이 없으면 해당 제작 단계만 `Blocked`로 보고하고 `tk-setup-skills`를 안내합니다.
구 제작 본문, 저장소 전역 경로나 다른 설치본으로 대체하지 않으며 자동 설치하지 않습니다.
설치 의존성에 포함되어 있다는 이유로 일반 설명에서 제작 카탈로그를 선로드하지 않습니다.

## 제작 결과를 설명에 결합하기

`tk-illustrate`는 구조화된 사실·콘티·완전한 프롬프트·참조 목록, 실제 이미지나 차단 근거,
적용 옵션과 검증 결과를 반환합니다. 부모는 이미지가 요청한 근거·언어·위치·수량을 충족하는지
확인하고 실제 결과를 본문·캡션·대체 텍스트와 결합합니다. 호스트가 이미지 저장을 소유하면
그 수명주기를 따르며, 요청된 HTML의 오프라인 내장에 실제 사본이 필요한 경우에만 저장합니다.

자식의 픽셀 검사는 설명 전체의 정확성 검사나 HTML 검사를 대신하지 않습니다. 저장된 최종 이미지,
정확한 텍스트와 근거를 재사용해 `tk-explain`의 필수 독립 리뷰를 수행합니다. 같은 이미지·근거의
동일한 검사를 불필요하게 반복하지 않되, 부모가 결합한 최종 HTML과 수정된 바이트는 다시 확인합니다.
콘텐츠 오류 수정은 제작 소유자에 돌려보내며 부모가 글자를 이미지 위에 덧칠하지 않습니다.

## 이미지 도구가 없을 때

설치된 `tk-illustrate`가 이미지 도구 부재나 필요한 기능 미지원으로 생성하지 못하면 콘티와
최종 프롬프트가 포함된 외부 인계 패키지를 받아 전달합니다. 실제 이미지가 없으면 그림 완료로
보고하지 않으며, 준비물의 `Pass`와 래스터의 `Blocked | Unverifiable`를 분리합니다.

기존 설명 페이지에서 승인된 파일 제작을 이어 가는 경우에만 부모가 같은 근거의 독립 SVG를 PNG로
변환하여 한 장의 임시 대체물로 넣을 수 있습니다. 캡션과 전달에 `임시 대체물, baoyu 생성본 아님`을
명시하고 완전한 프롬프트를 함께 제공합니다. 변환 도구가 없으면 인계 패키지와 차단 사유를 전달합니다.
이 경로는 기존 설명 페이지의 정적 대체물 계약이며, 독립 F3 이미지나 `tk-comic`의 SVG 콘티를
자동 제작하는 권한이 아닙니다. AI 래스터 요청은 여전히 미충족이며 전체 결과를 `Pass`로 합치지 않습니다.
제공자 설치·계정·추가 비용·외부 업로드·발행과 기존 파일 덮어쓰기는 기존 승인 범위를 보존합니다.
