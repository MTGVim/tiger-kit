# 학습자 근거에 따른 후속 설명

후속 교육도 현재 대화가 기본입니다. 계속 설명하거나 더 자세히 가르쳐 달라는 요청만으로 HTML·노트·학습 저장소를 만들지 않습니다. 실제로 제공된 답변이나 관찰한 실행 결과를 사용합니다. HTML을 열거나
읽거나 답을 공개했다는 사실에서 응답을 추정하지 않습니다. 검증된 맥락에서 일치하는 주제를 사용하고, 기존 페이지와 노트가 있을 때만 이를
복원합니다. 요청한 파일 작업에 필요한 저장 위치가 여러 곳으로 남아 있을 때만 질문합니다. 기존 학습
공간과 형식을 보존합니다. 이를 이전하거나 이력을 다시 쓰거나 전역 학습자 저장소를 만들지 않습니다.

표현된 각 생각에 대해 정답·오답·부분 정답·미관찰 여부와 근거를 기록합니다.
결과와 추론을 구별합니다. 결과가 맞아도 이유가 틀렸다면 바로잡아야 합니다.
추론 없이 결과만 있다면 해당 추론은 미관찰 상태로 남습니다. 맞는 단계는 인정하고,
빠진 조건을 짚으며, 실제 답변이 뒷받침할 때만 공통 원인을 추론합니다.
완성된 풀이 예시와 조건을 바꾼 전이 사례로 하나의 핵심 교정 내용을 가르칩니다.
학습자가 의무적인 재시도 없이 전체 해설을 요청하거나 건너뛰거나 중단할 수 있게 합니다.

후속 HTML을 요청하면 같은 렌더링·근거·검토 규칙과
새 `<slug>-followup-<n>.html`을 사용합니다. 이전 페이지는 보존합니다. 요청한 산출물·노트 저장 범위에서만 `<slug>.notes.md`에
관찰된 응답, 날짜, 생각별 판단, 근거로 뒷받침되는 오개념, 페이지 링크와 다음 집중 항목만 덧붙입니다.
빈 진행 틀, 과정 재생성, 자동 숙달 점수 또는 예약 작업을 만들지 않습니다.
일반적인 답변 피드백과 계속 가르쳐 달라는 요청은 별도 파일을 요청하지 않는 한 대화로 제공합니다. 다른 산출물 형식을 요청했다면 그 형식과 검증 절차를 따릅니다.
