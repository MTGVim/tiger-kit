# 후속 설명

사용자가 앞선 설명을 이해하지 못했다고 밝히면, 새로운 용어를 늘리기보다 이미 함께 살펴본 실제 사례 하나로 돌아가 핵심 관계부터 다시 설명합니다. 공유한 사례가 없다면 짧고 구체적인 예시 하나를 들고, 예시와 실제 관찰을 구분합니다.

같은 혼란이 반복되면 직전 설명에서 이해가 끊긴 단계나 문장을 짚어 확인합니다. 단순한 혼란 표현을 오개념의 증거로 취급하지 않으며, 사실 오류나 잘못된 작업에 대한 항의를 이해 부족으로 돌리지 않습니다.

후속 설명은 현재 대화에서 계속합니다. 별도 산출물을 명시적으로 요청받으면 요청한 형식과 검증 절차를 따릅니다. 자동 채점, 학습 기록, 후속 HTML 생성 또는 숙달도 추적을 하지 않습니다.
