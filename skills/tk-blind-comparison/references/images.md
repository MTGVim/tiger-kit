# Images and UI captures

Prepare new PNG copies on an identical canvas using local Pillow or an existing image tool.
Re-encode RGB/RGBA pixels without EXIF, comments or source filenames. Preserve aspect ratio;
letterbox to the same dimensions rather than stretching. Capture UI variants at the same
viewport, scale and interaction state. Crop browser tabs/address bars and neutralize identifying
logos, watermarks and labels only in copies when doing so preserves the comparison question.
Inspect the actual pixels and remaining filename/desktop/browser chrome. Do not claim metadata
removal removes a visible watermark or that automatic cropping found every identity cue.
If a watermark is itself the decision-relevant feature, disclose that full blinding is impossible.
