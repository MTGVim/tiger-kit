# 위임의 실행 예산과 종료

컨트롤러가 자식을 처음 디스패치하거나 같은 작업을 재개·교체·재시도하기 전에 읽습니다.
SDD 선택이나 새 장부를 요구하지 않으며, [위임 권한](delegation-permissions.md)을 대신하지 않습니다.

## 디스패치 계약과 관측 범위

브리프에 목표·허용 범위·구체적인 위험에 따른 조사 확대 조건, 완료·중단 조건과 부분 반환 의무를 담습니다.
소스를 읽을 담당자가 따로 있다면 컨트롤러가 전달 준비를 위해 같은 구현 분석을 먼저 끝내지 않습니다.
기존에 확정한 결정·계약과 필요한 진입점은 보존하고, 담당자가 원본을 읽게 합니다.

실제 호스트의 한도·사용량 조회·중단·재개 기능을 먼저 확인하고 다음을 구분합니다.

- **개별 자식 예산**: 역할·작업 크기에 맞춰 관측 가능한 턴·도구 호출·경과 시간·보고된 사용량 중 적용할 지표, 한도와 종료 준비 시점을 정합니다.
- **전체 작업의 누적 예산**: 컨트롤러와 모든 자식·재개·교체·재시도를 포함해 관측 가능한 실행량의 총 한도와 남은 필수 리뷰·검증·인계·정리 여유를 정합니다. 새 작업 시작 전에 실행 중 작업의 예상 잔여량도 고려합니다.
- **반환 자료량**: 짧은 상태·판정과 큰 근거의 경로를 분리합니다. 짧은 반환은 실행 비용 제한이 아니며 결함·실패·불확실성을 생략할 이유가 아닙니다.

숫자는 현재 작업과 관측 가능한 단위에 맞춰 브리프·컨트롤러 맥락에 정하며 고정 전역 값이나 제공자 모델 ID를 추가하지 않습니다.
호스트가 실제 강제하는 제한과 프롬프트상의 권고를 명시적으로 구분합니다. 지원하지 않는 API·필드나 관측하지 못한 토큰 값을 만들지 않습니다.
정산이 늦는 사용량은 다음 디스패치 판단에 쓰되 실행 중인 작업까지 정확한 실시간 hard cap으로 제한한다고 주장하지 않습니다.
관측·강제할 수 없는 지표는 그 한계와 사용 가능한 대리 지표를 밝힙니다. 적용 가능한 실행 지표가 없더라도 범위·종료 조건과 기존 수정 상한은 유지합니다.

## 역할별 종료와 누적 제한

읽기 전용 조사자·리뷰어·검증자는 한도에 도달하면 완료한 범위·근거·발견 사항과 미검토 범위를 반환합니다.
검토가 부족한 판정은 `Unverifiable`이며 예산 소진은 `Pass`가 아닙니다. 구체적인 횡단 위험에 필요한 조사를 막거나 필수 검증을 생략하지 않습니다.

구현자·수정자는 좁고 완료 가능한 작업 조각을 맡고, 읽기·검증·안전한 인계를 막는 촉박한 강제 한도를 피합니다.
종료 준비 시 새 작업을 시작하지 않고 가능한 도구 경계에서 변경 파일, 검증 상태, 남은 일과 commit 상태를 반환합니다.
강제 timeout은 안전한 checkpoint가 아닙니다. 결과나 이전 자식의 쓰기 종료가 불명확하면 호출자의 복구 계약으로 실제 변경·생명주기를 대조하기 전 새 구현자를 디스패치하지 않습니다.
종료를 위해 무조건 commit하거나 미완성 변경을 버리지 않습니다.

재개·교체·재시도에도 같은 작업의 소모량·남은 한도·실패 이력과 수정 회차를 이어받습니다. 알 수 없는 사용량을 0으로 초기화하지 않습니다.
기존 컨트롤러 맥락과 활성화된 복구 자료만 재사용하며 새 영구 예산 장부를 만들지 않습니다. 호출자가 영구 복구를 사용한다면 재개에 필요한 누적 상태도 그 자료에 보존합니다.
전체 예산으로 새 작업을 시작할 수 없으면 남은 필수 검토·검증을 명시해 미완료로 반환합니다.
승인 범위 안의 재배분·진단·재시도마다 사용자에게 추가 토큰 승인을 묻지 않으며, 권한·범위·중대한 결정 변경이나 계속할 수 없는 한계만 기존 질문 경계로 반환합니다.

## 무진행 반복과 접근 변경

같은 실패·검사·수정이 반복되면서 새 근거, 변경된 가설과 검증 진전이 모두 없을 때만 무진행으로 판단합니다.
정상 TDD RED, 의도적인 재현 실험과 진행 중인 장시간 검사는 단순 횟수만으로 실패 루프가 아닙니다.
무진행이면 같은 호출을 되풀이하기 전에 범위 안의 다른 진단 방식이나 적절한 역량 상향을 선택합니다.
그래도 해결되지 않으면 실제 시도·관찰·남은 문제를 부분 결과로 반환합니다. 기존 5회 수정 상한과 `complexity reset`을 재사용하며 재개·교체·설계 재검토로 회차를 초기화하거나 별도 반복 루프를 더하지 않습니다.
