# 의미 중심 리뷰 계획

승인 전에 변경 의도, 원래 사건 또는 예상 시나리오, 기대하는 변경 결과, `must-not-change` 동작이나 시각 영역, 변경에 귀속되는 위험 경계, 필요한 자동화·런타임·브라우저 근거와 구현 전에 알려진 불확실성을 다루는 의미 중심 리뷰 계획을 유지합니다. 사용자에게 보이는 출력이 바뀌면 승인 제안에 명시된 모든 신규·변경·삭제 표시 필드와 정확한 문구 및 조건별 표시 상태를 리뷰 계획에 그대로 연결하고 `이 밖의 표시 항목 없음`을 명시합니다. 이 목록은 허용된 표시의 상한이며 리뷰어에게 같은 목록을 전달해 누락뿐 아니라 초과 표시도 판정하게 합니다. 코드를 변경하는 모든 Ready Seed에 이를 보존합니다. direct/no-Seed 경로에서는 동일하게 승인된 의무를 현재 상호작용에 유지합니다.

Seed에 리뷰어 수, 제공자·모델 식별 정보, 작업자 라우팅이나 리뷰 대화록을 저장하지 않습니다. 정확한 diff가 존재한 뒤 실행 구조와 [독립 리뷰 프로토콜](review-protocol.md)이 리뷰 역할 수를 결정합니다.
