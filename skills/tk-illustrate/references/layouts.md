# 레이아웃 색인

조합 추천에는 이 색인만 읽고, 선택한 레이아웃의 카드만 추가로 읽습니다. 아래 21개 ID는 배치 방식이며 실제 관계를 증명하지 않습니다. 원문에 없는 단계·계층·인과·비율을 만들어 내지 않습니다.

| ID | 적합한 정보 |
| --- | --- |
| [linear-progression](layouts/linear-progression.md) | 선형 순서. 시간·단계·절차. |
| [binary-comparison](layouts/binary-comparison.md) | 두 대상 비교. A/B·전후·장단점. |
| [comparison-matrix](layouts/comparison-matrix.md) | 여러 기준 비교. 복수 대상·여러 속성. |
| [hierarchical-layers](layouts/hierarchical-layers.md) | 계층. 수준·우선순위·층위. |
| [tree-branching](layouts/tree-branching.md) | 분기 트리. 분류·결정·조직. |
| [hub-spoke](layouts/hub-spoke.md) | 중심과 주변 항목. 핵심 개념·관련 요소. |
| [structural-breakdown](layouts/structural-breakdown.md) | 구조 분해. 시스템 구성·부품·단면. |
| [bento-grid](layouts/bento-grid.md) | 모듈 격자. 개요·여러 주제. |
| [iceberg](layouts/iceberg.md) | 표면과 숨은 부분. 보이는 현상·기저 조건. |
| [bridge](layouts/bridge.md) | 현재와 목표 사이. 문제·해결 단계. |
| [funnel](layouts/funnel.md) | 단계별 축소. 필터링·전환. |
| [isometric-map](layouts/isometric-map.md) | 등각 배치. 공간·구성 관계. |
| [dashboard](layouts/dashboard.md) | 지표 모음. 지표·현황·자료 요약. |
| [periodic-table](layouts/periodic-table.md) | 분류별 동일 카드. 목록·도구·요소 분류. |
| [comic-strip](layouts/comic-strip.md) | 한 장의 순서 장면. 단순 시나리오·행동 순서. |
| [story-mountain](layouts/story-mountain.md) | 이야기의 변화. 서사·문제 해결 개요. |
| [jigsaw](layouts/jigsaw.md) | 결합하는 구성 요소. 조합·통합·역할. |
| [venn-diagram](layouts/venn-diagram.md) | 집합의 교집합. 공통점·차이·겹침. |
| [winding-roadmap](layouts/winding-roadmap.md) | 굽은 경로. 학습·프로젝트 단계. |
| [circular-flow](layouts/circular-flow.md) | 순환 과정. 반복·피드백·수명주기. |
| [dense-modules](layouts/dense-modules.md) | 고밀도 정보 모듈. 상세 가이드·복수 정보 영역. |

엄격한 수치·코드·정확한 토폴로지가 목표이면 정적 제작 경로를 제안합니다. `comic-strip`은 한 장의 단순한 순서 설명에 한정하며 다중 페이지 만화는 `tk-comic`이 소유합니다.
