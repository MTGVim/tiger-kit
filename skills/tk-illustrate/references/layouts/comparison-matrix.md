# 여러 기준 비교: `comparison-matrix`

이 레이아웃을 선택한 경우에만 읽고 콘티와 프롬프트에 반영합니다.

- 적합한 정보: 복수 대상·여러 속성.
- 배치: 행은 대상, 열은 기준으로 고정하고 각 셀을 동일한 단위와 조건으로 채웁니다. 미확인 값은 빈 성공 표시로 바꾸지 않습니다.
- 실패 조건: 정확한 표 자체가 결과물의 핵심이면 정적 표를 제안하며 작은 셀의 글자를 무리하게 줄이지 않습니다.

확정된 스타일·비율·정확한 라벨과 결합하고 실제 픽셀의 읽기 순서를 검사합니다. [출처와 조정](../sources.md)을 따릅니다.
