# 고밀도 정보 모듈: `dense-modules`

이 레이아웃을 선택한 경우에만 읽고 콘티와 프롬프트에 반영합니다.

- 적합한 정보: 상세 가이드·복수 정보 영역.
- 배치: 서로 다른 정보 기능을 가진 모듈로 나누고 제목·번호·여백을 일관되게 둡니다. 실제 표시 크기에 맞춰 필요한 만큼만 배치합니다.
- 실패 조건: 고정 6~7개 모듈·작은 글자·가짜 데이터 채우기를 강제하지 않으며 읽기 어려우면 분할을 제안합니다.

확정된 스타일·비율·정확한 라벨과 결합하고 실제 픽셀의 읽기 순서를 검사합니다. [출처와 조정](../sources.md)을 따릅니다.
