# 윤곽선이 있는 평면 삽화: `vector-illustration`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 교육·개념·기술 문서.
- 표현: 일정한 검은 외곽선, 닫힌 단순 도형, 크림색 바탕과 산호·민트·겨자색을 사용합니다. 그라데이션·사실적 입체 음영을 제외합니다.
- 정확성·가독성: 이 이름은 시각적 표현이며 실제 SVG 벡터 출력이나 수학적으로 정확한 선을 보장하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
