# 학술 도해 삽화: `scientific`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 과학 개념·기술 과정.
- 표현: 밝은 바탕, 명확한 경계, 경로별 청록·파랑·보라와 정확한 라벨을 사용합니다. 원문이 뒷받침한 구조만 묘사합니다.
- 정확성·가독성: 정밀 측정 차트·논문용 정확한 데이터 그림은 정적 제작을 사용하며 과학적 외관을 사실 검증으로 대체하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
