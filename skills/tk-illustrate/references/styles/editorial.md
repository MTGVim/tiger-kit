# 잡지 해설 삽화: `editorial`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 해설·자료·전문 콘텐츠.
- 표현: 흰색·옅은 회색 바탕, 검정 글자, 파랑·산호 강조로 정보 위계를 만듭니다. 짧은 설명과 시각 근거를 같은 영역에 둡니다.
- 정확성·가독성: 출판물 로고·표지를 복제하거나 강조 크기를 실제 통계량처럼 사용하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
