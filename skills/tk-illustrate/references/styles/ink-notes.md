# 검은 잉크 시각 노트: `ink-notes`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 전후 비교·기술 개념·틀.
- 표현: 질감 없는 흰 바탕에 검은 잉크 선을 사용합니다. 산호·청록·연보라를 의미가 있는 강조에만 제한합니다.
- 정확성·가독성: sketch-notes의 따뜻한 종이·많은 파스텔 면을 섞지 않고 지정한 절제된 표현을 보존합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
