# 화면 와이어프레임: `ui-wireframe`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 화면 개념·사용 흐름.
- 표현: 흰 바탕과 회색 상자, 단순한 선 아이콘, 제한된 파랑 강조를 사용합니다. 확정된 UI 문구를 실제 위치에 배치합니다.
- 정확성·가독성: Lorem ipsum이나 미확인 버튼·제품 동작을 넣지 않으며 실제 구현 화면으로 보고하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
