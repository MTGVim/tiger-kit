# 화면 와이어프레임: `ui-wireframe`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 화면 개념·사용 흐름.
- 표현: 흰 바탕과 회색 상자, 단순한 선 아이콘, 제한된 파랑 강조를 사용합니다. 확정된 UI 문구를 실제 위치에 배치합니다.
- 정확성·가독성: 실제 요구에 근거한 라벨·버튼·제품 동작만 표현하고 결과는 wireframe으로 구분합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침입니다. 실제 파일 형식과 정밀도는 생성 결과로 확인합니다. [출처와 조정](../sources.md)을 따릅니다.
