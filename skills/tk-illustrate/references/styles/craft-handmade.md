# 종이 공예와 손그림: `craft-handmade`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 개요·교육·일상 개념.
- 표현: 크림색 종이, 조금 불규칙한 선, 단순한 그림과 충분한 여백을 사용합니다. 종이 오리기 표현은 겹친 종이의 얕은 그림자로만 구분합니다.
- 정확성·가독성: 사진 질감이나 과도한 장식으로 정보 영역과 라벨을 가리지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
