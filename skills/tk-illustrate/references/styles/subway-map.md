# 노선도: `subway-map`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 과정·경로·네트워크.
- 표현: 흰 바탕에 색이 구분된 노선, 역 형태의 노드, 45도·90도 연결을 사용합니다. 교환 지점과 경로 이름을 명확히 씁니다.
- 정확성·가독성: 실제 관계가 없는 노드에 환승이나 방향을 만들어 넣지 않으며 지리적 거리로 해석하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
