# 실크스크린 포스터: `screen-print`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 의견·문화·상징적 장면.
- 표현: 2~5개 제한된 색, 굵은 실루엣, 망점과 인쇄 질감을 사용합니다. 여백의 형태와 상징으로 핵심 대비를 만듭니다.
- 정확성·가독성: 상징으로 정확한 수치·조건을 대신하지 않으며 복잡한 흐름에는 짧은 라벨과 명확한 연결을 확보합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
