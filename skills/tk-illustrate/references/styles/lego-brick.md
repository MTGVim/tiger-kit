# 조립 블록 모형: `lego-brick`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 모듈·조합·구성.
- 표현: 단순한 장난감 블록, 눈에 보이는 결합부와 원색을 사용합니다. 대상의 구성 단위를 구분하는 데 블록을 활용합니다.
- 정확성·가독성: 상표·고유 캐릭터·로고를 기본 복제하지 않으며 블록의 접합을 미확인 의존성으로 만들지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
