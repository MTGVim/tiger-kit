# 복고 격자 포스터: `retro-pop-grid`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 비교·분류·정보 개요.
- 표현: 크림색 바탕, 굵은 검은 격자와 외곽선, 분홍·하늘색·겨자색 면을 사용합니다. 핵심 영역만 흑백을 반전합니다.
- 정확성·가독성: 장식 영문·기호를 확정된 독자 언어에 임의로 섞거나 빈칸을 의미 없는 데이터로 채우지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
