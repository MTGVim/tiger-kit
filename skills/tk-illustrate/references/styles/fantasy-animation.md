# 손그림 판타지: `fantasy-animation`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 동화·상상 장면·정서.
- 표현: 부드러운 손그림 인물, 회화적 배경, 따뜻한 색과 절제된 환상 요소를 사용합니다. 캐릭터는 독창적으로 설계합니다.
- 정확성·가독성: 상상 요소는 사실과 구분하고 특정 작품의 고유 캐릭터·상징을 기본으로 가져오지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
