# 수채 동화책: `storybook-watercolor`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 이야기·정서·자연 장면.
- 표현: 옅은 수채 번짐, 가는 선, 종이 여백, 절제된 붓 자국으로 장면을 구성합니다. 설명 라벨에는 번짐 없는 공간을 둡니다.
- 정확성·가독성: 정밀 연결 관계나 데이터가 핵심이면 흐린 경계가 오해를 만들지 않는지 확인합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
