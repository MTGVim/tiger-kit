# 기술 브리핑 노트: `intuition-machine`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 기술 설명·구조 요약.
- 표현: 오래된 크림색 종이, 짙은 적갈색 제목, 청록·갈색 도판과 정돈된 2D 또는 등각 시점을 사용합니다.
- 정확성·가독성: 이중 언어·촘촘한 주석을 강제하지 않으며 확정된 언어와 실제 표시 크기를 우선합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
