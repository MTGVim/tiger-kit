# 기술 구조도: `technical-schematic`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 구성 요소·계층·분해.
- 표현: 파랑·청록·회색과 일정한 선 두께를 사용합니다. 격자 또는 일관된 등각 시점 위에 확인된 구성 요소와 호출선을 배치합니다.
- 정확성·가독성: 치수·눈금·회로 기호는 확인된 자료에 따라 표시하며 축척은 별도 근거가 있을 때만 명시합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침입니다. 실제 파일 형식과 정밀도는 생성 결과로 확인합니다. [출처와 조정](../sources.md)을 따릅니다.
