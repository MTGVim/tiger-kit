# 기술 구조도: `technical-schematic`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 구성 요소·계층·분해.
- 표현: 파랑·청록·회색과 일정한 선 두께를 사용합니다. 격자 또는 일관된 등각 시점 위에 확인된 구성 요소와 호출선을 배치합니다.
- 정확성·가독성: 장식용 치수·눈금·회로 기호를 추가하지 않으며 그림의 정밀한 외관을 검증된 축척으로 주장하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
