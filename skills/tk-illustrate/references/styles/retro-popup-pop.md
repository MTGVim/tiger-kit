# 복고 팝업 창: `retro-popup-pop`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 정보 모듈·오개념·비교.
- 표현: 청록 또는 크림색 바탕 위에 굵은 테두리의 옛 데스크톱 창을 배치합니다. 평면 색상과 검은 그림자로 층위를 구분합니다.
- 정확성·가독성: ERROR는 실제 오류가 확인된 곳에만 표시하며 창은 정적 설명 이미지로 구분합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침입니다. 실제 파일 형식과 정밀도는 생성 결과로 확인합니다. [출처와 조정](../sources.md)을 따릅니다.
