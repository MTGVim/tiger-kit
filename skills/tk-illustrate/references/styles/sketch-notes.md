# 따뜻한 시각 노트: `sketch-notes`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 교육·온보딩·개념 요약.
- 표현: 크림색 종이, 검은 손그림 선과 파스텔 정보 상자를 사용합니다. 단순한 아이콘과 읽을 수 있는 손글씨로 통일합니다.
- 정확성·가독성: 모든 그림에 동일한 상자 수·결론 위치를 강제하지 않고 내용 구조를 우선합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
