# 밝은 설계도: `blueprint`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 아키텍처·시스템·기술 문서.
- 표현: 밝은 설계지와 옅은 격자 위에 파랑·남색 연결과 회색 라벨을 사용합니다. 일정한 선 두께와 정렬로 영역을 구분합니다.
- 정확성·가독성: 장식 치수나 미확인 토폴로지를 넣지 않으며 technical-schematic의 어두운 설계도와 동일하다고 가정하지 않습니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
