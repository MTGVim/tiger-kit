# 네온 기술 장면: `cyberpunk-neon`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 미래 기술·게임·디지털 문화.
- 표현: 짙은 검정·보라 바탕, 청록·분홍 윤곽, 제한된 회로 모티프를 사용합니다. 제목과 본문은 또렷한 밝은 글자로 구분합니다.
- 정확성·가독성: 광원 번짐·글리치는 라벨을 보존하는 범위에서 사용하고 확인된 회로 연결만 표현합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침입니다. 실제 파일 형식과 정밀도는 생성 결과로 확인합니다. [출처와 조정](../sources.md)을 따릅니다.
