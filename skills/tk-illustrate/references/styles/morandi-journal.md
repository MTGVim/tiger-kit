# 차분한 다이어리: `morandi-journal`

이 스타일을 선택한 경우에만 읽고 제작 프롬프트에 필요한 지침을 반영합니다.

- 적합한 용도: 정보 가이드·친근한 기록.
- 표현: 크림색 종이, 세이지·청록·테라코타, 단정한 손그림 카드와 점선을 사용합니다. 테이프나 작은 낙서는 여백에 제한합니다.
- 정확성·가독성: 표정·진행 막대가 근거 없는 추천·품질 점수를 나타내지 않도록 합니다.

명시한 팔레트는 기본 색상을 바꾸며 선·형태·질감 계약은 유지합니다. 이 카드는 AI 래스터의 표현 지침이며 해당 파일 형식이나 정밀도를 보장하지 않습니다. [출처와 조정](../sources.md)을 따릅니다.
