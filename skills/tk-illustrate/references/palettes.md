# 팔레트

팔레트를 지정했거나 추천 조합에 포함할 때만 읽습니다. 팔레트는 스타일의 기본 색상을 바꾸며 선·질감·형태를 바꾸지 않습니다. `warm` 같은 이름이 스타일에도 있으면 어느 옵션의 값인지 구분합니다.

| ID | 색과 역할 |
| --- | --- |
| `macaron` | 크림색 바탕에 파랑 `#A8D8EA`, 민트 `#B5E5CF`, 연보라 `#D5C6E0`, 복숭아 `#FFD5C2`를 영역별로 사용하고 글자는 짙은 회색으로 둡니다. |
| `warm` | 크림·복숭아 바탕에 주황·테라코타·금색을 사용합니다. 경고와 일반 강조를 구분하고 짙은 갈색 글자로 대비를 확보합니다. |
| `neon` | 짙은 보라 바탕에 분홍·청록·노랑을 제한적으로 사용합니다. 본문은 밝고 번짐 없는 글자로 두며 광원 효과를 라벨 밖에 제한합니다. |
| `mono-ink` | 흰 바탕과 검은 잉크를 중심으로 산호·차분한 청록·연보라를 의미 있는 강조에만 사용합니다. |
| `cool` | 밝은 회색 또는 짙은 남색 바탕에 파랑·청록과 필요한 최소 강조색을 사용합니다. 기술 구성 요소를 색으로 구분할 때 범례를 붙입니다. |

`cool`은 TigerKit의 기술 설명용 조합입니다. 나머지 네 이름은 upstream에서 조정했습니다. 사용자가 실제 색상값을 지정하면 그것을 우선하며 원래 의미 색과 충돌할 경우 라벨·모양으로도 구분합니다. 색상만으로 상태나 우열을 전달하지 않습니다. 보이는 최종 이미지의 대비를 검사하며 팔레트의 존재만으로 접근성을 통과했다고 판단하지 않습니다.
