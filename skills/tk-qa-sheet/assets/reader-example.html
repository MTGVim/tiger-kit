아래 예시는 정확성과 응답 속도를 비교하기 위한 가상 시나리오입니다.

만료된 값을 막으면 최신 조회를 기다려야 합니다. 이전 값을 먼저 보여 주면 빨리 응답할 수 있지만, 갱신 전까지 오래된 값이 보입니다.

만료 시각에 도착한 요청

오전 10시에 저장한 값이 10시 5분에 만료된다고 가정합니다.
10시 5분에 요청이 도착하면 만료 조건에 따라 저장된 값을 사용할지 결정합니다.

처리 방식사용자가 받는 결과주요 단점
조회가 끝난 뒤 응답합니다.새로 조회한 값을 받습니다.조회 시간만큼 기다립니다.
이전 값으로 먼저 응답합니다.저장된 값을 받고 이후에 갱신합니다.오래된 값이 보일 수 있습니다.

허용할 수 있는 지연과 데이터의 유효 기간을 모르므로, 이 예시에서는 어느 방식도 권장하지 않습니다.

경계 조건을 코드로 확인하기

이 예시에서는 현재 시각이 만료 시각보다 작을 때만 캐시 값을 반환합니다.
두 시각이 같을 때의 결과는 경계 해설에서 확인할 수 있습니다.[1]

function readCache(entry, now) {
  return now < entry.expiresAt ? entry.value : null;
}
